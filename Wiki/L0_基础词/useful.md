# useful

> [!info] 基础信息
> **音标** /ˈjuːsfl/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**有用的，实用的**==；②==**有益的，有帮助的**==；

> [!tip] 原型义
> **原型义**：有用的（充满使用价值的）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接从"使用"引申为"有使用价值的"）

## 词根词缀

use(使用) + -ful(形容词后缀，充满……的)
**叙事**：use（使用）+ ful（充满）→ **充满使用价值的** → 有用的。a useful tool（有用的工具），a useful suggestion（有用的建议），a useful experience（有益的经历）。-ful 后缀表示"充满"，所以 useful 就是"充满用处"。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**有用的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **有用的**（功能层面）
>    - → **实用的**：有实际使用价值
>      - 激活条件：a useful tool, useful information
>    - → **有益的，有帮助的**：对人或事有帮助
>      - 激活条件：a useful experience, useful advice

### 统筹（选择适用的模式）

- **一字一词概括**：useful 就是"有用"——实用、有益、有帮助
- **延伸中心**：从"功能上有用"延伸到"对人有帮助"

> [!check]- 链路验证
> - [x] **可逆性**：从"有益的经历"能反向推导到"有用的"——有益就是对人有用的
> - [x] **可统筹**：一句话——"useful 就是充满使用价值的"
> - [x] **有支撑**：useful tips, useful information 均有真题支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> use（使用）+ ful（充满）→ useful。一个充满 use 的东西就是 useful 的。useful tips（有用的小贴士），useful information（有用的信息），a useful experience（有益的经历）。反义词就是 useless（无用的）——没有 use 的。
>
> **词拆分记忆**（辅助）：
> use（使用）+ ful（充满，联想 full 满的）→ 充满使用价值 → 有用的
