# machine

> [!info] 基础信息
> **音标** /məˈʃiːn/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**机器，机械**==（通过动力驱动的装置）；②==**计算机**==（口语）；③==**组织，机构**==（比喻高效运转的系统）；④==**车辆**==（口语，尤指汽车）；
**v.** ⑤==**用机器制造**==（machine sth）；

> [!tip] 原型义
> **原型义**：机器、装置（通过机械结构完成工作的设备）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（"机械装置"→"高效运转的组织"——从物理机器到抽象系统）

## 词根词缀

源自法语 *machine*（机器），来自拉丁语 *machina*（机器、装置、诡计），原始印欧语 *\*magh-*（能够、有力量）。与 [[mechanic]]（机械工）、[[mechanism]]（机制）、[[mechanical]]（机械的）同源，均来自希腊语 *mēkhanē*（机器、装置、手段）。与 [[mag]] 词根（力量、能力）有原始印欧语层面的关联。[[techn]]（技术、技艺）词根与 machine 的概念密切相关——技术就是制造和使用机器的能力。

**叙事**：machine 的核心画面是"一台轰隆隆运转的蒸汽机"。拉丁语 *machina* = 机器、装置。一台由齿轮、杠杆、活塞组成的庞大装置在轰隆隆运转——这就是 machine 的原始画面。从"物理机器"延伸到"计算机"——machine learning（机器学习）。再延伸到"高效运转的组织"——the party machine（政党机器），a well-oiled machine（运转良好的机器→高效团队）。machine 还可以指"车辆"——Are you taking the machine?（你开车去吗？）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**机器、装置**"为统筹中心，沿具身路径向外扩展：
>
> 1. **机械装置**（物理层面）
>    - → **机器，机械**：动力驱动的设备
>      - 激活条件：washing machine, sewing machine
>    - → **计算机**：信息处理机器
>      - 激活条件：machine learning, virtual machine
>    - → **组织，机构**：像机器一样运转的系统
>      - 激活条件：party machine, bureaucratic machine

### 统筹（选择适用的模式）

- **一字一词概括**：machine 就是"机器"——通过结构完成工作的装置
- **延伸中心**：从"物理机器"延伸到"计算机"再到"高效组织"

> [!check]- 链路验证
> - [x] **可逆性**：从"政党机器"能反向推导到"机器"——组织像机器一样运转
> - [x] **可统筹**：一句话——"machine 就是从物理机器到计算机到高效运转的组织"
> - [x] **有支撑**：washing machine, machine learning, party machine 均有语料支撑
