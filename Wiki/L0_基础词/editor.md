# editor

> [!info] 基础信息
> **音标** /ˈedɪtə(r)/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**编辑，编者**==（负责编辑出版物的人）；②==**主编**==（编辑部的负责人）；③（计算机）编辑器，编辑程序；

> [!tip] 原型义
> **原型义**：把作品向外呈现的人——编辑
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"向外呈现者"→"编辑人员"——从动作执行者到职业身份）

## 词根词缀

源自拉丁语 *editor*（出版者），是 *edere*（e-向外 + dere放置/给予，"向外呈现"）的施事名词形式。1640年代最初意思是"出版者"，1712年后演变为"为出版准备文稿的人"——即编辑。*edere* 的过去分词 *editus* 是 [[edit]]（编辑）的来源。*edere* 中的 *dare*（给予）与 [[date]]（日期）、[[donate]]（捐赠）同源。

**叙事**：editor 是"把作品向外呈现的人"。1640年代，editor 最初指"出版者"——那个把作品呈现给世人的人。后来随着出版业的发展，editor 的角色从"出版者"细化为"编辑"——那个在作品呈现给世人之前，负责修改、校订、打磨的人。今天 editor 可以是报社的主编（editor-in-chief），可以是学术期刊的编辑，也可以是计算机的文本编辑器（text editor）。editor 的灵魂是"把关者"——在作品和读者之间，editor 是那个决定"什么值得呈现、如何呈现"的人。

相关词：[[edit]]（编辑）、[[edition]]（版本）、[[editorial]]（社论）

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**把作品向外呈现的人——编辑**"为统筹中心，沿社会路径向外扩展：
>
> 1. **向外呈现的人**（身份层面）
>    - → **编辑，编者**：负责编辑出版物的人
>      - 激活条件：a newspaper editor, a book editor
>    - → **主编**：编辑部的负责人
>      - 激活条件：editor-in-chief, managing editor
>    - → **编辑器**（计算机）：编辑文本的程序
>      - 激活条件：text editor, photo editor

### 统筹（选择适用的模式）

- **一字一词概括**：editor 就是"编辑"——作品呈现给世人之前的把关者
- **延伸中心**：从"出版者"到"编辑人员"再到"计算机编辑器"

> [!check]- 链路验证
> - [x] **可逆性**：从"编辑"能反向推导到"向外呈现者"——编辑就是呈现作品的人
> - [x] **可统筹**：一句话——"editor 就是从出版者到编辑把关者"
> - [x] **有支撑**：newspaper editor, editor-in-chief 均有语料支撑
