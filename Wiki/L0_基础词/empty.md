# empty

> [!info] 基础信息
> **音标** /ˈempti/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**空的**==；②==**空洞的，无意义的**==；③空虚的；
**v.** ①倒空，腾空；

> [!tip] 原型义
> **原型义**：没有内容→空洞的→无意义的（源自古英语 *æmettig* = at leisure, vacant）
> **延伸维度**：充实程度
> **隐喻类型**：从"物理上的空"到"抽象意义上的空洞"——容器里没有东西是"空"，话语里没有实质内容是"空洞"

## 词根词缀

empty 源自古英语 *æmettig*（空闲的，未被占用的），与拉丁语 *vacare*（空）概念类似。无典型前缀-词根-后缀结构，为日耳曼语系本族词。
**叙事**：empty 是英语中最"空"的词。一个 empty cup（空杯子）里面没有水，一段 empty rhetoric（空洞的修辞）里面没有实质内容，一个 empty life（空虚的生活）里面没有意义。empty 从物理空间延伸到抽象内容，"空"的本质不变——缺少本该存在的东西。

## 词义链路

> [!abstract]- 词义链路法
> 以"**缺少本该存在的内容**"为统筹中心，沿充实程度向外扩展：
>
> 1. **缺少内容（物理层面）**
>    - → **空的**：容器、空间里没有东西
>      - 激活条件：an empty room, an empty bottle, empty hands
>    - → **倒空，腾空**（动词）：使某物变空
>      - 激活条件：empty the trash, empty a glass
> 2. **缺少内容（抽象层面）**
>    - → **空洞的，无意义的**：话语、承诺中缺少实质
>      - 激活条件：empty promises, empty rhetoric, empty words
>    - → **空虚的**：情感、生活中缺少意义
>      - 激活条件：feel empty, an empty life

### 统筹（选择适用的模式）

- **一字一词概括**：empty 就是"缺少本该存在的东西"——杯子里缺水是"空"，话里缺内容是"空洞"
- **延伸中心**：从"物理上的空"延伸到"抽象意义上的空洞"

> [!check]- 链路验证
> - [x] **可逆性**：从"空洞的承诺"能反向推导到"缺少内容"——空洞的承诺就是缺少实质内容的承诺
> - [x] **可统筹**：一句话——"empty 就是缺少本该存在的东西"
> - [x] **有支撑**：empty promises, empty rhetoric, an empty room 均有语料支撑
