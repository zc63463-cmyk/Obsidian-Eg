# numerical

> [!info] 基础信息
> **音标** /njuːˈmerɪkl/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**adj.** ①==**数字的，数值的**== `adj`；②==**用数字表示的**== `adj`；

> [!tip] 原型义
> **原型义**：数字的（与数字相关的）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接从 number 派生）

## 词根词缀

[[numer]](=number, 数字，源自拉丁语 *numerus*) + -ical(形容词后缀，"与……有关的")
**叙事**：numer（数字）+ ical（与……有关的）→ 与数字有关的 → 数字的。numer- 词根系列：number（数字）、numerous（众多的）、numerical（数字的）、numeral（数字的/数字）、innumerable（无数的 = in-不 + numerable 可数的）。numerical data = 数字数据；numerical analysis = 数值分析。

## 词义链路

> [!abstract]- 词义链路法
> 以"**数字的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **数字的**（数学层面）
>    - → **数值的**：用数值表示的
>      - 激活条件：numerical value, numerical data
>    - → **用数字表示的**：以数字形式呈现的
>      - 激活条件：numerical order, numerical superiority

### 统筹（选择适用的模式）

- **一字一词概括**：numerical 就是"用数字说话"——数字数据是"数值的"，数字排列是"数字顺序的"
- **延伸中心**：从"与数字相关"延伸到"数值表示"和"数量比较"

> [!check]- 链路验证
> - [x] **可逆性**：从"数值优势"能反向推导到"数字的"——用数字衡量的优势
> - [x] **可统筹**：一句话——"numerical 就是与数字有关的一切"
> - [x] **有支撑**：numerical data, numerical order 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> numer（数字）+ ical（与……有关的）→ 与数字有关的。记住 numer- 词根家族：number（数字）→ numerous（众多的 = 数字很多）→ numerical（数字的）→ numeral（数字）→ enumerate（列举 = e-出 + numer 数字 + ate → 把数字列出来）。numerical 就是"数字的"。
>
> **词拆分记忆**（辅助）：
> nu（新）+ merical（谜题）→ 新的数字谜题 → 数字的
