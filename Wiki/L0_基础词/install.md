# install

> [!info] 基础信息
> **音标** /ɪnˈstɔːl/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**v.** ①==**安装，设置**== `install a system/software` [正式]；②==**正式任命，使就职**== `install sb as sth` [正式]；③安置，安顿；

> [!tip] 原型义
> **原型义**：放入固定位置（将某人/某物安置到正式的位置上）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"安置到固定位置"→ 安装设备 / 任命到职位）

## 词根词缀

in-(进入) + stall(摊位/固定位置，源自古高地日耳曼语 *stal* "站立之处")
**叙事**：in（进入）+ stall（固定位置）→ 把东西放到它该在的固定位置 → 安装。就像把一台空调装到墙上它该待的位置，或者把一位新牧师安排到教堂的正式座位上。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**放入固定位置**"为统筹中心，沿空间路径向外扩展：
>
> 1. **放入固定位置**（物理层面）
>    - → **安装，设置**：将设备放到使用位置
>      - 激活条件：install software, install a system
>    - → **正式任命，使就职**：将人放到正式职位
>      - 激活条件：install a president, be installed in office
>    - → **安置，安顿**：将人/物放到合适位置
>      - 激活条件：install oneself in a hotel

### 统筹（选择适用的模式）

- **一字一词概括**：install 就是"放到位"——设备放到位叫"安装"，人放到位叫"任命"
- **v + 不同宾语**：install + 设备→安装；install + 人→任命

> [!check]- 链路验证
> - [x] **可逆性**：从"任命"能反向推导到"放入固定位置"——任命就是把人放到职位上
> - [x] **可统筹**：一句话——"install 就是把人/物放到该在的固定位置"
> - [x] **有支撑**：install software, install a president 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> 中世纪教堂仪式中，新牧师被正式安排坐到唱诗班的固定座位（stall）上，这就是 install 的本义。后来从"把人安排到座位上"扩展到"把设备安装到位置上"。install 就是"放到该在的位置"。
>
> **词拆分记忆**（辅助）：
> in（进入）+ stall（摊位/位置）→ 放到固定位置 → 安装/任命
