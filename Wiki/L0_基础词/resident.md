# resident

> [!info] 基础信息
> **音标** /ˈrezɪdənt/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**n.** ①==**居民，定居者**== `\local ~s / permanent ~\` [通用]；②==**（旅馆的）住宿者**== `\hotel ~s\` [通用]；③==**住院医生**== `\~ physician / senior ~\` [专业]；
**adj.** ①==**定居的，常驻的**== `\~ expert / ~ population\` [通用]；②==**（在某地）居住的**==；

> [!tip] 原型义
> **原型义**：居民，定居者（re- + sid + -ent，"再次坐下来的人"→ 定居的人）
> **延伸维度**：常驻身份
> **隐喻类型**：空间隐喻（"坐下来的人"→ "居民"→ "住院医生"——从物理定居到专业身份）

## 词根词缀

re-(前缀：再/回) + sid(坐，[[st-sta-stat]]的变体) + -ent(名词后缀：表示人)
**叙事**：resident 来自拉丁语 *residens*，re- = 回/再，sid = 坐（来自 PIE *\*sed-*，与词根 [[st-sta-stat]] 同源），-ent = 人。核心逻辑是"坐下来的人"→ "定居的人"→ "居民"。local residents = 当地居民。resident alien = 外籍居民。resident doctor = 住院医生（住在医院里的医生）。resident 也可以作形容词表示"定居的、常驻的"——resident expert = 常驻专家。与 [[residence]]（住所）和 [[reside]]（居住）同词族。

## 词义链路

> [!abstract]- 词义链路法
> 以"**居民/定居者**"为统筹中心，沿常驻身份向外扩展：
>
> 1. **坐下来的人**（身份层面）
>    - → **居民，定居者**：在某个地方定居的人
>      - 激活条件：local residents, permanent resident
>    - → **住宿者**：住在旅馆的人
>      - 激活条件：hotel residents
>    - → **住院医生**：住在医院的医生
>      - 激活条件：resident doctor/physician
>    - → **定居的，常驻的**：形容词用法
>      - 激活条件：resident expert, resident population

### 统筹（选择适用的模式）

- **一字一词概括**：resident 就是"坐下来的人"——从居民到住院医生到常驻的
- **延伸中心**：从"物理定居"延伸到"专业常驻身份"

> [!check]- 链路验证
> - [x] **可逆性**：从"住院医生"能反向推导到"坐下来的人"——住院医生就是住在医院里的人
> - [x] **可统筹**：一句话——"resident = 坐下来的人→居民→住宿者→住院医生"
> - [x] **有支撑**：local residents, resident doctor, resident expert 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> resident = re-（回）+ sid（坐，[[st-sta-stat]]）+ -ent（人）= "坐下来的人"→ 居民。local residents = 当地居民（在当地"坐下来"的人）。resident doctor = 住院医生（住在医院里的医生）。resident expert = 常驻专家。permanent resident = 永久居民。resident 和 [[residence]]（住所）、[[reside]]（居住）同词族：reside = 坐下来（动词），resident = 坐下来的人（名词），residence = 坐下来的地方（名词）。记住：-ent 后缀通常表示"人"——resident = 居民，student = 学生，president = 总统。
>
> **词拆分记忆**（辅助）：
> re（回）+ sid（sit，坐）+ ent（人）→ 回来坐着的人 → 居民 → resident
