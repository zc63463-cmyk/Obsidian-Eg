# none

> [!info] 基础信息
> **音标** /nʌn/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**pron.** ①==**没有一个，毫无**== `pron`；
**adv.** ①==**毫不，一点也不**== `adv`（the + 比较级 + none + the + 比较级）；
**n.** ①==**没有任何人或物**== `N`

> [!tip] 原型义
> **原型义**：没有一个（not one）
> **延伸维度**：否定-量化扩展
> **隐喻类型**：否定隐喻（"没有一个"→ 毫无→ 毫不）

## 词根词缀

古英语 nan"没有一个"，由 ne（不）+ an（一个）缩合而成。an 就是 one（一个），所以 none = not one = 没有一个。与 [[nonsense]]（无意义的话）同源。
**叙事**：none 是英语中最基本的否定代词，由 ne（不）+ an（一）= nan = none。它的核心逻辑就是"连一个都没有"。none of the students came（没有一个学生来）。none the less（尽管如此）= 少了也不少 = 毫不减少。none too pleased（一点也不高兴）= 没有太多高兴 = 一点也不高兴。none 可以接单数或复数动词，取决于语境。

## 词义链路

> [!abstract]- 词义链路法
> 以"**没有一个**"为统筹中心，沿否定-量化扩展向外扩展：
>
> 1. **没有一个**
>    - → **没有一个，毫无**：基本否定
>      - 激活条件：none of them, none left
>    - → **毫不，一点也不**：副词用法
>      - 激活条件：none the less, none too
>    - → **没有任何人或物**：名词用法
>      - 激活条件：second to none

### 统筹（选择适用的模式）

- **一字一词概括**：none 就是"没有一个"——连一个都没有
- **延伸中心**：从"没有一个"延伸到"毫不"再到固定搭配

> [!check]- 链路验证
> - [x] **可逆性**：从"毫不"能反向推导到"没有一个"——毫不就是"没有一个程度"
> - [x] **可统筹**：一句话——"none 就是没有一个，连一个都没有"
> - [x] **有支撑**：none of them, none the less, second to none 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> none = ne（不）+ one（一）= not one = 没有一个。这是最直观的构词：否定词 + 数词 = 零。none of the above（以上都不是）是选择题的标准选项。none the less（尽管如此）= 少了也不少 = 毫不减少。second to none（不亚于任何人）= 排名第二后面没有 = 第一。none 的核心画面就是"空无一物"。
>
> **拆分记忆**（辅助）：
> n + one = none → 把 one 中的 o 换成 n → 变成"没有"
