# accomplish

> [!info] 基础信息
> **音标** /əˈkʌmplɪʃ/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**v.** ①==**完成，实现**== `V N` [通用]；`V N by V-ing` [正式]；②==**达到（目的）**== `V N` [正式]；③取得成就；

> [!tip] 原型义
> **原型义**：完成到极致（完全做完）
> **延伸维度**：抽象路径
> **隐喻类型**：无显著隐喻，保持"完成"的核心含义

## 词根词缀

[[ac]]-（=ad-，向、加强）+ *complere*（填满、完成，词根 [[plen-pli-plet|plen/pli/plet]]），来自拉丁语 *accomplere*（完成）+ -ish（动词后缀）。字面义为"完全填满"→ "完成"。与 [[complete]]（完成）、[[complement]]（补充）同源。
**叙事**：ac（加强）+ complete（完成）→ 完全完成 → 完成、实现。accomplish a task = 完成任务。accomplish one's goal = 实现目标。accomplish 强调成功完成了某事，带有成就感。

## 词义链路

> [!abstract]- 词义链路法
> 以"**完成到极致**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **完全做完**（动作层面）
>    - → **完成，实现**：成功完成某事
>      - 激活条件：accomplish a task, accomplish a goal
>    - → **取得成就**：完成的结果
>      - 激活条件：an accomplished writer

### 统筹（选择适用的模式）

- **一字一词概括**：accomplish 就是"完成"——成功做完某事
- **延伸中心**：从"完成任务"延伸到"实现目标"再到"取得成就"

> [!check]- 链路验证
> - [x] **可逆性**：从"取得成就"能反向推导到"完成"——成就是完成了了不起的事
> - [x] **可统筹**：一句话——"accomplish 就是从完成到实现再到取得成就"
> - [x] **有支撑**：accomplish a task, accomplish one's goal 均有语料支撑

> accomplish = ac（加强）+ complete（完成）→ 完全完成 → 完成、实现。accomplish a task = 完成任务。accomplish one's purpose = 达到目的。accomplish 比 finish 更正式，强调成功完成。an accomplished fact = 既成事实。an accomplished musician = 有造诣的音乐家。
