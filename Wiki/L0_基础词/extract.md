# extract

> [!info] 基础信息
> **音标** /ɪkˈstrækt/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**提取，抽出**==；②摘录，选取；③榨取，索取；
**n.** ①摘录，选段；②提取物，精华；

> [!tip] 原型义
> **原型义**：向外拉出（从整体中拉出来）
> **延伸维度**：空间路径
> **隐喻类型**：无隐喻（直接物理动作：拉出）

## 词根词缀

ex-(出) + [[tract|tract-]](拉，拖) → 向外拉出
**叙事**：ex（向外）+ tract（拉）→ 向外拉出来 → 提取。牙医把坏牙从牙龈中"向外拉出来"就是 extract a tooth。矿工从矿石中"向外拉出"金属就是 extract metal。作家从长文中"向外拉出"一段话就是 extract a passage。extract 的核心动作就是"从整体中向外拉出"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**向外拉出（从整体中拉出来）**"为统筹中心，沿空间路径向外扩展：
>
> 1. **向外拉出**（物理动作层面）
>    - → **提取，抽出**：从整体中拉出需要的部分
>      - 激活条件：extract a tooth, extract oil
>    - → **摘录，选取**：从文本中拉出片段
>      - 激活条件：extract a passage, extract data
>    - → **榨取，索取**：从某人/某处拉出利益
>      - 激活条件：extract a confession, extract profit
>    - → **摘录，提取物**（名词化）：拉出来的东西
>      - 激活条件：an extract from the novel, plant extract

### 统筹（选择适用的模式）

- **v + 不同宾语**：extract + 牙齿/矿石 → 提取；extract + 文字/数据 → 摘录；extract + 供词/利润 → 榨取
- **延伸中心**：从"物理拉出"延伸到"信息选取"和"利益榨取"

> [!check]- 链路验证
> - [x] **可逆性**：从"榨取利润"能反向推导到"从整体中向外拉出"→"向外拉出"
> - [x] **可统筹**：一句话——"extract 就是从整体中向外拉出你需要的部分"
> - [x] **有支撑**：extract a tooth, extract data 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> ex（向外）+ tract（拉）→ 向外拉出来 → 提取。想象你从一杯咖啡中"向外拉出"咖啡因——这就是 extract caffeine。想象你从一本500页的书里"向外拉出"最精彩的一段——这就是 extract a passage。extract 就是用"拉"的方式从整体中取出你需要的部分。
>
> **词拆分记忆**（辅助）：
> ex（出）+ tract（拖拉机）→ 用拖拉机把东西从地里"拉出来" → 提取
