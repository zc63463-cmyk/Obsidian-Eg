# correct

> [!info] 基础信息
> **音标** /kəˈrekt/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**adj.** ①==**正确的，对的**==；②恰当的，合适的；
**v.** ①==**纠正，改正**==；②校正，校准；

> [!tip] 原型义
> **原型义**：使变直（拉丁语 *corrigere*：com-一起 + regere 引导/使直）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（直→正确——"直的"= "对的"，弯的就是错的）

## 词根词缀

[[cor-cord|cor]]-(=com-, 一起/加强) + [[rect|rect]](直，拉丁语 *regere* 引导/统治)
**叙事**：cor（加强）+ rect（直）→ 使变直 → 纠正。把弯曲的线拉直 = correct。把错误的答案改对 = correct。correct 就是"把弯的弄直"，引申为"把错的改对"。

建议创建词根笔记：rect/reg（直/引导/统治，拉丁语 *regere*）

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**使变直**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **使变直**（物理层面）
>    - → **纠正，改正**：把"弯的"（错误的）改"直"（正确的）
>      - 激活条件：correct mistakes, correct errors
>    - → **正确的**（形容词）：已经"直了"的，对的
>      - 激活条件：the correct answer, correct behavior
>    - → **恰当的，合适的**：行为上"端正的"
>      - 激活条件：correct manners, correct procedure

### 统筹（选择适用的模式）

- **一字一词概括**：correct 就是"直"——使变直=纠正，已经直了=正确，行为端正=恰当
- **延伸中心**：从"物理上的直"延伸到"抽象上的正确"

> [!check]- 链路验证
> - [x] **可逆性**：从"正确的"能反向推导到"直的"——正确的东西就是"不弯的"
> - [x] **可统筹**：一句话——"correct 就是使变直，弯的变直就是纠正，直的就是正确"
> - [x] **有支撑**：correct mistakes, the correct answer 均为高频表达
