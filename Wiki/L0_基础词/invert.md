# invert

> [!info] 基础信息
> **音标** /ɪnˈvɜːt/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**v.** ①==**使倒转，使颠倒**== `invert the order` [学术]；②使反转，使倒置；

> [!tip] 原型义
> **原型义**：使翻转（使朝向反方向，拉丁语 *invertere*，"向内转/翻转"）
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（"翻转"= "颠倒"——空间上的翻转→顺序/逻辑上的颠倒）

## 词根词缀

in-(=intensive，加强语气) + [[ver-vert|vert]](转，拉丁语 *vertere*，转)
**叙事**：in（加强）+ vert（转）→ 使完全转过去 → 使翻转/颠倒。把杯子倒过来——这就是 invert。把句子语序颠倒——这也是 invert。invert 是 [[inverse]]（相反的）的动词形式。

## 词义链路

> [!abstract]- 词义链路法
> 以"**使翻转（使朝向反方向）**"为统筹中心，沿空间路径向外扩展：
>
> 1. **使翻转**（物理层面）
>    - → **使倒转，使颠倒**：使上下或顺序翻转
>      - 激活条件：invert a glass, invert the order
>    - → **使反转，使倒置**：使逻辑或关系翻转
>      - 激活条件：invert the normal pattern

### 统筹（选择适用的模式）

- **v + 不同宾语**：invert + 杯子 = 倒转；invert + 顺序 = 颠倒；invert + 模式 = 反转
- **延伸中心**：从"物理上的翻转"到"顺序上的颠倒"到"模式上的反转"

> [!check]- 链路验证
> - [x] **可逆性**：从"使颠倒"能反向推导到"使翻转"——颠倒顺序就是把原来的顺序翻转过来
> - [x] **可统筹**：一句话——"invert 就是使翻转，翻转杯子、翻转顺序、翻转模式"
> - [x] **有支撑**：invert the order, invert a glass 均有语料支撑
