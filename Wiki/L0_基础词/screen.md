# screen

> [!info] 基础信息
> **音标** /skriːn/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**屏幕，荧光屏**==；②==**筛选，审查**==；③屏风，隔板；④掩蔽物，屏障；⑤（电影）银幕；
**v.** ①==**筛选，审查**==；②遮蔽，掩蔽；③放映（电影）；

> [!tip] 原型义
> **原型义**：用来遮挡或显示的屏障（源自古法语 *escrin*，屏风/遮蔽物，后来引申为显示信息的屏幕）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"物理屏障"→"筛选/审查"——把审查比作一道屏障，挡住不合格的）

## 词根词缀

源自古法语 *escrin*（屏风/箱子），可能与拉丁语 *scrinium*（箱子/容器）有关。属于日耳曼/法语混合来源，与 sc- 前缀（分离/遮挡）有关。
**叙事**：screen → **一道屏障** → 屏风、屏幕。屏风用来遮挡视线——a folding screen。手机屏幕用来显示信息——a phone screen。机场安检筛选旅客——screen passengers。

## 词义链路

> [!abstract]- 词义链路法
> 以"**用来遮挡或显示的屏障**"为统筹中心，沿空间路径向外扩展：
>
> 1. **用来遮挡或显示的屏障**（物理层面）
>    - → **屏幕，荧光屏**：显示信息的屏障
>      - 激活条件：phone screen, computer screen
>    - → **屏风，隔板**：遮挡视线的屏障
>      - 激活条件：a folding screen
>    - → **筛选，审查**：像屏障一样过滤不合格的
>      - 激活条件：screen passengers, screen candidates
>    - → **遮蔽，掩蔽**：用屏障挡住
>      - 激活条件：screen from view

### 统筹（选择适用的模式）

- **一字一词概括**：screen 就是"屏障"——显示信息的屏障叫屏幕，遮挡视线的屏障叫屏风，过滤不合格的屏障叫筛选
- **延伸中心**：从"物理屏障"延伸到"筛选/审查"

> [!check]- 链路验证
> - [x] **可逆性**：从"筛选"能反向推导到"屏障"——筛选就是用屏障过滤
> - [x] **可统筹**：一句话——"screen 就是一道用来遮挡或过滤的屏障"
> - [x] **有支撑**：phone screen, screen passengers 均有语料支撑
