# static

> [!info] 基础信息
> **音标** /ˈstætɪk/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**adj.** ①==**静态的，静止的**==；②不变的，固定的；③静电的；
**n.** ①静电；②静态；

> [!tip] 原型义
> **原型义**：站立不动的（保持静止状态的）
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（"空间上的不动"→"时间上的不变"→"物理上的静电"）

## 词根词缀

[[st-sta-stat]](站立/状态) + -ic(与……有关的，形容词后缀)
**叙事**：stat（站立/状态）+ ic（与……有关的）→ 站立不动的 → 静态的。[[static]] 与 [[station]]（站）和 [[stationary]]（不动的）同源。static electricity（静电）就是"不流动的电"。a static situation（静态的局面）就是"不变化的局面"。记住：static = 站着不动的 = 静态的。

## 词义链路

> [!abstract]- 词义链路法
> 以"**站立不动的**"为统筹中心，沿空间路径向外扩展：
>
> 1. **站立不动的**（空间层面）
>    - → **静态的，静止的**：不运动、不变化的
>      - 激活条件：static data, a static image
>    - → **不变的，固定的**：保持同一状态
>      - 激活条件：static prices, a static population
>    - → **静电的**：不流动的电荷
>      - 激活条件：static electricity, static cling

### 统筹（选择适用的模式）

- **一字一词概括**：static 就是"不动"——空间不动叫"静止"，时间不动叫"不变"，电荷不动叫"静电"
- **延伸中心**：从"空间上的不动"延伸到"时间上的不变"和"物理上的静电"

> [!check]- 链路验证
> - [x] **可逆性**：从"不变的"能反向推导到"站立不动的"——不变就是站着不动
> - [x] **可统筹**：一句话——"static 就是站着不动的，无论空间、时间还是电荷"
> - [x] **有支撑**：static data, static electricity 均有语料支撑
