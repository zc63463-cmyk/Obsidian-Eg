# cloud

> [!info] 基础信息
> **音标** /klaʊd/ | **词级** 基础词 | **语义场** [[自然物理]]

## 核心释义

**n.** ①==**云，云朵**==；②云状物（如尘云、烟云）；③（引申）阴影，阴霾；
**v.** ①使模糊，使蒙上阴影；②使困惑；

> [!tip] 原型义
> **原型义**：天空中聚集的云团（古英语 *clūd*，原义为"岩石/山丘"，后转指天空中的"云团"）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"云遮挡天空"→"阴影/困惑遮挡心灵"——物理遮挡→认知遮挡）

## 词根词缀

来源不明，古英语 *clūd* 原义为"岩石、山丘、团块"，后转义为天空中的"云团"（因为云看起来像山丘一样的团块）
**叙事**：cloud 原来指"山丘/岩石团"，后来人们觉得天上的云看起来像山丘一样的团块，就用来指"云"。云 cloud（遮住）太阳，就产生了阴影。困惑 cloud（蒙上阴影）了你的判断，就像云遮住了天空。

## 词义链路

> [!abstract]- 词义链路法
> 以"**云团（遮挡物）**"为统筹中心，沿空间路径向外扩展：
>
> 1. **天空中的云团**（自然层面）
>    - → **云，云朵**：天空中的水汽团块
>      - 激活条件：dark clouds, rain clouds
>    - → **云状物**：形状像云的东西
>      - 激活条件：cloud of dust, cloud of smoke
>    - → **使模糊，使蒙上阴影**：像云一样遮挡
>      - 激活条件：cloud one's judgment, cloud the issue

### 统筹

- **一字一词概括**：cloud 就是"遮"——云遮天空，阴影遮心情，困惑遮判断
- **一句话统筹**：cloud 就是"像云一样遮挡"——遮天空、遮光线、遮判断

> [!check]- 链路验证
> - [x] **可逆性**：从"使困惑"能反向推导到"云遮挡"——困惑就是认知上的"云遮"
> - [x] **可统筹**：一句话——"cloud 就是从物理遮挡到认知遮挡"
> - [x] **有支撑**：cloud of dust / cloud one's judgment 均为常见用法

## 搭配与短语

> [!example]- 搭配
> - **a cloud of dust/smoke**：一团尘土/烟雾
> - **under a cloud**：受怀疑，失宠
> - **cloud one's judgment**：使某人的判断模糊
> - **on cloud nine**：极度高兴
> - **every cloud has a silver lining**：黑暗中总有一线希望
