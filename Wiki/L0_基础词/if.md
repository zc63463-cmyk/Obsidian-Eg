# if

> [!info] 基础信息
> **音标** /ɪf/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**conj.** ①==**如果，假如**==（引导条件状语从句）；②==**是否**==（引导宾语从句，相当于 whether）；③==**即使，虽然**==（= even if）；
**n.** ①条件，假设（an if）；

> [!tip] 原型义
> **原型义**：如果，假如（源自古英语 *gif* "如果"，原始日耳曼语 *\*jabai*，原始印欧语 *\*h₁ey-* "给予、授予"）
> **延伸维度**：逻辑路径
> **隐喻类型**：空间隐喻（"条件"→"假设"→"是否"→"即使"）

## 词根词缀

if 源自古英语 *gif* "如果"，原始日耳曼语 *\*jabai*。有学者认为它与原始印欧语 *\*h₁ey-* "给予、授予"有关——"如果"本质上是一种"给予条件"的表达。if 是英语中最基本的连词之一，属于虚词/语法词。
**叙事**：if 是最基础的条件连词——"如果"。if 引导条件句（If it rains, I will stay home），也引导宾语从句表示"是否"（I don't know if he will come）。as if = 好像（仿佛）。only if = 只有（条件限定）。even if = 即使（让步条件）。if only = 但愿（虚拟语气）。if and only if = 当且仅当（数学/逻辑用语）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**如果，假如**"为统筹中心，沿逻辑路径向外扩展：
>
> 1. **如果，假如**（条件层面）
>    - → **是否**：引导间接疑问句
>      - 激活条件：I wonder if he will come.
>    - → **即使，虽然**：让步条件
>      - 激活条件：even if it rains, we'll go.
>    - → **好像**：比喻条件
>      - 激活条件：as if nothing happened
>    - → **但愿**：虚拟条件
>      - 激活条件：if only I had known

### 统筹（选择适用的模式）

- **一字一词概括**：if 就是"如果"——条件、是否、即使、好像、但愿
- **一句话统筹**：if 是英语条件逻辑的核心连词，从"如果"延伸出"是否"、"即使"、"好像"等多种用法

> [!check]- 链路验证
> - [x] **可逆性**：从"是否"能反向推导到"如果"——"是否"本质上是一个条件疑问
> - [x] **可统筹**：一句话——"if 就是条件逻辑的一切表达"
> - [x] **有支撑**：if only, as if, even if, only if 均有语料支撑

## 搭配与短语

> [!example]- 搭配 · L3
> - **if only**：但愿，要是……就好了——If only I had more time!
> - **as if**：好像，仿佛——He talks as if he were an expert.
> - **even if**：即使——Even if we fail, we should try.
> - **only if**：只有——You can succeed only if you work hard.
> - **what if**：如果……怎么办——What if it rains tomorrow?

## 真题/语料关联

> [!example]- 语料 · L3
> - "If only the government had taken action earlier, the crisis might have been averted."（如果政府早点采取行动，危机可能就避免了——if only + 虚拟语气为考研写作/翻译高频考点）
> - "The question is not whether we should act, but how."（问题不在于我们是否应该行动，而在于如何行动——whether vs if 的区分在考研中常见）
