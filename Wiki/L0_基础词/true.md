# true

> [!info] 基础信息
> **音标** /truː/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**真实的，真正的**==；②忠实的，忠诚的；③正确的，准确的；
**adv.** ①真正地，确实地；

> [!tip] 原型义
> **原型义**：忠实的（值得信赖的→真实的）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"忠实于承诺"→"符合事实"）

## 词根词缀

true 源自古英语 *trēowe*（忠实的、值得信赖的），原始日耳曼语 *\*treuwaz*（有好信用的），PIE *\*deru-*（坚定、坚实），与 [[tree]]（树，坚实的木头）、[[trust]]（信任）同源。
**叙事**：true 最早的意思不是"真实"而是"忠实"——一个 true 的人就是忠实可靠的人。后来从"忠实于事实"引申为"真实的"。true 和 [[trust]]（信任）同源——你信任一个人因为他 true（忠实）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**忠实**"为统筹中心，沿社会路径向外扩展：
>
> 1. **忠实**（人际关系）
>    - → **忠实的，忠诚的**：对某人/某事忠实
>      - 激活条件：a true friend, remain true to
>    - → **真实的，真正的**：忠实于事实的
>      - 激活条件：true story, true love
>    - → **正确的，准确的**：忠实于标准的
>      - 激活条件：true to form, come true

### 统筹（选择适用的模式）

- **延伸中心**：从"忠实于人"到"忠实于事实"到"忠实于标准"
- **一字一词概括**：true 就是"忠实"——忠实于承诺、事实、标准

> [!check]- 链路验证
> - [x] **可逆性**：从"真实的"能反向推导到"忠实的"——真实就是忠实于事实
> - [x] **可统筹**：一句话——"true 从忠实于人出发，延伸到忠实于事实和标准"
> - [x] **有支撑**：true friend, come true, true to 为考研高频表达

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> true 和 trust（信任）、tree（树）同源，都来自"坚实、坚定"这个核心概念。一棵 true 的树就是坚实的树，一个 true 的朋友就是忠实的朋友。come true（实现）就是梦想变得"忠实于现实"。true 的本义是"忠实"，后来才引申为"真实"。
>
> **词拆分记忆**（辅助）：
> true 本身就是最基础的词，无需拆分。记住"忠实"这个原始含义，所有引申义都围绕"忠实于……"展开。
