# default

> [!info] 基础信息
> **音标** /dɪˈfɔːlt/ | **词级** 基础词 | **语义场** [[资本经济]]

## 核心释义

**n.** ①==**违约，拖欠**==；②==**默认（值）**==；③缺席，不到场；
**v.** ①违约，拖欠（债务）；②默认，预设；
**adv.** ①by default：默认地，缺省地；

> [!tip] 原型义
> **原型义**：缺席（源自古法语 *defaute*，de-（离开）+ faute（过错/缺乏），未能到场/未能履行义务）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"缺席/未履行"→金融违约→计算机默认值→默认行为）

## 词根词缀

[[de]](离开/向下/否定) + faute(过错/缺乏，源自拉丁语 *fallere*，欺骗/失误) → 未能做到 → 缺席/违约
**叙事**：de（离开/未能）+ fault（过错）→ 未能做到 → default。贷款没能按时还就是 default on a loan（违约）。没有特别设置就让系统自动选择就是 by default（默认）。比赛对手没到场你自动获胜就是 win by default（因对手缺席而获胜）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**缺席（未能到场/未能履行）**"为统筹中心，沿社会路径向外扩展：
>
> 1. **缺席/未履行**（行为层面）
>    - → **违约，拖欠**：未能履行金融义务
>      - 激活条件：default on a loan, in default
>    - → **缺席**：未能到场
>      - 激活条件：win by default, judgment by default
>    - → **默认值**：没有特别设置时的"缺席选择"
>      - 激活条件：by default, default setting

### 统筹（选择适用的模式）

- **一字一词概括**：default 就是"没做到"——没还钱叫违约、没到场叫缺席、没设置叫默认
- **延伸中心**：从"未能履行义务"延伸到"金融违约"和"系统默认"

> [!check]- 链路验证
> - [x] **可逆性**：从"默认值"能反向推导到"缺席"——默认值就是"没有特别选择时的缺席选择"
> - [x] **可统筹**：一句话——"default 就是没能做到，无论是还钱、到场还是设置"
> - [x] **有支撑**：default on a loan, win by default, by default 均有语料支撑
