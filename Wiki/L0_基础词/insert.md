# insert

> [!info] 基础信息
> **音标** /ɪnˈsɜːt/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**插入，嵌入**==（把某物放入另一物的内部或中间）；②==**添加，附上**==（在文本中添加内容）；
**n.** ①==**插入物**==（插入到出版物中的附加页或内容）；②（杂志等的）插页；

> [!tip] 原型义
> **原型义**：放入其中（把一物放入另一物的内部）
> **延伸维度**：具身路径
> **隐喻类型**：方位隐喻（"物理插入"→"文本添加"——从空间到语言）

## 词根词缀

源自拉丁语 *insertus*，是 *inserere* 的过去分词，意为"嫁接、植入"。由 [[inter]] 的变体 *in-*（在...之中，来自 PIE *\*en*）+ *serere*（连接在一起、排列、放成一排）构成。*serere* 来自 PIE *\*ser-*（排列、连接），同源词包括 series（系列）、serial（连续的）、assert（断言 = as- + serere）。字面意思是"放入排列之中"→"插入"。
**叙事**：insert 的核心画面是"把一把钥匙插入锁孔"。拉丁语 *inserere* = in（在...之中）+ serere（连接）= 放入连接之中 = 插入。把钥匙插入锁孔——insert a key into the lock。在文本中添加一段话——insert a paragraph。杂志中的插页——an insert。记住 serere = 连接：series（系列 = 连接在一起的东西）、serial（连续的）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**放入其中**"为统筹中心，沿具身路径向外扩展：
>
> 1. **放入其中**（物理层面）
>    - → **插入，嵌入**：把一物放入另一物内部
>      - 激活条件：insert a key, insert a coin
>    - → **添加，附上**：在文本中添加内容
>      - 激活条件：insert a word, insert a paragraph
>    - → **插入物，插页**：被插入的东西
>      - 激活条件：a magazine insert

### 统筹（选择适用的模式）

- **一字一词概括**：insert 就是"插入"——从物理放入到文本添加
- **延伸中心**：从"物理插入"延伸到"文本添加"

> [!check]- 链路验证
> - [x] **可逆性**：从"文本添加"能反向推导到"物理插入"——添加就是"插入"到文本中
> - [x] **可统筹**：一句话——"insert 就是从物理插入到文本添加"
> - [x] **有支撑**：insert a key, insert a paragraph 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> insert = in-（在...之中）+ serere（连接）= 放入连接之中 = 插入。记住 in- = 在...之中（[[inter]] 的变体）：[[insert]]（插入）、[[inside]]（内部）、[[insist]]（坚持 = 站在里面）。serere = 连接：series（系列 = 连接在一起）、serial（连续的）。insert 的核心画面就是"把钥匙插入锁孔"——insert a key into the lock。考研重点：insert into（插入到...中）。
>
> **词拆分记忆**（辅助）：
> insert → in（进入）+ sert（sert 听起来像"塞它"）→ 塞进去 → 插入
