# run

> [!info] 基础信息
> **音标** /rʌn/ | **词频** 考研高频 | **语义场** [[行为动作]]

## 核心释义

**v.** ①==**跑，奔跑**==；②运行，运转；③经营，管理；④（液体）流淌；⑤竞选；
**n.** ①跑步；②连续的一段时间；

> [!tip] 原型义
> **原型义**：快速移动双腿（双脚交替快速前进）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（"快速移动"→机器运转/企业经营/液体流动——一切持续快速进行的状态）

## 词根词缀

run 源自古英语 *rinnan*，*ærnan*，原始日耳曼语 *\*rinnanan*，PIE *\*rei-*（流动、奔跑）。与 [[rival]]（竞争者，同源）、[[river]]（河流，同源）同源。
**叙事**：run 的最基本动作就是"跑"——双脚快速交替前进。河流在跑就是 river，两个人一起跑就是 rival（竞争者），机器在跑就是运行。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**快速移动**"为统筹中心，沿具身路径向外扩展：
>
> 1. **快速移动**（物理层面）
>    - → **运行，运转**：机器/系统"跑起来"
>      - 激活条件：run a machine, run a program
>    - → **经营，管理**：让企业"跑起来"
>      - 激活条件：run a business, run a company
>    - → **流淌**：液体"跑"过表面
>      - 激活条件：water runs down the hill
>    - → **竞选**：在政治赛道上"跑"
>      - 激活条件：run for president

### 统筹（选择适用的模式）

- **v + 不同宾语**：run a race（跑步）→ run a company（经营）→ run a fever（发烧）→ run a risk（冒险）
- **延伸中心**：一切"持续快速进行"的状态都是 run

> [!check]- 链路验证
> - [x] **可逆性**：从"经营"能反向推导到"跑"——经营就是让企业持续运转
> - [x] **可统筹**：一句话——"run 就是一切持续快速进行的状态"
> - [x] **有支撑**：run a business, run for office 均为考研高频表达

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> run 和 river（河流）同源——河流就是大地上"奔跑"的水。从"双脚快速移动"出发，一切持续进行的状态都可以用 run：机器在 run（运行），企业在 run（经营），水在 run（流淌），政治家在 run（竞选）。
>
> **词拆分记忆**（辅助）：
> run 本身就是最基础的词，无需拆分。记住"跑"这个核心动作，所有引申义都是"持续快速进行"的隐喻。
