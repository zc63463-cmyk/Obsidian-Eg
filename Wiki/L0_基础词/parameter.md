# parameter

> [!info] 基础信息
> **音标** /pəˈræmɪtər/ | **词级** 基础词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**参数，参量**==（数学、物理中的变量）`set the parameters` `mathematical parameters` [正式]；②==**界限，范围**== `within certain parameters` `define the parameters` [正式]；③决定因素，特征；

> [!tip] 原型义
> **原型义**：旁边的度量（用来衡量或界定事物的标准或界限）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"度量标准"→"界限范围"——从具体参数到抽象边界）

## 词根词缀

源自现代拉丁语 *parameter*，由 para-（在旁边，希腊语 *para*）+ meter（度量，来自希腊语 *metron*）构成。字面义是"在旁边度量的东西"——即用来衡量或界定事物的参照标准。最初用于数学领域，指方程中的变量参数，后来延伸到"界限、范围"。
**叙事**：para-（在旁边，参见 [[par]]）+ meter（度量）→ **在旁边度量的参照标准** → 参数/界限。在数学中，parameter 是方程中的"参数"——它不直接参与运算，但在旁边"界定"方程的行为。在生活中，parameter 延伸为"界限"——within certain parameters（在一定范围内）。做实验时，你需要设定各种 parameters（参数），确保实验可控。

## 词义链路

> [!abstract]- 词义链路法
> 以"**旁边的度量标准**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **旁边的度量标准（数学层面）**
>    - → **参数，参量**：数学/物理中的变量
>      - 激活条件：set the parameters, mathematical parameters
>    - → **界限，范围**：事物的边界或限制
>      - 激活条件：within certain parameters, define the parameters
>    - → **决定因素，特征**：影响事物的关键因素
>      - 激活条件：key parameters of success

### 统筹（选择适用的模式）

- **一字一词概括**：parameter 就是"参数"——从数学变量到界限范围到决定因素
- **延伸中心**：从"度量标准"延伸到"一切界定事物的参照"

> [!check]- 链路验证
> - [x] **可逆性**：从"界限"能反向推导到"度量标准"——界限本质上就是用参数来度量边界
> - [x] **可统筹**：一句话——"parameter 就是用来界定事物的度量标准"
> - [x] **有支撑**：set the parameters, within parameters 均有语料支撑
