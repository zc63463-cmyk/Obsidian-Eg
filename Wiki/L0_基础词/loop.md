# loop

> [!info] 基础信息
> **音标** /luːp/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**环，圈**==；②回路，循环；③环形道路；
**v.** ①成环形；②使成环；③（计算机）循环执行；

> [!tip] 原型义
> **原型义**：弯曲成环（线弯曲闭合形成环状）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"物理上的环形"→"逻辑上的循环/回路"——空间结构→抽象逻辑）

## 词根词缀

源自中古英语 *loupe*，可能与中古荷兰语 *loupen* "弯腰、跳跃"有关。无前缀后缀，基础词汇。
**叙事**：loop 就是一条线弯曲回来，首尾相连形成环。绳子打个环叫 loop，电流走一圈叫 loop，程序重复执行也叫 loop——因为它们都是"绕回来"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**弯曲成环**"为统筹中心，沿空间路径向外扩展：
>
> 1. **弯曲成环**（物理层面）
>    - → **环，圈**：线或带弯曲闭合形成的形状
>      - 激活条件：a loop of rope
>    - → **回路，循环**：路径闭合，回到起点
>      - 激活条件：a feedback loop, a closed loop
>    - → **环形道路**：道路闭合形成环
>      - 激活条件：the Loop (芝加哥环路)
>    - → **（计算机）循环执行**：程序绕回起点重复执行
>      - 激活条件：a loop in the code

### 统筹（选择适用的模式）

- **一字一词概括**：loop 就是"绕回来"——绳子绕回来叫"环"，电流绕回来叫"回路"，程序绕回来叫"循环"
- **延伸中心**：从"物理上的环形"延伸到"逻辑/系统上的循环"

> [!check]- 链路验证
> - [x] **可逆性**：从"循环"能反向推导到"弯曲成环"——循环就是逻辑上的绕回起点
> - [x] **可统筹**：一句话——"loop 就是绕回来，形成环"
> - [x] **有支撑**：feedback loop（反馈循环）在考研科技/社科阅读中高频出现

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> loop 就是"绕回来"。想象你把一根绳子弯成一个圆圈——这就是 loop。feedback loop（反馈循环）就是信息绕回来。vicious loop（恶性循环）就是坏东西绕回来越变越糟。closed loop（闭环）就是完全绕回来、没有缺口。
>
> **词拆分记忆**（辅助）：
> loop = loo（厕所）+ p → 厕所门绕回来关上 → 环（幽默记忆法）
