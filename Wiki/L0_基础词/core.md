# core

> [!info] 基础信息
> **音标** /kɔː(r)/ | **词级** 基础词 | **语义场** [[自然物理]]

## 核心释义

**n.** ①==**核心，要点**== `the core of the problem / core values` [通用]；②==**果核，果心**== `an apple core` [日常]；③==**（地球的）地核**== `the earth's core` [学术]；
**adj.** ①==**核心的，最重要的**== `core curriculum / core members` [通用]；

> [!tip] 原型义
> **原型义**：果核（果实最中心、最硬的部分）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（果核→核心/要点——像果实有果核一样，事物有最中心最重要的部分）

## 词根词缀

源自古法语 *cor*（心），源自拉丁语 *cor*（心脏），与 [[cord]]（绳/心）、[[cordial]]（热诚的）同源。
**叙事**：core 来自拉丁语"心"（cor）。苹果有果核（core），地球有地核（core），问题有核心（core）。一切事物的"心"就是它的 core。

建议创建词根笔记：cord/cor（心，拉丁语 *cor*/*cordis*）

## 词义链路

> [!abstract]- 词义链路法
> 以"**果核**"为统筹中心，沿空间路径向外扩展：
>
> 1. **果核**（物理层面）
>    - → **核心，要点**：事物的"果核"，最重要的部分
>      - 激活条件：core issue, core values, core curriculum
>    - → **地核**：地球的"果核"，最中心的部分
>      - 激活条件：earth's core, core temperature
>    - → **核心的**（形容词）：属于核心的
>      - 激活条件：core members, core business

### 统筹（选择适用的模式）

- **一字一词概括**：core 就是"心"——果心、核心、地核，都是事物的"心脏"
- **延伸中心**：从"果核"（物理中心）延伸到"核心"（抽象中心）

> [!check]- 链路验证
> - [x] **可逆性**：从"核心问题"能反向推导到"果核"——核心问题就是问题的"果核"
> - [x] **可统筹**：一句话——"core 就是事物的中心，从果核到核心"
> - [x] **有支撑**：core values, core issue, core curriculum 均为考研高频表达
