# rust

> [!info] 基础信息
> **音标** /rʌst/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**铁锈**== `remove rust; gather rust` [中性]；②（植物的）锈病；
**v.** ①==**（使）生锈**== `The lock has rusted; rust away` [中性]；②==**变得荒废/迟钝**== `My skills have rusted` [贬义]；

> [!tip] 原型义
> **原型义**：变红（铁暴露在空气中表面变红）
> **延伸维度**：具身路径
> **隐喻类型**：本体隐喻（"铁生锈"→能力荒废/衰退——像铁一样被腐蚀）

## 词根词缀

rust 源自古英语 *rust*，与 *rudu*（红色）同源，最终追溯至 PIE *\*reudh-*（红色），与 [[red]]（红色）同源。
**叙事**：rust 本义就是"红色"——铁暴露在空气中表面变红，就是铁锈。铁生了锈就变钝了，人也一样，长期不用就"生锈"了（能力衰退）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**铁变红（生锈）**"为统筹中心，沿具身路径向外扩展：
>
> 1. **铁变红**（物理层面）
>    - → **铁锈**：铁表面变红的产物
>      - 激活条件：iron rust, remove rust
>    - → **（使）生锈**：铁变红的过程
>      - 激活条件：The lock has rusted.
>    - → **荒废，迟钝**：像铁生锈一样能力衰退
>      - 激活条件：My skills have rusted.

### 统筹（选择适用的模式）

- **延伸中心**：从"铁生锈"到"能力荒废"
- **一字一词概括**：rust 就是"锈"——铁锈、技能之锈

> [!check]- 链路验证
> - [x] **可逆性**：从"荒废"能反向推导到"生锈"——荒废就是能力生锈
> - [x] **可统筹**：一句话——"rust 就是铁变红生锈，引申为一切因不用而衰退"
> - [x] **有支撑**：skills have rusted 为常见表达

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> rust 和 red（红色）同源——铁锈就是铁变红。一把好刀长期不用就生锈了，人的技能长期不练也会"生锈"（rust）。rust belt（铁锈地带）指美国东北部曾经繁荣的工业区，如今工厂荒废、铁锈斑斑。
>
> **词拆分记忆**（辅助）：
> rust 谐音"拉斯特"→ 拉出来的铁都是锈的 → 铁锈
