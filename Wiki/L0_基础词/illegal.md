# illegal

> [!info] 基础信息
> **音标** /ɪˈliːɡl/ | **词级** 基础词 | **语义场** [[政治法律]]

## 核心释义

**adj.** ①==**非法的，违法的**==；②==**违规的**==（illegal parking）；
**n.** ①==**非法移民**==（口语，the illegals）；

> [!tip] 原型义
> **原型义**：非法的，违法的（源自拉丁语 *illegalis*，il- = 不 + legalis = 合法的）
> **延伸维度**：规范路径
> **隐喻类型**：结构隐喻（"不合法"→"不被允许的"→"违规的"）

## 词根词缀

illegal = il-（= [[in-]]/[[im-]]，否定前缀，在 l 前变为 il-）+ legal（合法的）。legal 源自拉丁语 *legalis* "法律的"，来自 *lex* "法律"。词根笔记见 [[lect-leg]]（leg- = 法律/选择）。il- 是 in-（不）在字母 l 前的同化形式，类似 im-（在 b/p/m 前）、ir-（在 r 前）。
**叙事**：illegal = 不 + 合法的 = 非法的。il- 是 in-（不）的变体，在 l 开头的词前使用（illegal, illogical, illiterate）。legal = 法律的（[[lect-leg]]），所以 illegal = 不合法的。illegal immigration = 非法移民。illegal parking = 违规停车。illegal activities = 非法活动。记住 il- = 不（在 l 前），legal = 合法，illegal = 非法。

## 词义链路

> [!abstract]- 词义链路法
> 以"**非法的，违法的**"为统筹中心，沿规范路径向外扩展：
>
> 1. **非法的，违法的**（法律层面）
>    - → **违规的**：违反具体规定
>      - 激活条件：illegal parking / illegal dumping
>    - → **非法移民**：口语用法
>      - 激活条件：illegal aliens / the illegals

### 统筹（选择适用的模式）

- **一字一词概括**：illegal 就是"不合法"——违法的、违规的
- **一句话统筹**：illegal = il-（不）+ legal（合法的），一切不被法律允许的行为

> [!check]- 链路验证
> - [x] **可逆性**：从"违规停车"能反向推导到"非法"——违规就是违反法律/规定
> - [x] **可统筹**：一句话——"illegal 就是一切不合法的"
> - [x] **有支撑**：illegal immigration, illegal parking, illegal activities 均有语料支撑
