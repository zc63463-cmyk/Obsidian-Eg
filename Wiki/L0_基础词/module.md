# module

> [!info] 基础信息
> **音标** /ˈmɒdjuːl/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**模块，组件**==；②单元，单元课程；③（航天）舱；

> [!tip] 原型义
> **原型义**：小型量度单位（按一定尺度制作的小单元）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"标准小单元"→"可组合的功能模块"）

## 词根词缀

[[mod]](量度/方式/模式) + -ule(小，名词后缀)
**叙事**：mod（量度/尺度）+ ule（小）→ 按标准尺度做的小单元 → 模块。计算机的每个 module（模块）都是按标准尺寸设计的，可以像积木一样自由组合。大学的课程也分成 module（单元），每个 module 都是一个独立的小单元。记住：module = 标准小单元 = 模块。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**小型量度单位**"为统筹中心，沿空间路径向外扩展：
>
> 1. **小型量度单位**（物理层面）
>    - → **模块，组件**：按标准尺度制作的独立功能单元
>      - 激活条件：software module, memory module
>    - → **单元课程**：教学中的独立学习单元
>      - 激活条件：a course module, training module
>    - → **（航天）舱**：太空站中的独立舱段
>      - 激活条件：lunar module, command module

### 统筹（选择适用的模式）

- **一字一词概括**：module 就是"标准小单元"——软件的小单元叫"模块"，课程的小单元叫"单元"，太空站的小单元叫"舱"
- **延伸中心**：从"按标准尺度制作的小东西"延伸到各个领域的"独立功能单元"

> [!check]- 链路验证
