# duplicate

> [!info] 基础信息
> **音标** /ˈdjuːplɪkeɪt/ (v.) /ˈdjuːplɪkət/ (n./adj.) | **词频** 考研中频 | **语义场** [[抽象关系]]

## 核心释义

**v.** ①==**复制，复印**==；②==**重复**==；
**n.** ①==**复制品，副本**==；②完全一样的东西；
**adj.** ①==**完全相同的，复制的**==；②二重的；

> [!tip] 原型义
> **原型义**：折成两份（将一张纸对折变成两份相同的内容）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"对折"→"复制/重复"——物理上的对折动作映射到信息和社会领域的复制行为）

## 词根词缀

[[du-|du-/duo-]](二) + [[plic-plex|plic-/plex-]](折叠) + -ate(动词后缀)。源自拉丁语 *duplicare*（使加倍），来自 *duplus*（双重的）= *duo*（二）+ *plicare*（折叠）。
**叙事**：du（二）+ plic（折叠）+ ate（动词后缀）→ 把一张纸折成两份 → 复制。你把一份文件折成两份，展开后就是两份一模一样的内容——这就是 duplicate。duplicate 的词根就是"二"加"折叠"，本质就是"折成两份=复制"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**折成两份（对折）**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **折成两份**（物理层面）
>    - → **复制，复印**：折成两份→做出一模一样的副本
>      - 激活条件：duplicate a document, duplicate a key
>    - → **重复**：做出完全相同的第二次
>      - 激活条件：duplicate the results, duplicate the effort
>    - → **复制品，副本**：折出来的第二份
>      - 激活条件：a duplicate copy, in duplicate
>    - → **完全相同的**：两份一模一样
>      - 激活条件：a duplicate record

### 统筹（选择适用的模式）

- **一字一词概括**：duplicate 就是"复"——复制、复制品、重复、完全相同
- **延伸中心**：从"折成两份"延伸到"复制→重复→副本"
- **v + 不同宾语**：duplicate + document（复制文件）→ duplicate + results（重复结果）→ duplicate + effort（重复努力）

> [!check]- 链路验证
> - [x] **可逆性**：从"复制品"能反向推导到"折成两份"——副本就是对折出来的第二份
> - [x] **可统筹**：一句话——"duplicate 就是把一份折成两份，得到完全相同的副本"
> - [x] **有支撑**：duplicate a document, in duplicate 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> duplicate = du（二）+ plic（折叠）+ ate。想象你有一份重要合同，律师说"请一式两份"——你把合同折成两份，签两遍，就是 duplicate。duplicate a key 就是"折"出一把一模一样的钥匙。in duplicate 就是一式两份。duplicate 的本质就是"二+折叠"。
>
> **词拆分记忆**（辅助）：
> du（二，联想 double 双倍）+ plic（折叠，联想 complicate 复杂=折叠在一起）+ ate → 折叠两次 → 复制
