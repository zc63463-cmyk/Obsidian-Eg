# script

> [!info] 基础信息
> **音标** /skrɪpt/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**脚本，剧本**==；②==**笔迹，手写体**==；③文字体系，字母表；
**v.** ①==**为……写脚本**==；②照稿子念；

> [!tip] 原型义
> **原型义**：书写下来的东西（源自拉丁语 *scripta*，*scribere* 的过去分词，意为"写下的东西"）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"写下的文字"→"预定的行为模式"——把社会行为比作剧本）

## 词根词缀

[[scrib-script|scrib-/script-]](write, 写) + 无后缀（直接使用过去分词形式）
**叙事**：script → **写下来的东西** → 脚本、笔迹。电影剧本——a film script。医生的笔迹——doctor's script。建议创建词根笔记 [[scrib-script]]。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**书写下来的东西**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **书写下来的东西**（文字层面）
>    - → **脚本，剧本**：表演者要照着念的文本
>      - 激活条件：a film script, write a script
>    - → **笔迹，手写体**：手写下来的文字
>      - 激活条件：doctor's script, neat script
>    - → **文字体系**：一种书写系统
>      - 激活条件：Arabic script, Latin script

### 统筹（选择适用的模式）

- **一字一词概括**：script 就是"写下来的东西"——写下来给演员念的叫剧本，写下来的字迹叫笔迹，写下来的符号系统叫文字
- **延伸中心**：从"写下的文本"延伸到"书写系统"

> [!check]- 链路验证
> - [x] **可逆性**：从"文字体系"能反向推导到"写下来的东西"——文字体系就是被写下来的符号系统
> - [x] **可统筹**：一句话——"script 就是书写下来的任何东西"
> - [x] **有支撑**：film script, doctor's script 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 拉丁语 scripta（写下的东西）→ 英语 script → 脚本。scrib-/script- 词根就是"写"——describe 是"写下来描述"，script 就是"写下来的东西"。电影剧本——a film script。阿拉伯文字体系——Arabic script。
>
> **词拆分记忆**（辅助）：
> script → 联想"写（s）+ 程序（cript）"→ 写程序就是写脚本 → 脚本
