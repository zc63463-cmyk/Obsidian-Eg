# host

> [!info] 基础信息
> **音标** /hoʊst/ | **词级** 基础词 | **语义场** [[社会习俗]]

## 核心释义

**n.** ①==**主人，东道主**== `host country` [通用]；②==**节目主持人**== `TV host` [媒体]；③==**大量，许多**== `a host of N` [书面]；④（寄生物的）==**宿主**== `the host of N` [医学]；
**v.** ①==**主办，做东**== `host N` [通用]；②==**主持**== `host N` [通用]；

> [!tip] 原型义
> **原型义**：主人（接待客人的人，拉丁语 *hospes*）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（将"接待关系"延伸到"主持活动"、"寄生关系"——都是"提供场所/资源的一方"）

## 词根词缀

host 源自拉丁语 *hospes*（主人、客人），与 [[hospitality]]（好客）、[[hostel]]（旅店）、[[hospital]]（医院）同源。
**叙事**：host（主人）→ 接待客人的人 → 主人、东道主。主持节目的人也是 host——他"接待"观众和嘉宾。大量（a host of）来自军队的"主力"→"大量"。寄生物的"宿主"也是 host——它"接待"寄生物。

## 词义链路

> [!abstract]- 词义链路法
> 以"**主人（接待者）**"为统筹中心，沿社会路径向外扩展：
>
> 1. **主人（接待者）**（社会层面）
>    - → **主人，东道主**：接待客人的人
>      - 激活条件：host country, play host to
>    - → **节目主持人**：接待嘉宾和观众的人
>      - 激活条件：TV host, talk show host
>    - → **大量，许多**：军队的主力→大量（词义分化）
>      - 激活条件：a host of problems, a host of
>    - → **宿主**：接待寄生物的生物
>      - 激活条件：the host of the virus

### 统筹（选择适用的模式）

- **一字一词概括**：host 就是"接待者"——接待客人叫"主人"，接待观众叫"主持人"，接待寄生物叫"宿主"
- **延伸中心**：从"接待客人"延伸到"主持活动"和"寄生关系"

> [!check]- 链路验证
> - [x] **可逆性**：从"宿主"能反向推导到"接待者"——宿主就是接待寄生物的"主人"
> - [x] **可统筹**：一句话——"host 就是接待者，接待客人叫主人，接待观众叫主持人，接待寄生物叫宿主"
> - [x] **有支撑**：host country, a host of, TV host 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> host 来自拉丁语 hospes（主人/客人）。你请朋友来家里吃饭，你就是 host（主人）。你主持一档电视节目，你就是 TV host（主持人）。病毒进入你的身体，你就是 virus 的 host（宿主）。host 的核心就是"接待者"——谁在接待，谁就是 host。
>
> **词拆分记忆**（辅助）：
> host = hot（热）+ s → 热情接待客人的主人 → 主人
