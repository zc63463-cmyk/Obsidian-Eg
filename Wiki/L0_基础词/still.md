# still

> [!info] 基础信息
> **音标** /stɪl/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**adj.** ①==**静止的，不动的**==；②平静的，寂静的；
**adv.** ①==**仍然，还**==；②更，还要（表比较）；③静止地；
**n.** ①寂静，平静；②（电影中的）静帧；③蒸馏器；
**v.** ①使平静，使安静；②蒸馏；

> [!tip] 原型义
> **原型义**：静止的，不动的（保持在一个位置不动）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"物理静止"→"时间延续"——空间上的不动→时间上的持续不变）

## 词根词缀

still 源自古英语 *stille*（安静的，静止的），与 [[st-sta-stat]]（站立）词族同源——"站住不动"就是"静止"。属原始日耳曼语词汇，无前缀后缀拆分。
**叙事**：still 和 stand（站立）同源——站住不动就是 still（静止的）。湖水没有一丝波纹，still（平静的）。夜深了，四周 still（寂静的）。时间过去了十年，你 still（仍然）在坚持——"仍然"就是时间上的"不动"，状态没有改变。still 的灵魂就是"不动"——空间上不动叫静止，时间上不动叫仍然。

## 词义链路

> [!abstract]- 词义链路法
> 以"**不动，静止**"为统筹中心，沿空间路径向外扩展：
>
> 1. **不动**（空间层面）
>    - → **静止的，不动的**：身体/物体保持在一个位置
>      - 激活条件：stand still, keep still, still water
>    - → **平静的，寂静的**：环境没有声音的"运动"
>      - 激活条件：the still of the night, still air
>    - → **仍然，还**（adv.）：状态在时间上"不动"——没有改变
>      - 激活条件：still working, still alive, I still remember
>    - → **更，还要**（adv.）：在比较中"不动"——继续增加
>      - 激活条件：still better, still more
>    - → **使平静，使安静**（v.）：使从运动变为不动
>      - 激活条件：still the fears, still the waters

### 统筹（选择适用的模式）

- **一字一词概括**：still 就是"不动"——空间上不动叫静止，时间上不动叫仍然，声音上不动叫寂静
- **延伸中心**：从"空间上的不动"延伸到"时间上的持续"和"声音上的安静"

> [!check]- 链路验证
> - [x] **可逆性**：从"仍然"能反向推导到"不动"——仍然就是状态在时间上没有移动/改变
> - [x] **可统筹**：一句话——"still 就是任何维度上的'不动'——空间、时间、声音"
> - [x] **有支撑**：stand still, I still remember, still waters 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> still 和 stand（站立）同源——站住不动就是 still。你站在湖边，湖面 still（平静的），倒映着天空。十年过去了，你 still（仍然）记得那个下午。still 的核心就是"不动"——身体不动是静止，时间不动是仍然，声音不动是寂静。Still waters run deep（静水流深）——不动的水反而最深。
>
> **词拆分记忆**（辅助）：
> still = st（站立，同源 stand）+ ill → 站着生病了 → 动不了 → 静止的

## 搭配与短语

> [!example]- 搭配
> - **stand/stay still**：站着/保持不动（Stand still while I take the photo.）
> - **still water**：静水（Still waters run deep. 静水流深。）
> - **the still of the night**：夜的寂静
> - **still more/better**：更多/更好（The situation is still more complicated than we thought.）
