# overhaul

> [!info] 基础信息
> **音标** /ˌəʊvəˈhɔːl/ | **词级** 基础词 | **语义场** [[自然物理]]

## 核心释义

**v.** ①==**彻底检修，全面改革**==；
**n.** ①彻底检修；②全面改革；

> [!tip] 原型义
> **原型义**：彻底检修（把机器全部拆开，逐一检查每个部件后重新组装）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（机器检修→制度/体系全面改革）

## 词根词缀

over-(全面/彻底) + haul(拖/拉)
**叙事**：over（全面）+ haul（拖/拉）→ 把机器全部拖出来拆开检查 → 彻底检修。想象修车师傅把发动机整个 haul 出来，over（全面）检查每一个零件——这就是 overhaul。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**彻底检修**"为统筹中心，沿空间路径向外扩展：
>
> 1. **彻底检修**（物理层面）
>    - → **彻底检修（机器/设备）**：拆开检查每个部件
>      - 激活条件：overhaul an engine, overhaul the system
>    - → **全面改革（制度/体系）**：像检修机器一样全面检查改革
>      - 激活条件：overhaul the education system, overhaul the tax code

### 统筹

- **一字一词概括**：overhaul 就是"大拆大检"——拆开机器大检修、拆开制度大改革
- **结构隐喻**：制度/体系是机器，改革就是"彻底检修"
- **延伸中心**：从"机器检修"延伸到"制度全面改革"

> [!check]- 链路验证
> - [x] **可逆性**：从"全面改革"能反向推导到"彻底检修"——改革就像检修机器
> - [x] **可统筹**：一句话——"overhaul 就是把东西全部拆开，彻底检查和翻新"
> - [x] **有支撑**：overhaul the system, overhaul an engine 均有语料支撑
