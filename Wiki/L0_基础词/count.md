# count

> [!info] 基础信息
> **音标** /kaʊnt/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**v.** ①==**数，计算**==；②认为，看作；③有价值，重要；④算数，有效；
**n.** ①计数，总数；②==**伯爵**==（欧洲大陆贵族头衔）；

> [!tip] 原型义
> **原型义**：计算，数数（逐一清点数量）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"数数"→"有价值"→"算数"——被计算的东西才有价值）

## 词根词缀

count 源自拉丁语 *computare*（计算），*com-*（一起）+ *putare*（计算、思考）。进入古法语后简化为 *compter*，再进入英语变为 count。
**叙事**：count（计算）→ 数出来的东西才有价值 → count（重要）→ 数到头的人 → count（伯爵）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**计算，数数**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **计算，数数**（物理动作层面）
>    - → **认为，看作**：在心中"计算"某人的身份
>      - 激活条件：count oneself lucky, I count it a privilege
>    - → **有价值，重要**：被计算的东西才有价值
>      - 激活条件：every vote counts, it counts
>    - → **算数，有效**：计算的结果被认可
>      - 激活条件：that doesn't count
>    - → **伯爵**：在领地上替国王"计算"税收的人
>      - 激活条件：Count Dracula, the Count of Monte Cristo

### 统筹（选择适用的模式）

- **一字一词概括**：count 就是"算"——算数字叫"数数"，算价值叫"重要"，算身份叫"伯爵"
- **延伸中心**：从"逐一计算"延伸到"价值判断"和"身份认定"

> [!check]- 链路验证
> - [x] **可逆性**：从"重要"能反向推导到"计算"——被计算的东西才有价值
> - [x] **可统筹**：一句话——"count 就是算，算数字、算价值、算身份"
> - [x] **有支撑**：every vote counts, count oneself lucky 均有语料支撑
