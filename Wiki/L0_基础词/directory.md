# directory

> [!info] 基础信息
> **音标** /dəˈrektəri/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**目录，号码簿**==；②==**名录，指南**==；③（计算机）目录，文件夹；

> [!tip] 原型义
> **原型义**：引导你找到东西的地方（指引方向的工具）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"指引方向的东西"→目录/号码簿→计算机文件夹）

## 词根词缀

[[dis-di|di]]-(=dis-, 分开/朝向) + [[rect|rect]](引导) + -ory(名词后缀，表场所/集合)
**叙事**：di（朝向）+ rect（引导）+ ory（场所/集合）→ 引导你找到东西的集合→目录。电话簿 directory 引导你找到电话号码，计算机的 directory 引导你找到文件，人名 directory 引导你找到联系人——它们都在 rect（引导）你找到需要的东西。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**引导找到东西的集合**"为统筹中心，沿空间路径向外扩展：
>
> 1. **引导找到东西的集合**（工具层面）
>    - → **目录，号码簿**：引导你找到人名/电话的列表
>      - 激活条件：telephone directory, a directory of services
>    - → **名录，指南**：引导你找到信息/资源的集合
>      - 激活条件：business directory, online directory
>    - → **（计算机）目录，文件夹**：引导你找到文件的层级结构
>      - 激活条件：root directory, file directory

### 统筹

- **一字一词概括**：directory 就是"指路集合"——指电话叫"号码簿"，指文件叫"目录"，指人名叫"名录"
- **延伸中心**：从"指引方向的工具"延伸到各种信息检索工具

> [!check]- 链路验证
> - [x] **可逆性**：从"计算机目录"能反向推导到"引导找到东西"——目录就是引导你找到文件的层级结构
> - [x] **可统筹**：一句话——"directory 就是引导你找到需要的东西的集合"
> - [x] **有支撑**：telephone directory, root directory 均为常见搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> di（朝向）+ rect（引导）+ ory（场所）→ 引导你找到东西的集合。翻开电话 directory，它 rect（引导）你找到朋友的号码；打开电脑 directory，它 rect（引导）你找到保存的文件。directory 就是你的"指路牌集合"。
>
> **词拆分记忆**（辅助）：
> direct（直接）+ ory（图书馆tory）→ 在图书馆里直接找到你要的书→ directory（目录）
