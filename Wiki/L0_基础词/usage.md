# usage

> [!info] 基础信息
> **音标** /ˈjuːsɪdʒ/ | **词频** 考研中频 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**使用，用法**==；②==**惯用法，习语**==；③使用率，利用率；④对待方式；

> [!tip] 原型义
> **原型义**：使用、用法（使用某物的方式或习惯）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"使用物品"→"语言使用习惯""社会对待方式"——物品的使用→语言的使用→人的使用）

## 词根词缀

use(使用) + -age(名词后缀，表示状态/行为/结果)
**叙事**：use（使用）+ age（名词后缀）→ **使用的方式/状态** → 用法、惯用法。usage 最初就是"使用的方式"。语言也有 usage——English usage（英语惯用法）。人对人的 usage 也可以指"对待"——rough usage（粗暴对待）。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**使用、用法**"为统筹中心，沿社会路径向外扩展：
>
> 1. **使用、用法**（物品层面）
>    - → **使用方式**：使用某物的方法
>      - 激活条件：water usage, energy usage
>    - → **语言惯用法**：语言使用的习惯
>      - 激活条件：English usage, modern usage
>    - → **对待方式**：对待人的方式
>      - 激活条件：rough usage, fair usage

### 统筹（选择适用的模式）

- **一字一词概括**：usage 就是"用法"——物品的用法、语言的用法、人的用法
- **延伸中心**：从"物品使用"延伸到"语言惯用"和"社会对待"

> [!check]- 链路验证
> - [x] **可逆性**：从"语言惯用法"能反向推导到"使用"——惯用法就是语言的使用方式
> - [x] **可统筹**：一句话——"usage 就是使用的方式和习惯"
> - [x] **有支撑**：water usage, English usage 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> use（使用）+ age → usage。你 use 水的方式就是 water usage（用水量）。你 use 英语的方式就是 English usage（英语惯用法）。别人 use 你的方式就是他对你的 usage（对待方式）。use 是动作，usage 是方式和习惯。
>
> **词拆分记忆**（辅助）：
> use（使用）+ age（名词后缀）→ 使用的方式 → 用法
