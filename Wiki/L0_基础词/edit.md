# edit

> [!info] 基础信息
> **音标** /ˈedɪt/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**v.** ①==**编辑，编校**== `\edit a manuscript/book` [中性/专业]；②==**剪辑**== `\edit a film/video` [中性/专业]；③主编（担任……的编辑）；

> [!tip] 原型义
> **原型义**：把作品呈现出来——编辑、修订
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"向外呈现"→"为出版而修订"——从"拿出"到"精心打磨后发表"）

## 词根词缀

源自拉丁语 *edere*（e- = out 向外 + -dere = put 放置/给予），字面意思是"向外放、拿出来、呈现出来"。*edere* 的过去分词是 *editus*（已呈现的）。1791年英语中 edit 作为动词首次出现，最初意思是"出版"，后来演变为"为出版而编辑修订"。同源词包括 [[edition]]（版本）、[[editor]]（编辑）、[[editorial]]（社论的）。*edere* 中的 *dare*（给予）与 [[date]]（日期，"给予"的时间）、[[donate]]（捐赠）同源。

**叙事**：edit 的核心动作是"向外呈现"（e- + dere）。古罗马的作者完成作品后，需要把作品"拿出来"呈现给世人——这就是 *edere*。但"拿出来"之前，必须先精心打磨、修改、校订，确保内容准确、语言流畅。于是 edit 从"出版"演变为"编辑修订"——在呈现给世人之前对文稿进行修改和完善。今天我们 edit 一篇文章、edit 一部电影、edit 一张照片，本质上都是在"打磨后呈现"。edit 的灵魂是"精心打磨后呈现给世人"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**把作品呈现出来——编辑、修订**"为统筹中心，沿社会路径向外扩展：
>
> 1. **向外呈现**（行为层面）
>    - → **编辑，编校**：为出版而修改、校订文稿
>      - 激活条件：edit a manuscript, edit a book
>    - → **剪辑**：电影、录音等的编辑处理
>      - 激活条件：edit a film, edit a video
>    - → **主编**：担任……的编辑
>      - 激活条件：edit a journal, edit a newspaper

### 统筹（选择适用的模式）

- **一字一词概括**：edit 就是"编辑"——精心打磨后呈现给世人
- **延伸中心**：从"向外呈现"到"修改校订"再到"多媒体剪辑"

> [!check]- 链路验证
> - [x] **可逆性**：从"编辑"能反向推导到"向外呈现"——编辑就是打磨后呈现
> - [x] **可统筹**：一句话——"edit 就是从向外呈现到精心打磨后发表"
> - [x] **有支撑**：edit a manuscript, edit a film 均有语料支撑

## 搭配与短语

> [!example]- 搭配
> - **edit a manuscript / book**：编辑手稿/书
> - **edit a film / video**：剪辑电影/视频
> - **edit out**：删去，剪辑掉
> - **edit a journal / newspaper**：主编期刊/报纸
