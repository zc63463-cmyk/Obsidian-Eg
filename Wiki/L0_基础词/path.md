# path

> [!info] 基础信息
> **音标** /pɑːθ/ | **词级** 基础词 | **语义场** [[自然物理]]

## 核心释义

**n.** ①==**小路，小径**==；②路线，路径；③==**道路，途径**==（抽象）；

> [!tip] 原型义
> **原型义**：走过的小路（源自拉丁语 *passus*，步/步伐，与 pass 同源）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"物理路径"→"人生道路/发展途径"——空间上的路→抽象的路）

## 词根词缀

源自拉丁语 *passus*（步/步伐），与 [[pass]]（经过）同源
**叙事**：path 就是被脚步踩出来的小路。你走多了，自然就形成了path。从物理的小路延伸到抽象的"道路"——career path（职业道路），the path to success（成功之路）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**走过的小路**"为统筹中心，沿空间路径向外扩展：
>
> 1. **走过的小路**（物理层面）
>    - → **小路，小径**：被人踩出来的窄路
>      - 激活条件：a narrow path through the forest
>    - → **路线，路径**：行进的路线或轨迹
>      - 激活条件：career path, flight path
>    - → **道路，途径**（抽象）：达到目标的抽象路径
>      - 激活条件：the path to success, parallel paths

### 统筹（选择适用的模式）

- **延伸中心**：path 的核心特征是"路"——从物理的路→抽象的路
- **一句话统筹**：path 就是从A到B的路——可以是林间小路，也可以是人生道路

> [!check]- 链路验证
> - [x] **可逆性**：从"成功之路"能反向推导到"走过的小路"——成功之路就是通往成功的路
> - [x] **可统筹**：一句话——"path 就是从A到B的路"
> - [x] **有支撑**：career path, the path to success, parallel paths 均有语料支撑
