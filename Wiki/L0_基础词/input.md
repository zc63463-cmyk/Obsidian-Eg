# input

> [!info] 基础信息
> **音标** /ˈɪnpʊt/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**输入，投入**==；②输入的数据/信息/资源；③（电子）输入端；
**v.** ①==**输入，录入**==；

> [!tip] 原型义
> **原型义**：放进去（把东西放入某处）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"放入"→"信息/资源的投入"——将抽象的投入概念化为物理上的放入）

## 词根词缀

in-(进入) + [[put|put-]](放置，放)
**叙事**：in（进入）+ put（放）→ 放进去 → 输入。你在键盘上打字就是把信息放进去——input data。你对一段关系投入时间和精力——input time and energy。input 就是"放进去"。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**放进去**"为统筹中心，沿空间路径向外扩展：
>
> 1. **放进去**（动作层面）
>    - → **输入，录入**：将数据/信息放入系统
>      - 激活条件：input data, input information
>    - → **输入的数据/信息/资源**：放进去的东西本身
>      - 激活条件：the input was incorrect
>    - → **投入**：将时间、精力等放入某事
>      - 激活条件：input of time and effort

### 统筹（选择适用的模式）

- **一字一词概括**：input 就是"放进"——把数据放进电脑叫"输入"，把精力放进项目叫"投入"
- **v + 不同宾语**：input data（输入数据）→ input time（投入时间）→ input information（输入信息）

> [!check]- 链路验证
> - [x] **可逆性**：从"投入"能反向推导到"放进去"——投入就是把精力放进去
> - [x] **可统筹**：一句话——"input 就是把东西放进去，可以是数据，也可以是精力"
> - [x] **有支撑**：input data, input of resources 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> in（进入）+ put（放）→ 放进去 → 输入。你在电脑前 input 数据，就是把信息放进去。老师说你需要更多 input，就是你需要投入更多时间和精力。output 是"放出来"，input 是"放进去"——一进一出。
>
> **词拆分记忆**（辅助）：
> in（进入）+ put（放置）→ 放进去 → 输入/投入
