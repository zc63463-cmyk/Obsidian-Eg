# buffer

> [!info] 基础信息
> **音标** /ˈbʌfə/ | **词频** 考研中频 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**缓冲器，缓冲物**==；②缓冲区（计算机）；③缓冲人/物；
**v.** ①==**缓冲，减轻**==；②保护...免受冲击；

> [!tip] 原型义
> **原型义**：缓冲物（放在两物之间减轻碰撞的东西）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"buffer against stress"——将心理压力类比为物理冲击）

## 词根词缀

buffer（源自动词 *buff*（撞击、弹起），或来自古法语 *buffe*（打击），与 [[buffet]] 同源）
**叙事**：buffer 是一个"挡箭牌"——放在两个会碰撞的东西之间，吸收冲击力。汽车保险杠是 buffer，计算机内存里的缓冲区也是 buffer（缓冲数据传输），人际关系中的"缓冲人"还是 buffer。buffer 的核心功能就是"吸收冲击、减轻碰撞"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**缓冲物**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **缓冲物**（物理层面）
>    - → **缓冲器**：减轻物理碰撞的装置
>      - 激活条件：shock buffer, buffer zone
>    - → **缓冲区**：计算机中临时存储数据的区域
>      - 激活条件：data buffer, memory buffer
>    - → **缓冲，减轻**：减轻冲击/压力
>      - 激活条件：buffer against the shock, buffer the impact

### 统筹（选择适用的模式）

- **一字一词概括**：buffer 就是"缓冲"——物理缓冲、数据缓冲、心理缓冲
- **延伸中心**：从"物理缓冲器"延伸到"数据缓冲区"再到"心理缓冲"

> [!check]- 链路验证
> - [x] **可逆性**：从"心理缓冲"能反向推导到"物理缓冲物"——心理缓冲就是放在压力和心灵之间的"缓冲器"
> - [x] **可统筹**：一句话——"buffer 就是放在中间减轻冲击的东西"
> - [x] **有支撑**：buffer zone, buffer against 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> buffer 来自 buff（撞击、弹起）。想象两辆汽车相撞，中间有一个充气的 buffer 吸收了冲击力——这就是缓冲器。计算机世界里，数据从硬盘传到内存也需要一个"中转站"来缓冲速度差异——那就是 buffer（缓冲区）。在人际关系中，一个调解矛盾的人也是 buffer——他缓冲了双方的冲突。
>
> **音意关联**（辅助）：
> buffer 发音 /ˈbʌfə/，像"巴佛"——一个叫"巴佛"的大力士站在中间，帮你挡住冲击。
