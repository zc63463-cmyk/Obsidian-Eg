# scenario

> [!info] 基础信息
> **音标** /sɪˈnɑːriəʊ/ | **词级** 基础词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**（可能发生的）情景，局面**==（对可能发生之事的描述或设想）；②==**剧本，脚本**==（电影、戏剧等的情节概要）；③方案，预测；

> [!tip] 原型义
> **原型义**：舞台上的布景——假想的场景
> **延伸维度**：符号路径
> **隐喻类型**：结构隐喻（"戏剧舞台的布景"→"假想的未来情景"——从戏剧到现实预测）

## 词根词缀

源自意大利语 *scenario*（舞台布景），来自拉丁语 *scaena*（舞台），最终追溯到希腊语 *skēnē*（帐篷、舞台布景）。*skēnē* 与希腊语 *skia*（影子、阴影）同源——舞台最初就是一个能投射影子的帐篷。同源词包括 [[scene]]（场景、场面）、[[scenery]]（风景、舞台布景）、[[obscene]]（淫秽的，"偏离舞台"→不该在舞台上展示的）。

**叙事**：古希腊的露天剧场里，演员需要一个换装和休息的地方，于是搭了一个帐篷——这就是 *skēnē*。后来这个帐篷变成了舞台的背景墙，上面画着各种布景。到了意大利文艺复兴时期，剧作家们把整部戏的情节概要写成文字，标注每个场景的布景安排，这份文件就叫 *scenario*（剧本/脚本）。再后来，scenario 从戏剧领域走入了商业和政治领域——人们开始把"对未来的设想"也叫做 scenario，因为预测未来就像在舞台上布置布景一样，都是"假想一个场景"。The worst-case scenario = 最坏的情况。a possible scenario = 一种可能的情景。scenario 的灵魂是"假想的场景"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**舞台上的布景——假想的场景**"为统筹中心，沿符号路径向外扩展：
>
> 1. **舞台布景**（物理层面）
>    - → **剧本，脚本**：描述舞台场景的文字概要
>      - 激活条件：film scenario, write a scenario
>    - → **（可能发生的）情景，局面**：对未来的假想场景
>      - 激活条件：worst-case scenario, a possible scenario
>    - → **方案，预测**：对事态发展的设想
>      - 激活条件：scenario planning, scenario analysis

### 统筹（选择适用的模式）

- **一字一词概括**：scenario 就是"假想场景"——从戏剧布景到未来预测
- **延伸中心**：从"舞台布景"延伸到"剧本概要"再到"未来情景设想"

> [!check]- 链路验证
> - [x] **可逆性**：从"情景"能反向推导到"舞台布景"——情景就是假想的舞台场景
> - [x] **可统筹**：一句话——"scenario 就是从舞台布景到假想的未来情景"
> - [x] **有支撑**：worst-case scenario, scenario planning 均有语料支撑

## 搭配与短语

> [!example]- 搭配 · L3
> - **worst-case scenario**：最坏的情况
> - **best-case scenario**：最好的情况
> - **a possible / likely scenario**：一种可能/可能的情景
> - **scenario planning / analysis**：情景规划/分析
> - **under this scenario**：在这种情况下
