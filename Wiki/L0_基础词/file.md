# file

> [!info] 基础信息
> **音标** /faɪl/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**文件，档案**== `N` [通用]；②==**文件夹**== `N folder` [通用]；③==**纵列**== `in single N` [通用]；④==**锉刀**== `N` [通用]；
**v.** ①==**归档，存档**== `V N` [通用]；②==**提出（申请/诉讼）**== `V a lawsuit` [法律]；③==**锉平**== `V N` [通用]；

> [!tip] 原型义
> **原型义**：用线串起来的文件（档案）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（把"纵列"隐喻为"像文件一样排列的线条"）

## 词根词缀

file 源自拉丁语 *filum*（线、丝），原指用线把文件串起来保存。与 [[fiber]]（纤维）的拉丁语源 *fibra* 可能同源。
**叙事**：fil（线）→ 用线把文件串起来 → file（档案）。古代人用线把文件串起来归档保存，所以 file 既是"文件"也是"归档"的动作。计算机里的 file（文件）也沿用了这个概念。

建议创建词根笔记 [[fil-filum]]（线/丝，拉丁语 *filum*）

## 词义链路

> [!abstract]- 词义链路法
> 以"**用线串起来的文件**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **用线串起来的文件**（物质层面→抽象层面）
>    - → **文件，档案**：保存信息的载体
>      - 激活条件：computer file, keep on file
>    - → **文件夹**：存放文件的容器
>      - 激活条件：file folder
>    - → **归档，存档**：把文件分类保存
>      - 激活条件：file a document, file away
>    - → **提出（申请/诉讼）**：向官方提交文件
>      - 激活条件：file a lawsuit, file a claim
>    - → **纵列**：像线一样排列的一行
>      - 激活条件：single file, in file
>    - → **锉刀**：用于磨平的工具（来自古法语 *fil*，与"线"无关的独立词源）
>      - 激活条件：nail file

### 统筹（选择适用的模式）

- **一字一词概括**：file 就是"文件"——纸上的文件叫档案，电脑里的文件叫 file，提交文件叫归档，排成一条线叫纵列
- **延伸中心**：从"纸质文件"延伸到"电子文件"再到"提交文件的动作"

> [!check]- 链路验证
> - [x] **可逆性**：从"提出诉讼"能反向推导到"文件"——提出诉讼就是向法院提交文件
> - [x] **可统筹**：一句话——"file 就是一切与文件相关的载体和操作"
> - [x] **有支撑**：file a lawsuit, computer file, on file 均有真题支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> file 来自拉丁语 filum（线）。古人用线把文件串起来归档 → file（档案）。电脑里的 file（文件）也是这个概念。file a lawsuit（提出诉讼）就是向法院提交文件。in single file（排成一列纵队）就像文件排成一条线。
>
> **词拆分记忆**（辅助）：
> fi（联想"fire"火）+ le（联想"乐"）→ 火烧文件要赶紧归档 → 文件
