# linear

> [!info] 基础信息
> **音标** /ˈlɪniə(r)/ | **词级** 基础词 | **语义场** [[理性世界]]

## 核心释义

**adj.** ①==**线的，直线的**==；②==**线性的**==（数学/物理）；③长度的；

> [!tip] 原型义
> **原型义**：线的（像线一样直的，沿一条线展开的）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"像线一样"→ 直线的 / 线性的 / 逐步递进的）

## 词根词缀

lin(线，拉丁语 *linea*) + -ear(形容词后缀，表示"属于……的")
**叙事**：lin（线）+ -ear（……的）→ 属于线的 → 像线一样直的 → 线性的。从拉丁语 *linea*（亚麻线）而来。linear thinking = 像线一样一条路走到黑的思维方式。建议创建词根笔记 [[lin]]。

## 词义链路

> [!abstract]- 词义链路法
> 以"**线的**"为统筹中心，沿空间路径向外扩展：
>
> 1. **线的**（空间层面）
>    - → **线的，直线的**：像线一样直的
>      - 激活条件：linear motion, linear design
>    - → **线性的**：沿一条线逐步展开的（数学/逻辑）
>      - 激活条件：linear equation, linear thinking
>    - → **长度的**：与线（长度）相关的
>      - 激活条件：linear dimensions

### 统筹（选择适用的模式）

- **一字一词概括**：linear 就是"线的"——像线一样直的叫"直线的"，像线一样逐步展开的叫"线性的"
- **延伸中心**：从"线的形状"延伸到"线性的关系"和"线性的思维"

> [!check]- 链路验证
> - [x] **可逆性**：从"线性思维"能反向推导到"线的"——像线一样一条路走到黑
> - [x] **可统筹**：一句话——"linear 就是一切与线相关的"
> - [x] **有支撑**：linear equation, linear motion 均有语料支撑
