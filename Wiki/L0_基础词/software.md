# software

> [!info] 基础信息
> **音标** /ˈsɒftweə(r)/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**软件**==（计算机程序和数据的总称，与硬件相对）；

> [!tip] 原型义
> **原型义**：软的货物（相对于硬件而言的计算机程序和数据）
> **延伸维度**：具身路径
> **隐喻类型**：方位隐喻（"有形的物理部件"→"无形的数据程序"——从硬件到软件）

## 词根词缀

software 是一个复合词，由 **soft**（软的）+ **ware**（货物、商品）构成。*ware* 源自古英语 *waru*（货物、商品），常见于 hardware（硬件）、glassware（玻璃器皿）、silverware（银器）等词。1960年代计算机科学发展初期，人们将计算机的物理部件称为 **hardware**（硬件），与之相对，程序和数据被称为 **software**（软件），因为它们是"看不见摸不着"的"软"的部分。
**叙事**：software 的核心画面是"计算机里看不见摸不着的程序"。计算机有两部分：hardware（硬件）是你可以触摸的物理部件——键盘、屏幕、芯片；software（软件）是你看不见的程序和数据——操作系统、应用程序。就像一个商店里，hardware 是货架和柜台（硬的），software 是里面的商品（软的货物）。这个词是1960年代才被创造出来的，是计算机时代最成功的造词之一。

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> software = soft（软的）+ ware（货物）= 软的货物 = 软件。计算机有硬件（hardware = hard 硬的 + ware 货物）和软件（software = soft 软的 + ware 货物）。硬件是键盘、芯片这些"硬"的东西，软件是程序、数据这些"软"的东西。记住 ware = 货物：glassware（玻璃器皿）、silverware（银器）、ironware（铁器）。
>
> **词拆分记忆**（辅助）：
> software → soft（软）+ ware（货物）→ 软的货物 → 软件
