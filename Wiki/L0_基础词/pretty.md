# pretty

> [!info] 基础信息
> **音标** /ˈprɪti/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**adj.** ①==**漂亮的，俏丽的**==；②相当大的，相当好的（a pretty sum）；
**adv.** ①相当，颇（pretty good）；②

> [!tip] 原型义
> **原型义**：精巧的（制作精巧的）
> **延伸维度**：抽象路径
> **隐喻类型**：本体隐喻（"精巧的"→"漂亮的"→"相当大的"）

## 词根词缀

源自古英语 *prættig*（精巧的，狡猾的），与 prat（把戏/花招）有关
**叙事**：pretty 最初不是"漂亮"的意思，而是"精巧的、巧妙的"。一个精巧的工艺品就是 pretty，后来延伸为"漂亮的"。再后来，pretty 从形容词虚化为副词，表示"相当、颇"——a pretty good job（相当好的工作）。记住：pretty = 精巧的 → 漂亮的 → 相当的。

## 词义链路

> [!abstract]- 词义链路法
> 以"**精巧的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **精巧的**（工艺层面）
>    - → **漂亮的，俏丽的**：精巧的东西看起来漂亮
>      - 激活条件：a pretty girl, a pretty dress
>    - → **相当大的/好的**：从"精巧的"虚化为强调程度
>      - 激活条件：a pretty sum of money, a pretty mess
>    - → **相当，颇**（adv.）：进一步虚化为程度副词
>      - 激活条件：pretty good, pretty sure

### 统筹（选择适用的模式）

- **一字一词概括**：pretty 就是"相当"——pretty girl（相当漂亮的女孩），pretty good（相当好）
- **延伸中心**：从"精巧的"到"漂亮的"再到"相当"——词义虚化路径

> [!check]- 链路验证
> - [x] **可逆性**：从"相当"能反向推导到"精巧的"——"相当"是"精巧"的虚化结果
> - [x] **可统筹**：一句话——"pretty 从精巧到漂亮再到相当，一路虚化"
> - [x] **有支撑**：pretty good, pretty sure 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> pretty 最初的意思是"精巧的"——一件精巧的工艺品让人赞叹。后来"精巧的"变成了"漂亮的"，再后来"漂亮的"虚化为"相当"。a pretty girl = 相当漂亮的女孩，pretty good = 相当好。记住：pretty 的核心不是"漂亮"而是"精巧"——精巧到令人赞叹的程度就是"相当"。
>
> **词拆分记忆**（辅助）：
> pret（prat，把戏/花招）+ ty → 精巧的花招 → 精巧的 → 漂亮的 → 相当
