# rest

> [!info] 基础信息
> **音标** /rest/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**休息，放松**== `\take a ~ / get some ~\` [通用]；②==**依赖，寄托**== `\~ on / ~ with\` [通用]；③==**放置，搁**==；
**n.** ①==**休息**== `\have/take a ~\` [通用]；②==**其余的人/物**== `\the ~ of\` [通用]；③==**静止，安宁**==；

> [!tip] 原型义
> **原型义**：停下来休息（停止活动以恢复体力）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（"停止活动"→"依赖/其余/静止"——从身体休息到抽象依赖）

## 词根词缀

源自古英语 *ræst*（休息、床），与古高地德语 *ruasta*（休息）同源，来自原始日耳曼语 *\*rasto*（休息、一段距离）。原始印欧语词根可能与 *\*ros-*（休息）有关。注意：rest（休息）与 rest（其余，the rest）在英语中是同一个词的不同义项——"其余"来自"留下来的部分"（停下来不动的部分）。
**叙事**：rest 的核心画面是"劳动后停下来恢复体力"。古英语 *ræst* = 休息 = 停下来。当你走累了，停下来坐一会儿——这就是 rest。Rest on the table（放在桌上）= 让物体"停下来"。The argument rests on evidence（论点依赖于证据）= 论点"停靠"在证据上。The rest of the students（其余的学生）= 留下来不动的部分。

## 词义链路

> [!abstract]- 词义链路法
> 以"**停下来休息**"为统筹中心，沿具身路径向外扩展：
>
> 1. **停止活动**（物理层面）
>    - → **休息，放松**：身体停下来恢复
>      - 激活条件：take a rest, rest assured
>    - → **放置，搁**：让物体停下来
>      - 激活条件：rest on the table, rest one's eyes
>    - → **依赖，寄托**：思维"停靠"在某处
>      - 激活条件：rest on, rest with
>    - → **其余的**：留下来不动的部分
>      - 激活条件：the rest of, for the rest

### 统筹（选择适用的模式）

- **一字一词概括**：rest 就是"停下来"——从休息到依赖到其余
- **延伸中心**：从"身体停止"延伸到"思维停靠"和"留下来的部分"

> [!check]- 链路验证
> - [x] **可逆性**：从"依赖"能反向推导到"停下来"——依赖就是思维"停靠"在某处
> - [x] **可统筹**：一句话——"rest 就是从停下来休息到依赖到其余"
> - [x] **有支撑**：take a rest, rest on evidence, the rest of 均有语料支撑
