# acquaint

> [!info] 基础信息
> **音标** /əˈkweɪnt/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**v.** ①==**使认识，使了解**== `V N with N` [正式]；`V oneself with N` [正式]；②==**通知，告知**== `V N with N` [正式]；

> [!tip] 原型义
> **原型义**：使彼此认识（从陌生到熟悉的过渡）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（"人与人之间的认识"→"对事物的了解"——从社交到认知）

## 词根词缀

源自古法语 *acointer*（使认识），来自拉丁语 *ad*（朝向、去）+ *cognitus*（认识的、已知的），*cognitus* 是 *cognoscere*（认识、知道）的过去分词。其中 *ad-* 演变为 *ac-*（同化），*cognitus* 演变为 *quaint*。与 [[cognition]]（认知）、[[recognize]]（认出）同源。
**叙事**：acquaint 的核心画面是"介绍两个陌生人互相认识"。拉丁语 *ad* + *cognitus* = 朝向 + 已知的 = 使认识。I'll acquaint you with the facts = 我将使你了解事实。acquaint yourself with the rules = 使你自己熟悉规则。acquaint 的核心是"从陌生到熟悉"的过渡——让本来不认识的人或事物变得"已知"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**使彼此认识**"为统筹中心，沿社会路径向外扩展：
>
> 1. **使认识**（社交层面）
>    - → **使了解，使熟悉**：让人对某事物从不认识到了解
>      - 激活条件：acquaint oneself with, be acquainted with
>    - → **通知，告知**：正式告知某人某事
>      - 激活条件：acquaint sb. with the fact

### 统筹（选择适用的模式）

- **一字一词概括**：acquaint 就是"使了解"——从陌生到熟悉的桥梁
- **v + 不同宾语**：acquaint 人 with 事实→使了解；acquaint oneself with 规则→使自己熟悉

> [!check]- 链路验证
> - [x] **可逆性**：从"通知"能反向推导到"使认识"——通知就是让某人"认识"某事
> - [x] **可统筹**：一句话——"acquaint 就是从使人与人认识到使人对事物了解"
> - [x] **有支撑**：acquaint oneself with, be acquainted with 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> acquaint = ac（朝向）+ quaint（已知的）= 使认识。拉丁语 *ad* + *cognitus* = 朝向 + 已知的 = 让某人走向已知 = 使了解。想象一个聚会场景，主人把两个陌生人拉到一起说"Let me acquaint you with each other"——让我介绍你们认识。acquaint 的核心是"从陌生到熟悉"的过渡。常用被动语态：be acquainted with = 与……相识，了解。
>
> **词拆分记忆**（辅助）：
> acquaint → ac（一再）+ quaint（古怪的）→ 一再接触古怪的人 → 逐渐了解他
