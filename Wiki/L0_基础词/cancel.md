# cancel

> [!info] 基础信息
> **音标** /ˈkænsəl/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**vt.** ①==**取消，撤销**==；②废除，删去；③抵消，中和；
**vi.** ①取消；②相互抵消；
**n.** ①取消，撤销；

> [!tip] 原型义
> **原型义**：取消（划掉、使无效）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"划掉"= 使事物从存在变为不存在 → 从划掉文字到取消计划）

## 词根词缀

cancel 源自拉丁语 *cancellare*（画格子、划掉），来自 *cancelli*（格栅、格子架）。原义是在文件上画交叉线表示"作废"。
**叙事**：cancelli（格栅）→ 在文件上画交叉线 → **划掉、使无效** → 取消。想象在一份合同上画一个大大的"X"——这份合同就被 cancel 了。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**取消（划掉、使无效）**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **取消**（行为层面）
>    - → **撤销**：取消已经决定的事
>      - 激活条件：cancel a meeting, cancel an order
>    - → **废除，删去**：从文本中划掉
>      - 激活条件：cancel a word, cancel a clause
>    - → **抵消，中和**：数学/物理上的相互消除
>      - 激活条件：cancel each other out, cancel out

### 统筹（选择适用的模式）

- **一字一词概括**：cancel 就是"消"——取消是消除计划，抵消是消除效果
- **延伸中心**：从"取消计划/事件"延伸到"废除条款"和"相互抵消"

> [!check]- 链路验证
> - [x] **可逆性**：从"抵消"能反向推导到"取消"——抵消就是两个量相互取消
> - [x] **可统筹**：一句话——"cancel 就是通过划掉使事物从存在变为不存在，从计划到条款到数值"
> - [x] **有支撑**：cancel a meeting, cancel each other out 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> cancel 来自拉丁语 *cancellare*，原义是"画格栅"。古人在作废的文件上画交叉线（像格栅一样），表示这份文件不再有效——这就是 cancel。所以 cancel 的核心画面就是"画X"——在计划上画X就是取消，在数字上画X就是抵消。
>
> **词拆分记忆**（辅助）：
> can（能）+ cel（cell 牢房）→ 能让人进牢房 → 取消自由 → 取消
