# query

> [!info] 基础信息
> **音标** /ˈkwɪəri/ | **词级** 基础词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**疑问，问题**==；②查询
**v.** ①==**询问，质疑**==；②对……表示怀疑

> [!tip] 原型义
> **原型义**：疑问（对某事提出问题以获取信息）
> **延伸维度**：信息路径
> **隐喻类型**：认知隐喻（"提出问题"→疑问→质疑→查询）

## 词根词缀

源自拉丁语 *quaere*（询问、寻求），*quaerere* 的祈使语气形式
**叙事**：query 直接来自拉丁语 *quaere*（询问），是 *quaerere*（寻求、询问）的祈使语气形式。从"询问"到"疑问"到"质疑"，query 始终围绕着"提出问题"这个核心动作。在现代计算机领域，query 也指"查询"——向数据库提出的问题。[[queue]]、[[quiz]]、[[quota]] 与 query 形似且同源（都来自拉丁语 *quaerere*）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**疑问（对某事提出问题以获取信息）**"为统筹中心，沿信息路径向外扩展：
>
> 1. **提出问题**（信息层面）
>    - → **疑问，问题**：提出的问题
>      - 激活条件：raise a query, answer a query
>    - → **询问，质疑**：提出问题以获取信息或表达怀疑
>      - 激活条件：query a decision, query someone's motives
>    - → **查询**（计算机）：向数据库提出的问题
>      - 激活条件：database query, search query

### 统筹（选择适用的模式）

- **一字一词概括**：query 就是"提出问题"——提出疑问叫"query"，质疑决定叫"query"，数据库查询也叫"query"
- **延伸中心**：从"疑问"延伸到"质疑""查询"

> [!check]- 链路验证
> - [x] **可逆性**：从"数据库查询"能反向推导到"疑问"——查询就是向数据库提出的问题
> - [x] **可统筹**：一句话——"query 就是对某事提出问题以获取信息或表达怀疑"
> - [x] **有支撑**：raise a query, query a decision, database query 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> query 来自拉丁语 *quaere*（询问！），是动词 *quaerere*（寻求、询问）的命令式。想象一个古罗马法官对证人说："Quaere!"（说！问！），这就是 query 的起源。从法庭上的"询问"到日常的"疑问"再到计算机的"查询"，query 始终是"提出问题"。
>
> **词拆分记忆**（辅助）：
> query 本身是根词，来自拉丁语 quaere（询问）。联想：query 的发音像"奎瑞"——你"奎瑞"（query）一下，就是"询问"一下。
