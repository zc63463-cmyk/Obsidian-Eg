# release

> [!info] 基础信息
> **音标** /rɪˈliːs/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**释放，放开**==；②发布，发行（新闻、产品等）；③免除（责任）；④发泄（情绪）；
**n.** ①==**释放，获释**==；②发布，发行；③发泄，宣泄；

> [!tip] 原型义
> **原型义**：松开、释放（放开被束缚或被控制的人或物）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"物理松开"→"发布信息""免除责任""发泄情绪"——松开束缚→松开控制→松开信息→松开情绪）

## 词根词缀

re-(=back，回) + lease(松开，拉丁语 *laxare*，与 [[relax]] 中的 lax 同源)
**叙事**：re（回）+ lease（松开）→ **松开回去** → 释放。把囚犯 release 了——松开枷锁让他回去。把新歌 release 了——松开信息让它公之于众。把怒气 release 了——松开情绪让它出去。建议创建词根笔记 [[lax]]（松的，拉丁语 *laxus*）

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**松开、释放**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **松开、释放**（物理层面）
>    - → **释放人/物**：放开被束缚的
>      - 激活条件：release a prisoner, release from custody
>    - → **发布信息/产品**：松开控制让信息公之于众
>      - 激活条件：release a report, release a new product
>    - → **免除责任**：松开某人的义务
>      - 激活条件：release from obligation
>    - → **发泄情绪**：松开压抑的感情
>      - 激活条件：release anger/tension

### 统筹（选择适用的模式）

- **一字一词概括**：release 就是"放"——放人、放消息、放责任、放情绪
- **v + 不同宾语**：release a prisoner（释放囚犯）→ release a report（发布报告）→ release tension（发泄紧张）

> [!check]- 链路验证
> - [x] **可逆性**：从"发布报告"能反向推导到"松开"——发布就是把信息从控制中"松开"
> - [x] **可统筹**：一句话——"release 就是把被控制的东西放出来"
> - [x] **有支撑**：release a report, release from custody 均有真题支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> re（回）+ lease（松开）→ release。lease 和 relax 里的 lax 是亲戚，都是"松"。release 就是"松开"。松开囚犯——release a prisoner。松开信息——release a report。松开新产品——release a new version。松开情绪——release your feelings。
>
> **词拆分记忆**（辅助）：
> re（回）+ lease（松开，联想 lease 租约到期就"松开"了）→ 释放
