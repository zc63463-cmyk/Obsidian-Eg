# jog

> [!info] 基础信息
> **音标** /dʒɒɡ/ | **词级** 基础词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**慢跑**==；②轻推，轻撞；③唤起（记忆）；
**n.** ①慢跑；②轻推；

> [!tip] 原型义
> **原型义**：轻轻推撞（身体上的轻微碰撞动作）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（"轻推"→"唤起记忆"：像轻推一样把沉睡的记忆推醒）

## 词根词缀

jog 源自中古英语 *joggen*，拟声词，模仿轻推或颠簸时发出的声音。无标准词根词缀可拆分。
**叙事**：jog 模仿"嗒嗒"的轻推声→ 轻轻推一下→ 慢跑时身体有节奏地颠簸→ jog one's memory 轻推记忆。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**轻轻推撞**"为统筹中心，沿具身路径向外扩展：
>
> 1. **轻轻推撞**（身体动作层面）
>    - → **慢跑**：身体有节奏地轻颠，像被轻轻推着前进
>      - 激活条件：go for a jog, jog in the park
>    - → **唤起记忆**：像轻推一样把沉睡的记忆推醒
>      - 激活条件：jog one's memory
>    - → **轻推/轻撞**：本义，轻微的物理接触
>      - 激活条件：jog someone's elbow

### 统筹（选择适用的模式）

- **一字一词概括**：jog 就是"轻推"——推人身体是"轻推"，推自己跑步是"慢跑"，推记忆是"唤起"
- **v + 不同宾语**：jog + elbow（轻推手肘）→ jog + body（慢跑）→ jog + memory（唤起记忆）

> [!check]- 链路验证
> - [x] **可逆性**：从"唤起记忆"能反向推导到"轻推"——jog memory 就是轻推记忆
> - [x] **可统筹**：一句话——"jog 就是从轻推出发，推身体是慢跑，推记忆是唤起"
> - [x] **有支撑**：jog one's memory, go for a jog 均有语料支撑
