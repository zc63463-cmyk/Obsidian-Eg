# frame

> [!info] 基础信息
> **音标** /freɪm/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**框架，骨架**== `N of N`；②画框，边框 `N N`；③体格，身材 `adj N`；④（电影等的）画面，镜头 `N N`；
**v.** ①给……镶框 `V N`；②==**制定，构建**== `V N`（计划、理论等）；③陷害，诬陷 `V N for N`；④表达，阐述 `V N`；

> [!tip] 原型义
> **原型义**：编织而成的骨架结构
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（将"物理框架"比作"理论框架"、"计划框架"、"法律框架"）

## 词根词缀

源自古英语 *framian*（有益的/促进的），与 [[from]] 同源。在中古英语中引申为"建造/构建"→"框架"。与 [[form]]（形状/形式）有远源关联。
**叙事**：frame 最初是"建造"的意思——建造一个房子需要先搭框架（frame）。后来框架变成了画框（picture frame）、眼镜框（glasses frame）。人的身体也有框架——体格（body frame）。制定一个计划就是给它搭框架——frame a plan。陷害一个人就是给他编造一个假的框架——frame someone。记住：frame = 框架 = 一切有结构的东西。

## 词义链路

> [!abstract]- 词义链路法
> 以"**编织而成的骨架结构**"为统筹中心，沿具身路径向外扩展：
>
> 1. **编织而成的骨架结构**（物理层面）
>    - → **框架，骨架**：建筑或物体的支撑结构
>      - 激活条件：steel frame, the frame of a building
>    - → **画框，边框**：围绕画作的框架
>      - 激活条件：picture frame, door frame
>    - → **体格，身材**：身体的骨架
>      - 激活条件：a large frame, a muscular frame
>    - → **画面，镜头**：电影的一帧画面
>      - 激活条件：a freeze frame, frame by frame
>    - → **制定，构建**：为计划/理论搭框架
>      - 激活条件：frame a policy, frame a question
>    - → **陷害，诬陷**：编造一个假的框架
>      - 激活条件：frame someone for a crime

### 统筹（选择适用的模式）

- **v + 不同宾语**：frame + building → 搭框架；frame + plan → 制定；frame + person → 陷害
- **延伸中心**：从"物理框架"延伸到"抽象框架"（计划、理论）和"编造框架"（陷害）

> [!check]- 链路验证
> - [x] **可逆性**：从"陷害"能反向推导到"框架"——陷害就是给某人编造一个假的框架
> - [x] **可统筹**：一句话——"frame 就是框架，无论是建筑的骨架、计划的框架还是陷害的假框架"
> - [x] **有支撑**：steel frame, frame a plan, frame someone 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> frame 就是"框架"。建房子先搭 frame（框架），画画装进 picture frame（画框），人有 large frame（大体格），电影一帧一帧播放——frame by frame。制定政策就是 frame a policy（给政策搭框架），陷害别人就是 frame someone（给某人编造假的框架）。记住：frame = 框架 = 一切有结构的东西。
>
> **形意关联**（辅助）：
> frame 和 [[form]]（形状/形式）远源同根——form 是"形状"，frame 是"形状的骨架"。

## 搭配与短语
