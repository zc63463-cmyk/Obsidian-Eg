# instance

> [!info] 基础信息
> **音标** /ˈɪnstəns/ | **词级** 基础词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**例子，实例**== `for instance` [通用]；②==**情况，场合**== `in this instance` [正式]；③请求，建议（法律）；
**v.** ①==**举例说明**==（instance 作动词极少见）；

> [!tip] 原型义
> **原型义**：站在面前的具体情况（"近在眼前"的一个具体事例）
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（"站在面前"→ 呈现在眼前的具体例子/情况）

## 词根词缀

in-(在……上/靠近) + [[st-sta-stat|st]](站立，拉丁语 *stare*) + -ance(名词后缀)

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**站在面前的具体情况**"为统筹中心，沿空间路径向外扩展：
>
> 1. **站在面前的具体情况**（空间层面）
>    - → **例子，实例**：摆在面前说明问题的具体案例
>      - 激活条件：for instance, an instance of
>    - → **情况，场合**：面前出现的具体情形
>      - 激活条件：in this instance, in some instances
>    - → **请求，建议**：呈现在法官面前的诉求
>      - 激活条件：at the instance of sb.（应某人的请求）

### 统筹（选择适用的模式）

- **一字一词概括**：instance 就是"摆在面前的"——摆在面前的例子叫"实例"，摆在面前的情况叫"场合"
- **延伸中心**：从"近在眼前"延伸到"具体例子"和"具体情况"

> [!check]- 链路验证
> - [x] **可逆性**：从"例子"能反向推导到"站在面前"——例子就是摆在面前让你看的
> - [x] **可统筹**：一句话——"instance 就是站在你面前的具体情况"
> - [x] **有支撑**：for instance, in this instance 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> in（靠近）+ st（站）→ 站在你面前的 → 摆在你面前的一个具体例子。for instance = for example，就是"给你摆一个站在面前的例子"。[[instant]] 也是同源——站在你面前的时刻 = 瞬间。
>
> **词拆分记忆**（辅助）：
> in（在……里）+ stance（站姿）→ 站在面前的姿态 → 例子

## 搭配与短语

> [!example]- 搭配
> - **for instance**：例如（= for example）
> - **in this instance**：在这种情况下
> - **in the first instance**：首先，起初
> - **at the instance of sb.**：应某人的请求
