# ballet

> [!info] 基础信息
> **音标** /ˈbæleɪ/ (英) /bæˈleɪ/ (美) | **词级** 基础词 | **语义场** [[社会习俗]]

## 核心释义

**n.** ①==**芭蕾舞，芭蕾舞剧**== `study N` / `N class`；②==**芭蕾舞团**== `the Royal N`；

> [!tip] 原型义
> **原型义**：小型舞蹈（一种优雅的舞台舞蹈艺术）
> **延伸维度**：社会路径
> **隐喻类型**：无隐喻（直接指舞蹈艺术形式）

## 词根词缀

源自法语 *ballet*，来自意大利语 *balletto*（小型舞蹈），是 *ballo*（舞蹈）的指小词。*ballo* 源自拉丁语 *ballare*（跳舞），与 [[ball]]（舞会）同源。
**叙事**：ball（舞会/跳舞）+ -et（指小后缀）→ **小型舞蹈** → 芭蕾舞。芭蕾最初是一种"小型的、精致的舞蹈"，后来发展成独立的舞台艺术形式。

## 词义链路

> [!abstract]- 词义链路法
> 以"**小型舞蹈（精致的舞台舞蹈）**"为统筹中心，沿社会路径向外扩展：
>
> 1. **小型舞蹈**（艺术层面）
>    - → **芭蕾舞，芭蕾舞剧**：一种以足尖技巧为特征的舞台舞蹈
>      - 激活条件：ballet dancer, ballet class
>    - → **芭蕾舞团**：表演芭蕾舞的团体
>      - 激活条件：the Royal Ballet

### 统筹（选择适用的模式）

- **一字一词概括**：ballet 就是"精致的舞蹈"——从宫廷小型舞蹈到专业芭蕾艺术
- **延伸中心**：从"小型舞蹈"延伸到"芭蕾舞剧"和"芭蕾舞团"

> [!check]- 链路验证
> - [x] **可逆性**：从"芭蕾舞剧"能反向推导到"小型舞蹈"——芭蕾最初就是一种小型舞蹈
> - [x] **可统筹**：一句话——"ballet 就是从小型舞蹈发展而来的精致舞台艺术"
> - [x] **有支撑**：ballet dancer, ballet class 均有语料支撑

>

> ballet 来自意大利语 balletto（小型舞蹈），ball（跳舞）+ -et（小的）。芭蕾最初是宫廷中的"小型舞蹈"，后来发展成需要极高技巧的舞台艺术。芭蕾舞者（ballet dancer）用足尖跳舞，优雅而有力。
