# contain

> [!info] 基础信息
> **音标** /kənˈteɪn/ | **词级** 基础词 | **语义场** [[人本世界]]

## 核心释义

**v.** ①==**包含，容纳**==；②控制，遏制（防止扩散）；③克制，抑制（情绪）；

> [!tip] 原型义
> **原型义**：包含在内（把东西放在容器里不让出去）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（"物理容器容纳"→ "抽象内容包含"→ "情绪/危险遏制"）

## 词根词缀

[[contra-counter|con-]]（共同/一起）+ [[tain]]（持有，来自拉丁语 *tenere*，"持有/保持"）。con + tain → 把东西"一起持有"在里面 → 包含。与 [[tend-tens|tend-/tens-/tent-]]（伸展/持有）同源，tain 是 tenere 的变体。与 [[obtain]]（获得）、[[maintain]]（维持）、[[content]]（内容）同源。
**叙事**：con（一起）+ tain（持有）→ contain。一个盒子里"持有"着各种东西——它 contains（包含）这些物品。消防员控制火势——他们 contain（遏制）火，不让它扩散。一个人愤怒但强忍着——他 contains（克制）自己的情绪。contain 的核心是"持有在里面，不让出去"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**包含在内**"为统筹中心，沿空间路径向外扩展：
>
> 1. **包含在内**（空间层面）
>    - → **包含，容纳**：容器里持有东西
>      - 激活条件：contain vitamins, the box contains books
>    - → **遏制，控制**：把危险"持有"在一定范围内
>      - 激活条件：contain the fire, contain the virus
>    - → **克制，抑制**：把情绪"持有"在心里
>      - 激活条件：contain one's anger, could hardly contain herself

### 统筹（选择适用的模式）

- **一字一词概括**：contain 就是"持有在里面"——容器包含物品，消防员遏制火势，人克制情绪
- **延伸中心**：从"物理容纳"延伸到"危险遏制"和"情绪克制"

> [!check]- 链路验证
> - [x] **可逆性**：从"遏制火势"能反向推导到"包含在内"——遏制就是把火"持有"在一定范围内
> - [x] **可统筹**：一句话——"contain 就是把东西持有在里面，不让它出去，无论是物品、火势还是情绪"
> - [x] **有支撑**：contain vitamins, contain the fire, contain one's anger 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> contain = con（一起）+ tain（持有）。想象一个密封的罐子，里面"持有"着各种水果——这个罐子 contains（包含）水果。消防员赶到火灾现场，用防火带围住火场——他们 contain（遏制）了火势，不让它蔓延。一个被冒犯的人深呼吸，把怒火压在心里——他 contains（克制）了自己的愤怒。contain 就是"持有在里面，不让出去"。
>
> **词拆分记忆**（辅助）：
> contain = con（共同）+ tain（ten 保持）→ 共同保持在里面 → 包含/遏制
