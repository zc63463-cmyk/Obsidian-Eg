# web

> [!info] 基础信息
> **音标** /web/ | **词级** 基础词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**蜘蛛网**==；②==**网络，网状物**==；③==**万维网（the Web）**==；④网络（人际/社会关系）；
**v.** ①==**用网覆盖，使陷入网中**==；

> [!tip] 原型义
> **原型义**：蜘蛛网（丝线交织成的网状结构）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（将蜘蛛网→比喻为一切网状结构——互联网、人际网络、错综复杂的关系）

## 词根词缀

源自古英语 *webb*，与 [[weave]]（编织）同源。蜘蛛网就是蜘蛛 weave（编织）出来的 web。
**叙事**：web 就是蜘蛛网。蜘蛛用丝线 weave（编织）出 web。后来从蜘蛛网延伸到一切网状结构——the World Wide Web（万维网）、a web of lies（谎言的网）、a web of relationships（关系网）。web 就是一切"交织连接的结构"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**蜘蛛网（网状结构）**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **蜘蛛网**（物理层面）
>    - → **网络，网状物**：一切网状结构
>      - 激活条件：a web of wires, a web of relationships
>    - → **万维网（the Web）**：互联网的网状信息结构
>      - 激活条件：the World Wide Web, the Web
>    - → **错综复杂的事物**：如网般交织的复杂局面
>      - 激活条件：a web of deceit/intrigue

### 统筹（选择适用的模式）

- **延伸中心**：web 的核心是"交织连接"——蜘蛛网的丝线交织→互联网的节点连接→人际关系的交织
- **一句话统筹**：web 就是一切"交织连接的结构"——从蜘蛛网到互联网

> [!check]- 链路验证
> - [x] **可逆性**：从"万维网"能反向推导到"蜘蛛网"——都是网状结构
> - [x] **可统筹**：一句话——"web 就是从蜘蛛网到一切网状结构的延伸"
> - [x] **有支撑**：the Web, a web of 均有语料支撑
