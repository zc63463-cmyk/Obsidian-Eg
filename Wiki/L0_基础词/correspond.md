# correspond

> [!info] 基础信息
> **音标** /ˌkɒrɪˈspɒnd/ | **词级** 基础词 | **语义场** [[社会专业]]

## 核心释义

**v.** ①==**通信，通信联系**==；②==**符合，一致**==；③相当于，对应；

> [!tip] 原型义
> **原型义**：互相通信（通过信件相互回应，拉丁语 *correspondere*：cor-共同 + respondere 回应）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（通信→一致——信件一来一回"对得上"= 一致/对应）

## 词根词缀

[[cor-cord|cor]]-(=com-, 共同/相互) + [[spond|spond/spons]](=承诺/回应，拉丁语 *spondere* 承诺) + -d(动词后缀)
**叙事**：cor（相互）+ spond（回应）→ 相互回应 → 通信。两个人互相写信回应 = correspond。引申为"对得上"= 符合/一致。A corresponds to B = A 和 B 对得上 = A 相当于 B。

建议创建词根笔记：spond/spons（承诺/回应，拉丁语 *spondere*）

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**互相回应**"为统筹中心，沿社会路径向外扩展：
>
> 1. **互相回应**（行为层面）
>    - → **通信，通信联系**：通过信件互相回应
>      - 激活条件：correspond with sb., correspond by email
>    - → **符合，一致**：回应的内容"对得上"
>      - 激活条件：correspond to the facts, correspond with the description
>    - → **相当于，对应**：A 和 B 互相"回应"= A 对应 B
>      - 激活条件：The U.S. Congress corresponds to the British Parliament.

### 统筹（选择适用的模式）

- **一字一词概括**：correspond 就是"互应"——互相回应=通信，回应得对得上=一致，互相呼应=对应
- **延伸中心**：从"互相回应"延伸到"对得上"（一致/符合/对应）

> [!check]- 链路验证
> - [x] **可逆性**：从"符合"能反向推导到"互相回应"——符合就是回应得对得上
> - [x] **可统筹**：一句话——"correspond 就是互相回应，回应得对就是一致"
> - [x] **有支撑**：correspond with, correspond to 均为考研高频搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> correspond = cor（相互）+ spond（回应）→ 互相回应。两个人互相写信 = correspond（通信）。事实和描述互相"回应"= 对得上 = correspond（一致）。美国国会和英国议会互相"呼应"= correspond（对应）。记住：correspond = 互应。
>
> **词拆分记忆**（辅助）：
> cor（共同/相互，如 cooperate）+ respond（回应）→ 互相回应 → correspond
