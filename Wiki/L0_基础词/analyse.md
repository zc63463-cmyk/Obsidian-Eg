# analyse

> [!info] 基础信息
> **音标** /ˈænəlaɪz/ | **词级** 基础词 | **语义场** [[理性世界]]

## 核心释义

**v.** ①==**分析，解析**== `analyse data/results` [学术]；`analyse the problem` [通用]；②==**分解，细察**==；③==**精神分析**==（心理学）；

> [!tip] 原型义
> **原型义**：分析（把整体分解为部分以理解）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（物理分解→思维分解→心理分析）

## 词根词缀

[[ana|ana]]-(=up, throughout, 彻底地/向上) + [[lyt-lys|lyt]](=loosen, 解开) + -ise(= -ize, 使动后缀) → 彻底解开 → 分析
**叙事**：ana（彻底）+ lyse（解开）→ 彻底解开一个复杂问题 → 分析。分析数据（analyse data），分析问题（analyse the problem），精神分析（psychoanalyse）。analyse 就是"分析"——把复杂事物彻底解开来看。美式拼写为 analyze。

## 词义链路

> [!abstract]- 词义链路法
> 以"**分析**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **分析**（思维层面）
>    - → **分解，细察**：把整体拆分为部分
>      - 激活条件：analyse the data/results
>    - → **精神分析**：心理层面的"彻底解开"
>      - 激活条件：psychoanalyse, be analysed

### 统筹（选择适用的模式）

- **一字一词概括**：analyse 就是"解"——解题、解构、解心结
- **延伸中心**：从思维分析延伸到数据分解和心理分析

> [!check]- 链路验证
> - [x] **可逆性**：从"精神分析"能反向推导到"彻底解开"——精神分析就是彻底解开心理问题
> - [x] **可统筹**：一句话——"analyse 就是彻底解开——分析数据→分解问题→分析心理"
> - [x] **有支撑**：analyse data, analyse the problem 均有语料支撑
