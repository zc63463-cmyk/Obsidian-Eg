%% ========== 核心释义填写指南 ==========
【句型标注】每个义项后用反引号标注核心句型框架，最多2个
  - 格式：`V N` / `V that-clause` / `V oneself to N` / `with N` 等
  - 句型是义项的子属性，只标产出型（学习者需要主动使用的）
  - 义项完全相同时共享句型，不重复

【语域标签】可选，紧跟句型标注之后，用方括号包裹
  - formal / informal / law / academic / literary / spoken / written / journalism
  - 大部分词不需要标，只有义项明显受语域约束时才标

【常见错误】可选callout，紧跟核心释义
  - 只记最高频的1-2个错误，不贪多
  - 格式：~~错句~~ → 正句 ✅ ← 原因
  - 例：suggest 不接 to V：~~suggest to go~~ → suggest going ✅ ← suggest 后接 V-ing

【句型符号定义表】
  V           = 动词原形（当前词本身）
  N           = 名词/名词短语（直接宾语）
  N1 for N2   = 两个名词，for 连接
  oneself to N = 反身代词 + 介词宾语
  adj         = 形容词（作表语/定语）
  V-ed        = 过去分词用法
  V-ing       = 动名词用法
  that-clause = that 从句
  to V        = 不定式
  prep N      = 介词短语
  it V adj to V = 形式主语结构
  V N1 N2     = 双宾结构
  be adj prep N = 形容词+介词

【特殊词类句型标注参考】
  及物动词    V N / V that-clause
  不及物动词  V / V prep N / V into N
  双宾动词    V N1 N2 / V N2 to N1
  系动词      V adj / V N
  形容词      adj / be adj prep N / be adj that
  名词        N / a N of N / prep N
  副词        adv / V adv
  介词        prep N
========== 指南结束 ========== %%

## 真题/语料关联

> [!example]- 语料
> - <完整英文例句>. `[真题]` / `[COCA-ACAD]` / `[例]`

%% ========== 语料填写指南 ==========
【三级可信度】
  A级 [真题]      = 考研/CET4/CET6/TOEFL 试卷原文
     细标格式     = [考研-2023-阅读] / [CET6-2022-翻译]
  B级 [COCA]/[BNC] = 语料库真实用例
     细标格式     = [COCA-ACAD] / [BNC-SPOKEN] / [COCA-NEWS]
  C级 [例]        = AI生成或自编，统一标[例]，不区分来源

【规则】
  1. 每条必须是完整句子，不是片段
  2. 句中核心搭配/目标词用粗体标记（可选）
  3. 每条末尾必须标注来源标记

【数量要求】
  必备词：≥3条（含≥1条A/B级）
  基础词：≥3条
  超纲词：≥2条

【语料与搭配的关系】
  搭配section = 短语级语块（abandon ship：弃船）
  语料section = 完整句子（The ship was abandoned. [真题]）
  两者不重复
