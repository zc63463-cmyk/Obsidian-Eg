## 修正 6.5：句型标注回填

### 目标
为核心释义的每个义项添加句型框架标注，让读者一眼看出"这个词在句子里的语法座位"。

### 操作方法
在核心释义的每个义项后，用反引号标注核心句型框架。每个义项最多标注 2 个核心句型。

### 修正前
```markdown
**vt.** ①==**抛弃，放弃**==；②==**沉溺于，放纵**==；
**n.** ①放任，狂热；
```

### 修正后
```markdown
**vt.** ①==**抛弃，放弃**== `V N`；②==**沉溺于，放纵**== `V oneself to N`；
**n.** ①放任，狂热 `with N`；
```

### 句型符号定义

| 符号 | 含义 | 示例 |
|------|------|------|
| `V` | 动词原形（当前词本身） | abandon |
| `N` | 名词/名词短语（直接宾语） | abandon a plan |
| `N1 for N2` | 两个名词，for 连接 | abandon the city for the countryside |
| `oneself to N` | 反身代词 + 介词宾语 | abandon oneself to despair |
| `adj` | 形容词（作表语/定语） | be complete / a complete set |
| `V-ed` | 过去分词用法 | an abandoned car |
| `V-ing` | 动名词用法 | abandoning hope |
| `that-clause` | that 从句 | suggest that... |
| `to V` | 不定式 | decide to V |
| `V-ing`(作宾语) | 动名词作宾语 | avoid V-ing |
| `prep N` | 介词短语 | under oath / with abandon |
| `it V adj to V` | 形式主语 | it seems possible to... |
| `V N1 N2` | 双宾结构 | give V N1 N2 |
| `be adj prep N` | 形容词+介词 | be aware of N |

### 特殊词类句型标注参考

| 词类 | 句型标注方式 | 示例 |
|------|------------|------|
| 及物动词 | `V N` / `V that-clause` | suggest `V N` / `V that-clause` |
| 不及物动词 | `V` / `V prep N` / `V into N` | decay `V` / `V into N` |
| 双宾动词 | `V N1 N2` / `V N2 to N1` | give `V N1 N2` |
| 系动词 | `V adj` / `V N` | become `V adj` |
| 形容词 | `adj` / `be adj prep N` / `be adj that` | aware `be adj of N` |
| 名词 | `N` / `a N of N` / `prep N` | evidence `N for N` |
| 副词 | `adv` / `V adv` | openly `V adv` |
| 介词 | `prep N` | despite `prep N` |

### 句型标注规则

1. **每个义项最多标注 2 个核心句型**——太多反而失去聚焦
2. 只标**产出型句型**（学习者需要主动使用的），不标理解型
3. 义项完全相同时（如 adj. 和 vt. 的"完成"），共享句型，不必重复
4. 句型是义项的子属性，紧跟在 `==**释义**==` 后面
5. 可选语域标签放在句型标注之后：`==**释义**== \`句型\` [formal]`
6. 如果义项本身已含语境信息（如"放弃（信仰/习惯）"），直接加句型即可，不需要语域标签

### 常见错误 callout（可选，对高频易错词添加）

对考研高频词中有常见句型错误的词，在核心释义后添加常见错误 callout：

```markdown
> [!warning]- 常见错误
> suggest 不接 `to V`：~~suggest to go~~ → suggest going ✅ ← suggest 后接 V-ing
```

格式：`~~错~~ → 对 ✅ ← 原因`

**注意**：仅对有明确高频错误的词添加，不要为每个词都加。不确定是否有常见错误就不加。

## 修正 6.6：语料可信度标记

### 目标
为语料 section 的每条例句添加可信度标记，片段型语料重写为完整句子。

### 操作方法
1. 判断每条例句的来源可信度
2. 在每条末尾添加可信度标记
3. 片段型语料重写为完整句子

### 三级可信度体系

| 等级 | 标记 | 判断标准 |
|------|------|---------|
| **A 级** | `[真题]` | 明确出自考研/CET4/CET6/TOEFL 试卷原文 |
| **B 级** | `[COCA-ACAD]` 等 | 出自语料库，可标注语域 |
| **C 级** | `[例]` | 无法确认来源的例句（包括 AI 生成和自编） |

### A 级细标格式
- `[考研-2023-阅读]` 或 `[CET6-2022-翻译]`
- 如果只知道是真题但不确定年份，标 `[真题]`

### B 级细标格式
- `[COCA-ACAD]` = COCA 学术语域
- `[COCA-NEWS]` = COCA 新闻语域
- `[BNC-SPOKEN]` = BNC 口语语域
- 如果只知道是语料库但不确定语域，标 `[COCA]` 或 `[BNC]`

### 修正前
```markdown
> [!example]- 语料
> - "abide by the rules and regulations"（遵守规章制度）——考研翻译和阅读中常见搭配
> - "cannot abide the noise/pollution"（无法忍受噪音/污染）——环境类话题中常见
```

### 修正后
```markdown
> [!example]- 语料
> - Citizens must abide by the rules and regulations of the community. `[例]`
> - She cannot abide the constant noise from the construction site. `[例]`
```

### 片段重写规则
1. 片段型语料（带引号的短语、中文说明为主体的条目）必须重写为完整英文句子
2. 重写后的句子应自然、语法正确、体现目标词的典型用法
3. 保留原条目中的语境信息（如"考研阅读""法律类"），作为重写参考
4. 重写后的句子统一标 `[例]`（因为是 AI 生成的完整句，不是原句摘录）
5. 如果原条目本身已是完整英文句子，直接加标记即可

### 语料数量要求

| 词频级别 | A/B 级语料（最少） | C 级语料（最多） | 总计 |
|----------|------------------|----------------|------|
| 必备词 | 1 条 | 2 条 | 3 条 |
| 基础词 | 0 条 | 3 条 | 3 条 |
| 超纲词 | 0 条 | 2 条 | 2 条 |

- 如果现有语料不足，补充 C 级例句凑够数量
- 如果现有语料超过数量要求，保留有价值的条目，不强删
- 必备词要求至少 1 条 A/B 级，如果当前没有真题/语料库例句，可以补充一条模拟真题风格的句子，标 `[例]`

### 语料格式规范
1. 每条必须是**完整句子**，不是片段
2. 句中核心搭配/目标词可用粗体标记（可选）
3. 每条末尾必须标注来源标记，格式为 `` `[标记]` ``
4. 不要保留中文翻译（原条目的中文翻译在重写为完整句后删除）
5. 不要保留行尾的"——考研阅读常见搭配"等说明性文字

## 执行顺序

每个文件按以下顺序执行：
1. 先判断 6.5 是否已完成（核心释义有无反引号句型标注）→ 未完成则执行 6.5
2. 再判断 6.6 是否已完成（语料条目有无可信度标记）→ 未完成则执行 6.6
3. 两个修正都完成后，保存文件

## 关键规则
1. **不要修改其他内容**：只修改核心释义 section（6.5）和语料 section（6.6），不要动 frontmatter、词义链路、搭配等其他 section
2. **不要重复已完成的修正**：如果文件已有句型标注或可信度标记，跳过对应修正
3. **搭配 section 不动**：句型信息嵌入核心释义后，搭配 section 保持原样
4. **语料与搭配的关系**：搭配 = 短语级语块，语料 = 完整句子，两者不重复
5. **保持行尾格式**：义项之间用中文分号；结尾用中文分号
6. **保持编码一致**：文件用 UTF-8 编码，行尾用 CRLF

- 处理文件数
- 6.5 命中数（需要添加句型标注的文件数）/ 跳过数（已完成的）

- 片段重写数（6.6 中重写了多少条片段型语料）
- 补充语料数（因数量不足而补充的例句条数）
- 遇到的异常情况
