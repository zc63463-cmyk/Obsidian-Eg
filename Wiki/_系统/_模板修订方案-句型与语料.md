> 修订日期：2026-04-26

## 一、问题 3：句型框架

### 1.1 设计原则

**核心洞察**：学习者用错词，80% 是句型错，不是词义错。搭配 section 当前格式（"短语 + 中文翻译"）只能帮助理解，不能指导产出。

**设计目标**：让读者一眼看出"这个词在句子里的语法座位"。

**关键约束**：
- 句型标注嵌入核心释义，不和搭配 section 重复
- 格式必须对 L0 学习者友好——不要出现语言学符号（如 V_np, N1 等）
- 句型是义项的子属性，不是独立维度

### 1.2 句型标注格式

在核心释义的每个义项后，用反引号标注句型框架：

```markdown
## 核心释义

**vt.** 
①==**抛弃，放弃**== `V N` / `V N for N`
   → abandon a plan / abandon the city for the countryside
②==**沉溺于，放纵**== `V oneself to N`
   → abandon oneself to despair / drink / pleasure

**n.** 
①放任，狂热 `with N`
   → with reckless / wild abandon
```

### 1.3 句型符号定义

使用学习者友好的简写，不用语言学标记：

| 符号 | 含义 | 示例 |
|------|------|------|
| `V` | 动词原形（当前词） | abandon |
| `N` | 名词/名词短语（直接宾语） | abandon a plan |
| `N1 for N2` | 两个名词，用 for 连接 | abandon the city for the countryside |
| `oneself to N` | 反身代词 + 介词宾语 | abandon oneself to despair |
| `adj` | 形容词（当前词作表语/定语） | be complete / a complete set |
| `V-ed` | 过去分词用法 | an abandoned car |
| `V-ing` | 动名词用法 | abandoning hope |
| `that-clause` | that 从句 | suggest that... |
| `to V` | 不定式 | decide to V |
| `V-ing` (作宾语) | 动名词作宾语 | avoid V-ing |
| `prep N` | 介词短语 | under oath / with abandon |
| `it V adj to V` | 形式主语 | it seems possible to... |

### 1.4 句型与义项的绑定规则

1. **每个义项最多标注 2 个核心句型**——太多反而失去聚焦
2. 只标**产出型句型**（学习者需要主动使用的），不标理解型
3. 不规则用法用 `⚠️` 标注：`abandon ⚠️ 不接 to V，接 V N`
4. 义项完全相同时（如 adj. 和 vt. 的"完成"），共享句型，不必重复

### 1.5 搭配 section 的重新定位

句型嵌入核心释义后，搭配 section 释放出来，专注于**高频语块**（lexical chunks）：

```markdown
## 搭配与短语

> [!example]- 搭配 · L3
> - **abandon ship**：弃船（紧急放弃）
> - **abandon hope**：放弃希望（文学/正式）
> - **with reckless abandon**：不顾一切地（状语语块）
> - **abandon oneself to**：沉溺于（反身结构）
```

变化：
- 不再重复句型信息（核心释义已有）
- 每条是一个**可整体记忆的语块**，不是"词 + 翻译"
- 括号内标注语域/使用场景
- 不需要每条都配例句（核心释义的句型行已提供）

### 1.6 特殊词类的句型标注

| 词类 | 句型标注方式 | 示例 |
|------|------------|------|
| 及物动词 | `V N` / `V that-clause` | suggest `V N` / `V that-clause` |
| 不及物动词 | `V` / `V prep N` | decay `V` / `V into N` |
| 双宾动词 | `V N1 N2` / `V N2 to N1` | give `V N1 N2` |
| 系动词 | `V adj` / `V N` | become `V adj` |
| 形容词 | `adj` / `be adj prep N` | aware `be adj of N` |
| 名词 | `N` / `a N of N` / `prep N` | evidence `N for N` / `a N of N` |
| 副词 | `adv` / `V adv` | openly `V adv` |
| 介词 | `prep N` | despite `prep N` |

## 二、问题 4：语料可信度分层

### 2.1 设计原则

**核心矛盾**：5000+ 词条的语料填充是规模问题，手动不可行，AI 生成是唯一可规模化的路径，但可信度需要标注。

**设计目标**：
- 让使用者清楚每条例句的可信度
- 让后续维护者知道哪些需要替换为真实语料
- 格式统一，便于批量处理

### 2.2 三级可信度体系

| 等级 | 标记 | 来源 | 说明 |
|------|------|------|------|
| **A 级** | `[真题]` | 考研/CET4/CET6/TOEFL 原文 | 最高可信度，直接从试卷摘录 |
| **B 级** | `[COCA]` / `[BNC]` | 语料库真实用例 | 母语者产出，但非应试原文 |
| **C 级** | `[例]` | LLM 生成或自编 | 合理但非真实语料，仅供理解 |

### 2.3 语料 section 新格式

```markdown
## 真题/语料关联

> [!example]- 语料 · L3
> - The government abandoned the project due to budget constraints. `[真题]`
> - She abandoned herself to grief after the loss of her child. `[例]`
> - Many pets are abandoned by their owners when they become inconvenient. `[COCA-NEWS]`
```

规则：
1. 每条必须是**完整句子**，不是片段
2. 每条末尾必须标注来源标记
3. A 级真题标注更细：`[考研-2023-阅读]` 或 `[CET6-2022-翻译]`
4. B 级语料库标注语域：`[COCA-ACAD]` / `[BNC-SPOKEN]` / `[COCA-NEWS]`
5. C 级统一标 `[例]`，不需要区分 LLM 还是自编

### 2.4 语料和搭配的关系

搭配 section 专注语块，语料 section 专注完整句子。两者不重复：

| section | 内容 | 格式 |
|---------|------|------|
| 搭配 | 高频语块（短语级） | `abandon ship`：弃船 |
| 语料 | 完整句子（句级） | The ship was abandoned. `[真题]` |

### 2.5 语料数量要求

| 词频级别 | A/B 级语料（最少） | C 级语料（最多） | 总计 |
|----------|------------------|----------------|------|
| 必备词 | 1 条 | 2 条 | 3 条 |
| 基础词 | 0 条 | 3 条 | 3 条 |
| 超纲词 | 0 条 | 2 条 | 2 条 |

必备词要求至少 1 条 A/B 级语料，因为高频词更容易获得真题引用。低频词允许全部用 C 级。

### 2.6 当前存量卡片的迁移策略

当前 5249 张卡片的语料 section 质量参差不齐：
- 部分 有完整真题引用 → 直接加 `[真题]` 标记
- 部分 是自编例句 → 加 `[例]` 标记
- 部分 是主题提示（无完整句子）→ 需要重新生成为完整句子

**迁移顺序**：必备词（1793）→ 基础词（2406）→ 超纲词（1050）

**迁移方式**：LLM 批量处理——对每条例句判断可信度并加标记，片段型重写为完整句子。

## 三、模板变更摘要

### 3.1 核心释义 section 变更

**之前**：
```markdown
**vt.** ①==**抛弃，放弃**==；②==**沉溺于，放纵**==；
```

**之后**：
```markdown
**vt.** 
①==**抛弃，放弃**== `V N`
②==**沉溺于，放纵**== `V oneself to N`
```

### 3.2 搭配 section 变更

**之前**：
```markdown
> [!example]- 搭配 · L3
> - **abandon a plan**：放弃计划
> - **abandon oneself to**：沉溺于
```

**之后**：
```markdown
> [!example]- 搭配 · L3
> - **abandon ship**：弃船（紧急放弃）
> - **abandon hope**：放弃希望（文学/正式）
> - **with reckless abandon**：不顾一切地（状语语块）
```

### 3.3 语料 section 变更

**之前**：
```markdown
> [!example]- 语料 · L3
> - "abandon the attempt to do sth."——考研阅读常见搭配
```

**之后**：
```markdown
> [!example]- 语料 · L3
> - The team abandoned the project after months of failed attempts. `[例]`
> - She danced with wild abandon, as if no one was watching. `[例]`
```

### 3.4 前置条件：不规则用法标注

在核心释义句型行后，可选加一行⚠️标注常见错误：

```markdown
**vt.** 
①==**建议，提议**== `V N` / `V that-clause` / `V V-ing`
⚠️ 不接 `to V`：suggest to go ❌ → suggest going ✅
```

这个标注直接阻断最高频的产出错误。

## 五、完备模板变更摘要（2026-04-27）

> 基于对 English Word Coach 和英语学习助手两个 skill 的深度研究，对模板进行完备化重写。
> 解决问题3（句型框架）、问题4（语料可信度）、问题7（维度框架），并删除L0-L4等级体系。

### 5.1 L0-L4 等级体系删除

掌握度完全由网站端（vocab-observatory）FSRS 算法管理，Obsidian 模板不再承载等级信息。

| 删除位置 | 删除内容 |
|---------|---------|
| Frontmatter | `mastery: L0` 字段 |
| Tags | `- 掌握/<mastery_level>` |
| Callout 标题 | 所有 `· Ln` 后缀（如 `搭配 · L3` → `搭配`） |
| 整个 section | `## 复习记录` 及其内容 |

保留 `last_review` 和 `review_count` 作为本地简单元数据，网站端可读取。

### 5.2 核心释义增强（问题3）

- 每个义项后加句型标注（反引号）+ 可选语域标签（方括号）
- 格式：`==**释义**== \`句型\` [语域]`
- 新增常见错误 callout（可选）：`~~错~~ → 对 ✅ ← 原因`
- 句型符号定义表写入模板注释区

### 5.3 搭配重新定位（问题3）

- 定位为高频语块（lexical chunks），不重复句型信息
- 每条标使用场景/语域
- 数量3-6条，聚焦高频

### 5.4 语料可信度分层（问题4）

- 三级可信度：[真题](A) / [COCA/BNC](B) / [例](C)
- 完整句子格式，每条必标来源
- 必备词要求≥1条A/B级语料

### 5.5 维度框架调整（问题7）

- `extension_dim` 改为 YAML 数组：`extension_dim: [社会路径]` 或 `[社会路径, 具身路径]`
- `metaphor_type` 降级为可选：无隐喻则整行删除，不写 `无隐喻`
- 参考文件使用规则已更新

### 5.6 模板新增内容

- 每个 section 附填写指南（用 `%% 注释 %%` 包裹，Obsidian 渲染时不可见）
- 句型符号定义表（13个符号 + 特殊词类参考）
- 语域标签可选值列表
- Frontmatter 填写指南（含必填/可选/已删除字段说明）

### 5.7 与前版模板的完整对照

| 维度 | 旧模板 | 完备模板 |
|------|--------|---------|
| Frontmatter mastery | `mastery: L0` | 删除 |

| 核心释义 | 仅释义 | 释义 + 句型标注 + 语域标签 |
