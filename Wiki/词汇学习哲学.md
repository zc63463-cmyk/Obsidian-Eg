# 词汇学习哲学

> [!abstract] 核心理念
> VocabVault 知识库的底层方法论文档。本文定义了词汇分析、记忆编码、加工深度分层、复习调度等核心规则，是所有单词笔记的方法论基石。

---

## 1. 加工深度理论

词汇记忆的本质是**加工深度**（Depth of Processing）。浅层加工（重复抄写、机械背诵）产生脆弱记忆；深层加工（语义分析、联想建构、主动产出）产生持久记忆。VocabVault 的每一层结构都对应一个加工深度等级。

## 2. 词汇分析规则

### 2.1 隐喻类型判定

语言中大量词汇通过隐喻从具体域映射到抽象域。判定隐喻类型有助于理解词义延伸的逻辑：

- **方位隐喻（Orientational Metaphor）**：用空间方位表达抽象概念。如 `happy is up`（情绪高涨）、`important is big`（重大事件）。例：`decline` 从"向下倾斜"到"数量下降"。
- **结构隐喻（Structural Metaphor）**：用一种概念的结构来建构另一种概念。如 `argument is war`（辩论是战争）、`time is money`（时间是金钱）。例：`defend` 从"击退敌人"到"为被告辩护"。
- **本体隐喻（Ontological Metaphor）**：将抽象概念视为实体或物质。如 `the mind is a machine`（大脑是机器）。例：`digest` 从"消化食物"到"消化信息"。
- **无隐喻**：词义在同一个语义域内延伸，不涉及跨域映射。如 `drink water` → `drink medicine`（都是"摄入液体"）。

### 2.2 词义链路操作规程

**Step 1**：判定原型义（物理动作优先 > 最具体义项优先 > 最早学到优先 > 词源义参考）

**Step 2**：确定延伸维度 + 隐喻类型
- 具身路径：从身体动作/感官体验出发
- 空间路径：从空间关系出发
- 时间路径：从时间顺序出发
- 社会路径：从人际/社会关系出发
- 抽象路径：从逻辑/概念关系出发

**Step 3**：描述路径 + 激活条件
- 每个引申义需说明"从原型义如何延伸而来"
- 每个引申义需标注"在什么语境下激活该义"

**Step 4**：选择统筹模式（6种选1-2种）
- 一字一词概括
- 延伸中心
- 一句话统筹
- v + 不同宾语
- 不同主体 + v
- 不同程度/过程

**验证标准**：可逆性 + 可统筹 + 有支撑

### 2.3 统筹模式详解

当一词多义时，需要找到能"统筹"所有义项的核心线索：

1. **一字一词概括**：以原型义为统筹中心，一个字/词概括所有义项。如 `cover` = "盖"：盖住身体(衣服) → 盖住信息(报道) → 盖住距离(行走) → 盖住费用(负担)
2. **延伸中心**：这个词具有的某个特征贯穿所有义项。如 `sharp` = "锋利/敏锐"：刀锋利 → 头脑敏锐 → 言辞尖锐 → 急剧(锋利的曲线)
3. **一句话统筹**：用一句中文将所有义项耦合。如 `strike` = "用力击打"：击打别人(罢工) → 击打心灵(震撼) → 击中目标(想到) → 击打时钟(报时)
4. **v + 不同宾语**：动词+不同宾语产生不同含义。如 `kill`：杀死(人) → 毁坏(sth.) → 消磨(time) → 终止(计划)
5. **不同主体 + v**：不同执行者导致不同含义。如 `observe`：科学家观察(实验) → 公民遵守(法律) → 庆祝(节日)
6. **不同程度/过程**：不同程度/过程下的含义变化。如 `develop`：显影(照片) → 发展(经济) → 开发(土地) → 患病(症状)

### 2.4 词性转换路径分析

| 转换路径 | 核心逻辑 | 示例 |
|---------|---------|------|
| v → n | 该动作的**结果**或**产物** | create → creation（创造的产物） |
| n → n | 子集链路 / 特性抽象 | science → scientific（科学的特性） |
| a → v | **使动用法**：使某物具有该形容词的特征 | pure → purify（使纯净） |
| v → a | +ed 表示"持有该动作的状态" | interest → interested（被引起兴趣的状态） |
| n → v | 将名词所指的事物作为动作执行 | water → water the plants（给植物浇水） |

### 2.5 派生词链接规则

派生词与母词之间存在两种核心关系：

- **词义补充**：派生词反哺母词，提供母词不具备的语义维度。如 `create`（创造）→ `creative`（有创造力的）补充了"人的特质"维度。
- **词义填充**：母词填充派生词，派生词的词义需要回到母词才能完全理解。如 `-tion` 后缀名词需要回到动词才能理解其动作本质。

### 2.6 词拆分记忆规则

当标准词根词缀分析无法解释或效果不佳时，允许使用**创造性拆分**：

- 拆分后的每部分必须有独立含义
- 拆分结果必须能串联成一个有意义的"故事"
- 故事遵循5标准：具象、情感、简洁、关联、独特
- 例：`contemplate` = `con`（一起）+ `template`（模板）+ `plate`（盘子）→ 把所有想法放在一个盘子里一起端详 → 深思

### 2.7 编码策略

#### 2.7.1 "增"标记法

在同义词辨析中，使用"增"标记来精确描述词与词之间的语义/情感差异：

- **语义增量**：`word A (增-语义增量) vs word B`。如 `exclaim (增-情感强度) vs say`。
- **情感增量**：`word A (增-正面/负面情感) vs word B`。如 `thrifty (增-正面评价) vs stingy`。
- **方式增量**：`word A (增-方式差异) vs word B`。如 `murmur (增-低声) vs say`。

#### 2.7.2 双编码策略

同时激活言语编码和意象编码，形成双重记忆痕迹：

- **言语编码**：词根拆分、词义链路、同义词辨析
- **意象编码**：叙事化记忆、画面联想、具身模拟

#### 2.7.3 间隔重复原理

基于艾宾浩斯遗忘曲线的优化版本：

- 每次复习应比上一次间隔更长
- 复习时必须**主动回忆**而非被动识别
- 不同加工深度等级对应不同的复习间隔（见第3节）

#### 2.7.4 叙事化词源记忆

优先使用叙事化词源作为记忆锚点，创作标准：

1. **具象**：包含具体画面（人、物、场景）
2. **情感**：触发情绪反应（惊讶、幽默、恐惧）
3. **简洁**：一句话完成，不超过30字
4. **关联**：与词根/词缀/已知词形成网络
5. **独特**：与其他词的记忆不混淆

## 3. 与加工深度等级的对应

VocabVault 采用4级加工深度体系（L0-L4），每级对应不同的认知操作和复习策略：

### L0：感知层 — 初次接触

**认知操作**：感知词形、音标、核心释义

**复习策略**：
- 当天 + 1天后
- **主动回忆**：看到英文单词，能否说出原型义？
- 目标：建立词形-释义的基础联结

### L1：理解层 — 深度分析

**认知操作**：词义链路分析、词根词缀拆分、记忆锚点建构、统筹模式选择

**复习策略**：
- 3天后 + 1周后
- **主动回忆**：能否从原型义推导出所有引申义？能否说出词根拆分？
- 目标：建立词义之间的逻辑网络

### L2：辨析层 — 横向对比

**认知操作**：同义词辨析、反义词对比、派生词族构建、搭配积累

**复习策略**：
- 2周后 + 1个月后
- **主动回忆**：能否区分近义词？能否列举派生词？
- 目标：建立词汇间的横向关联网络

### L3：应用层 — 语料关联

**认知操作**：真题/语料关联、搭配与短语、翻译实践

**复习策略**：
- 1个月后 + 2个月后
- **主动回忆**：能否在真题语境中识别该词？能否正确使用搭配？
- 目标：将词汇知识嵌入真实语言环境

### L4：产出层 — 内化掌握

**认知操作**：写作/翻译中的主动产出、创造性使用

**复习策略**：
- 2个月后 + 按需复习
- **主动产出**：在写作和翻译中自然使用该词
- 目标：词汇成为主动词汇（productive vocabulary）

### 复习间隔速查表

| 等级跃迁 | 复习时间点 | 回忆内容 |
|---------|-----------|---------|
| L0 → L1 | 当天 + 1天后 | 原型义 |
| L1 → L2 | 3天后 + 1周后 | 词义链路 + 词根 |
| L2 → L3 | 2周后 + 1个月后 | 辨析 + 语料 |
| L3 → L4 | 2个月后 | 写作/翻译主动产出 |

## 4. 四维辨析法

用于同义词的系统化对比分析：

| 维度 | 核心问题 | 示例 |
|------|---------|------|
| **核心语义差异** | 这几个词的核心概念有什么不同？ | say vs tell vs speak vs talk |
| **方式特点** | 动作执行的方式有什么区别？ | murmur（低声）vs shout（大声） |
| **常见对象** | 通常搭配什么宾语/对象？ | answer（问题）vs reply（人） |
| **情感色彩** | 褒义/贬义/中性？正式/非正式？ | thrifty（褒）vs stingy（贬） |

## 5. 语义场体系

VocabVault 采用10大语义场分类：

| 语义场 | 核心范畴 | 典型词汇 |
|--------|---------|---------|
| 理性世界 | 认知、思维、逻辑、知识 | think, analyze, logic |
| 人本世界 | 情感、态度、性格、关系 | love, honest, brave |
| 社会习俗 | 文化、教育、宗教、日常 | wedding, school, holiday |
| 社会专业 | 法律、医疗、军事、学术 | court, surgery, research |
| 资本经济 | 商业、金融、贸易、产业 | market, invest, profit |
| 政治法律 | 政府、权力、权利、治理 | democracy, law, vote |
| 自然物理 | 自然现象、物质、环境 | climate, energy, gravity |
| 人体动作 | 身体动作、生理、健康 | run, breathe, disease |
| 物品工具 | 日常物品、设备、技术 | computer, tool, bridge |
| 抽象关系 | 数量、程度、因果、逻辑关系 | cause, however, significant |
