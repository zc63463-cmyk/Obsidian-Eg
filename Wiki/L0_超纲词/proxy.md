# proxy

> [!info] 基础信息
> **音标** /ˈprɒksi/ | **词级** 超纲词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**代理人，代表**== `N`；②==**代理权，委托书**== `N`；③==**代理服务器**== `N`；
**adj.** 代理的；

> [!tip] 原型义
> **原型义**：在前方代替他人行事（站在别人前面替他做事）
> **延伸维度**：社会路径
> **隐喻类型**：方位隐喻（"pro-"=在前方，站在前面替别人处理事务→代理人）

## 词根词缀

[[pro]](向前/在前) + [[prox-proach|prox]](近/接近，拉丁语 *proxitare*) → 在前面接近→代替
**叙事**：pro（在前面）+ x/y（近）→ 站在前面替你接近问题的人 → **代理人**。就像你请律师替你出庭，律师就是你的 proxy——站在你前面替你说话的人。

## 词义链路

> [!abstract]- 词义链路法
> 以"**在前面代替他人行事**"为统筹中心，沿社会路径向外扩展：
>
> 1. **在前面代替他人行事**（社会角色层面）
>    - → **代理人，代表**：站在前面替别人处理事务的人
>      - 激活条件：act as a proxy, proxy vote
>    - → **代理权，委托书**：代替他人行事的权利/凭证
>      - 激活条件：hold a proxy, proxy statement
>    - → **代理服务器**：在网络中代替用户访问目标的服务器
>      - 激活条件：proxy server, web proxy

### 统筹（选择适用的模式）

- **一字一词概括**：proxy 就是"替身"——替你投票的人是代理，替你上网的服务器也是代理
- **延伸中心**：从"代替他人行事的人"延伸到"代理权"和"代理服务器"

> [!check]- 链路验证
> - [x] **可逆性**：从"代理服务器"能反向推导到"代替他人行事"——代理服务器就是代替用户访问网络
> - [x] **可统筹**：一句话——"proxy 就是站在前面替别人行事的人或工具"
> - [x] **有支撑**：proxy vote, proxy server 均为常见搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> pro（在前方）+ x/y（接近）→ 站在你前面替你接近问题的人。股东大会上你不能到场，你的 proxy 替你投票；上网时你不能直接访问，proxy server 替你转发请求。proxy 就是你不在场时的"替身"。
>
> **词拆分记忆**（辅助）：
> pro（前）+ xy（谐音"西"）→ 站在前面向西看替你放哨的人 → 代理人
