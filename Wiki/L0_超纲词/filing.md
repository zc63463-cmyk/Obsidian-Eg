# filing

> [!info] 基础信息
> **音标** /ˈfaɪlɪŋ/ | **词频** 考研中频 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**归档，存档**==；②档案，文件；③提交（法律文件）；④锉削，锉磨；
**v.** ①(file 的现在分词) 归档；提交；

> [!tip] 原型义
> **原型义**：归档（将文件整理存放到指定位置）
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（从"物理空间上的整理"→"法律/行政上的提交"——将文件放到正确的位置）

## 词根词缀

file(文件，档案，源自拉丁语 *filum*，线) + -ing(名词后缀，表示动作/结果)
**叙事**：file（文件）+ -ing（动作/结果）→ 整理文件的动作 → 归档。古时文件用线串起来归档（拉丁语 filum = 线），filing 就是把文件"串好"存放。filing a lawsuit 就是"提交"诉讼——把文件放到法院去。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**归档**"为统筹中心，沿空间路径向外扩展：
>
> 1. **归档**（文件管理层面）
>    - → **存档，归档整理**：将文件分类存放
>      - 激活条件：filing system, filing cabinet
>    - → **提交（法律文件）**：将文件提交给官方机构
>      - 激活条件：filing a lawsuit, filing a claim
>    - → **锉削**：file 作为动词"锉"的现在分词
>      - 激活条件：filing down rough edges

### 统筹（选择适用的模式）

- **一字一词概括**：filing 就是"存"——存放文件、提交文件
- **v + 不同宾语**：file documents（归档文件）→ file a lawsuit（提交诉讼）→ file nails（锉指甲）

> [!check]- 链路验证
> - [x] **可逆性**：从"提交诉讼"能反向推导到"归档"——都是把文件放到该放的地方
> - [x] **可统筹**：一句话——"filing 就是把东西放到正确的位置"
> - [x] **有支撑**：filing system, filing a lawsuit 均为高频表达
