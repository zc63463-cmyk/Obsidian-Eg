# fend

> [!info] 基础信息
> **音标** /fend/ | **词频** 考研低频 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**抵挡，防御**==；②照料自己，自谋生路；
**n.** ①照料，照管；

> [!tip] 原型义
> **原型义**：抵挡，防御（保护自己免受伤害）
> **延伸维度**：具身路径
> **隐喻类型**：无隐喻（字面义即核心义，源自 defend 的缩写）

## 词根词缀

fend 是 defend（防御）的缩写形式，defend 源自 [[de|de]]-(离开) + [[tend-|tend-/tens-]](伸展，照管)。
**叙事**：fend 是 defend 的缩写 → 防御、抵挡。fend off 就是"击退、挡开"。fend for oneself 就是"自己照料自己"——没人帮你 defend，你得自己 fend。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**抵挡，防御**"为统筹中心，沿具身路径向外扩展：
>
> 1. **抵挡，防御**（身体动作层面）
>    - → **击退，挡开**：将攻击或危险推开
>      - 激活条件：fend off an attack, fend off a blow
>    - → **照料自己，自谋生路**：自己保护自己
>      - 激活条件：fend for oneself

### 统筹（选择适用的模式）

- **一字一词概括**：fend 就是"挡"——挡住攻击，挡住困难
- **延伸中心**：从"抵挡外力"延伸到"自我照料"

> [!check]- 链路验证
> - [x] **可逆性**：从"自谋生路"能反向推导到"防御"——自己照料自己就是自我防御
> - [x] **可统筹**：一句话——"fend 就是用自己的力量挡住一切"
> - [x] **有支撑**：fend off, fend for oneself 均为固定搭配

> [!quote]- 记忆方式 · L1

> fend 是 defend（防御）的缩略形式。中世纪英语中 fend = defend。fend off 就是"挡开"——像用盾牌挡开攻击一样。fend for yourself 就是"你自己照顾自己吧"——没人帮你 defend，你得自己 fend。记住 fend = defend 去掉 de。
