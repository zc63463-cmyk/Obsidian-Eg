# overview

> [!info] 基础信息
> **音标** /ˈoʊvərvjuː/ | **词级** 超纲词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**概述，概观**== `an overview of N` [学术]；②==**总体看法，全景**== `V an overview` `a comprehensive overview of N` [学术]；

> [!tip] 原型义
> **原型义**：从上面看（从高处俯瞰全景）
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（"从上面看"→"全面了解"——从空间上的俯瞰延伸到认知上的全局把握）

## 词根词缀

over-(在上面) + [[vis-vid|view]](=view, 看)
**叙事**：over（在上面）+ view（看）→ 从上面看 → 概述。站在山顶 overview 整个城市——你看到了全景。写论文时先给一个 overview——让读者从"上面"看到全貌。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**从上面看**"为统筹中心，沿空间路径向外扩展：
>
> 1. **从上面看**（空间层面）
>    - → **概述，概观**：从全局角度的简要描述
>      - 激活条件：an overview of the situation, a brief overview
>    - → **总体看法，全景**：对整体的全面了解
>      - 激活条件：provide an overview, give a comprehensive overview

### 统筹（选择适用的模式）

- **一字一词概括**：overview 就是"全貌"——看到全貌的描述叫"概述"，对全貌的了解叫"总体看法"
- **延伸中心**：从"空间俯瞰"延伸到"认知全局"

> [!check]- 链路验证
> - [x] **可逆性**：从"概述"能反向推导到"从上面看"——概述就是从全局角度的描述
> - [x] **可统筹**：一句话——"overview 就是从上面看到的全貌"
> - [x] **有支撑**：an overview of, provide an overview 均有语料支撑
