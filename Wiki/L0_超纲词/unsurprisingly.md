# unsurprisingly

> [!info] 基础信息
> **音标** /ˌʌnsərˈpraɪzɪŋli/ | **词级** 超纲词 | **语义场** [[抽象关系]]

## 核心释义

**adv.** ①==**不出所料地，毫不奇怪地**== `adv`；

> [!tip] 原型义
> **原型义**：不令人惊讶地（un-不 + surprise惊讶 + -ing...的 + -ly...地 → 不令人惊讶地）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接否定：去掉"惊讶"的情感反应）

## 词根词缀

un-(不，否定) + [[sur-]](在...之上→surprise 源自古法语 *surprendre* = 在上面抓住) + -ing(形容词后缀) + -ly(副词后缀)
**叙事**：un（不）+ surprise（惊讶）+ ingly（地）→ **不令人惊讶地** → 不出所料地。考试前没复习， unsurprisingly 挂科了。

## 词义链路

> [!abstract]- 词义链路法
> 以"**不令人惊讶地**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **不令人惊讶地**（认知层面）
>    - → **不出所料地，毫不奇怪地**：结果在预料之中
>      - 激活条件：Unsurprisingly, the project failed.

### 统筹（选择适用的模式）

- **一字一词概括**：unsurprisingly 就是"果然"——不出所料、毫不意外
- **一句话统筹**：unsurprisingly 就是"不令人惊讶地"，表示结果完全在预料之中

> [!check]- 链路验证
> - [x] **可逆性**：从"不出所料地"能反向推导到"不令人惊讶地"——不出所料就是不令人惊讶
> - [x] **可统筹**：一句话——"unsurprisingly 就是不令人惊讶地、果然如此"
> - [x] **有支撑**：Unsurprisingly, ... 为常见句式
