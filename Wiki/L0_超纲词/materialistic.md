# materialistic

> [!info] 基础信息
> **音标** /məˌtɪəriəˈlɪstɪk/ | **词级** 超纲词 | **语义场** [[理性世界]]

## 核心释义

**adj.** ①==**物质主义的，贪图物质享受的**== `be adj prep N` [贬义]；②==**唯物主义的**== `adj N` [正式/哲学]；

> [!tip] 原型义
> **原型义**：物质主义的（以物质追求为导向的）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（字面义即核心义）

## 词根词缀

material（物质）+ -ist（人）+ -ic（形容词后缀，……的）→ 物质主义者的→ 物质主义的
**叙事**：material（物质）+ -ist + -ic → 像物质主义者一样的 → 贪图物质享受的。一个 materialistic 的人只关心名牌、豪车、大房子——一切以物质衡量。

## 词义链路

> [!abstract]- 词义链路法
> 以"**物质主义的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **物质主义的**（价值观层面）
>    - → **贪图物质享受的**：过度追求物质财富
>      - 激活条件：a materialistic society, materialistic values
>    - → **唯物主义的**：哲学上认为物质是第一性的
>      - 激活条件：materialistic philosophy

### 统筹（选择适用的模式）

- **一字一词概括**：materialistic 就是"物欲的"——以物质追求为核心的
- **延伸中心**：从"物质主义价值观"延伸到"哲学唯物主义"

> [!check]- 链路验证
> - [x] **可逆性**：从"贪图物质享受的"能反向推导到"物质主义的"
> - [x] **可统筹**：一句话——"materialistic 就是以物质追求为导向的"
> - [x] **有支撑**：materialistic society, materialistic values 均有语料支撑
