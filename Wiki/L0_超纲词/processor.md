# processor

> [!info] 基础信息
> **音标** /ˈprəʊsesə/ | **词级** 超纲词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**处理器，中央处理器（CPU）**== `N`；②==**加工者，处理者**== `N`；③==**数据处理程序**== `N`；

> [!tip] 原型义
> **原型义**：处理的人/机器（处理信息、数据或原料）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接描述功能角色）

## 词根词缀

[[pro]]（pro-，向前/进行）+ [[cess]]（走，拉丁语 *cedere*）+ -or（人/物）= 向前走的人/物→处理者→处理器
**叙事**：pro（向前）+ cess（走）= process（处理/过程）→ processor（处理器）。电脑的大脑就是 processor（CPU）——它处理所有信息。食品加工厂里的工人也是 processor——加工者。

## 词义链路

> [!abstract]- 词义链路法
> 以"**处理信息/数据的人或机器**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **处理者**（功能层面）
>    - → **处理器（CPU）**：电脑中处理信息的核心芯片
>      - 激活条件：dual-core processor, processor speed
>    - → **加工者**：处理原料的人
>      - 激活条件：food processor, data processor

### 统筹（选择适用的模式）

- **一字一词概括**：processor 就是"处理器"——处理信息或数据的人/机器
- **延伸中心**：从"信息处理芯片"延伸到"加工者"

> [!check]- 链路验证
> - [x] **可逆性**：processor = process(处理) + -or(人/物)，含义直接
> - [x] **可统筹**：一句话——"processor 就是处理信息或数据的人或机器"
> - [x] **有支撑**：processor speed, CPU 为常见搭配
