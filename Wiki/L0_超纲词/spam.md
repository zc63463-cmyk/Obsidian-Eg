# spam

> [!info] 基础信息
> **音标** /spæm/ | **词级** 超纲词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**垃圾邮件，垃圾信息**== `N`；②==**（品牌）斯帕姆午餐肉**== `N`；
**v.** ①==**向……发送垃圾信息**== `V`；②==**大量发送（垃圾信息）**== `V`；

> [!tip] 原型义
> **原型义**：大量重复发送的不请自来的电子消息（源自 Monty Python 喜剧中的 SPAM 罐头恶搞）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（将"无处不在的午餐肉"映射为"无处不在的垃圾信息"）

## 词根词缀

spam（源自 SPAM 午餐肉品牌名，后因 Monty Python 喜剧小品中反复出现"Spam"一词而成为"垃圾信息"的代名词）
**叙事**：SPAM 原是一个午餐肉品牌。Monty Python 的喜剧小品中，餐厅菜单上每道菜都含 SPAM，"Spam"这个词被反复念叨到令人厌烦。互联网用户借用这个梗，把大量重复、不请自来的邮件称为 spam。现在 spam 包括垃圾邮件、垃圾短信、垃圾评论等一切垃圾信息。

## 词义链路

> [!abstract]- 词义链路法
> 以"**垃圾邮件，垃圾信息**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **午餐肉品牌**（物理层面）
>    - → **垃圾邮件**：大量重复的不请自来的邮件
>      - 激活条件：spam email, spam filter
>    - → **垃圾信息**：扩展到一切垃圾信息
>      - 激活条件：comment spam, spam messages
>    - → **发送垃圾信息**：动词用法
>      - 激活条件：stop spamming, spam someone's inbox

### 统筹（选择适用的模式）

- **一字一词概括**：spam 就是"垃圾"——垃圾邮件、垃圾短信、垃圾评论
- **延伸中心**：从"垃圾邮件"延伸到"一切垃圾信息"
- **一句话统筹**：spam 就是不请自来、大量重复、令人厌烦的信息

> [!check]- 链路验证
> - [x] **可逆性**：从"垃圾评论"能反向推导到"垃圾邮件"——都是不请自来的垃圾信息
> - [x] **可统筹**：一句话——"spam 就是不请自来的大量重复信息"
> - [x] **有支撑**：spam email, spam filter, spam comments 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> SPAM 原是午餐肉品牌。Monty Python 喜剧中小丑反复喊"Spam! Spam! Spam!"——就像你的邮箱里每天收到的垃圾邮件一样，"优惠！中奖！贷款！"反复出现，令人崩溃。所以 spam 成了"垃圾信息"的代名词。
>
> **词拆分记忆**（辅助）：
> spam → 谐音"死拍母"→ 死命拍广告给你妈 → 垃圾信息
