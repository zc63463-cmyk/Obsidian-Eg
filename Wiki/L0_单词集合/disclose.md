# disclose

> [!info] 基础信息
> **音标** /dɪsˈkləʊz/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**vt.** ①==**揭露，泄露**==（秘密/信息） ; ②==**公开，透露**== ;

> [!tip] 原型义
> **原型义**：打开覆盖物、移除遮挡
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（揭露秘密 = 打开覆盖物）

## 词根词缀

dis-(打开/移除) + [[close/clus|close]](关闭/覆盖) → 移除覆盖
**叙事**：把覆盖的东西移开 → 揭露、公开。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**移除覆盖**"为统筹中心，沿空间路径向外扩展：
>
> 1. **移除覆盖**（物理层面：打开遮挡物）
>    - → **揭露/泄露**：移除信息的"覆盖" → 激活条件：秘密、丑闻被曝光
>    - → **公开/透露**：主动移除信息的遮挡 → 激活条件：官方、机构发布信息

### 统筹（选择适用的模式）

- **一字一词概括**："揭"——揭开
- **一句话统筹**：从物理上移除遮挡到信息上揭露秘密，都是"揭开"

> [!check]- 链路验证
> - [x] **可逆性**：揭露秘密 → 移除信息的覆盖 → 移除覆盖
> - [x] **可统筹**：所有义项围绕"移除覆盖/揭开"
> - [x] **有支撑**：disclose information / refuse to disclose 为常见搭配

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**：
> dis（打开/移除）+ close（关闭/覆盖）→ 把关闭的东西打开 → 揭露。想象你打开一个上锁的箱子，里面藏着秘密文件。
>
> **词拆分记忆**：
> dis + close（关闭）→ 不关闭 → 打开 → 揭露
