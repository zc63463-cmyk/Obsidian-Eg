# condense

> [!info] 基础信息
> **音标** /kənˈdens/ | **词频** 考研中频 | **语义场** [[自然物理]]

## 核心释义

**v.** ①==**浓缩，压缩**==（液体/文章） ; ②==**凝结，冷凝**==（气体变液体） ;

> [!tip] 原型义
> **原型义**：使变密集、使密度增大
> **延伸维度**：空间路径
> **隐喻类型**：本体隐喻（信息 = 物质，可被压缩）

## 词根词缀

con-(加强) + [[dens|dens/dens]](密集/浓厚) + -e(动词后缀)
**叙事**：使物质变得更密集 → 浓缩、凝结。

建议创建词根笔记 [[dens/dens]]

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**使变密集**"为统筹中心，沿空间路径向外扩展：
>
> 1. **使变密集**（物理层面：增大物质密度）
>    - → **凝结/冷凝**：气体分子变密集成为液体 → 激活条件：物理/化学语境
>    - → **浓缩/压缩**：信息/液体变得更密集 → 激活条件：文章、液体等需要精简时

### 统筹（选择适用的模式）

- **一字一词概括**："密"——使变密集
- **一句话统筹**：从气体凝结到文章压缩，都是"使变密集"

> [!check]- 链路验证
> - [x] **可逆性**：浓缩 → 使信息变密集 → 使变密集
> - [x] **可统筹**：所有义项围绕"使变密集"
> - [x] **有支撑**：condensed milk（炼乳）为常见搭配
