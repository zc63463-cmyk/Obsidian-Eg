# build

> [!info] 基础信息
> **音标** /bɪld/ | **词级** 必备词 | **语义场** [[物品工具]]

## 核心释义

**v.** ①==**建造，建筑**== `V N` / `V`; ②建立，构建（关系、体系等） `V N` / `V`; ③逐渐增强，发展 `V N` / `V`
 **n.** ①体格，身材  `a N` / `a N of N`; ②构造，结构 `a N` / `a N of N`
> [!tip] 原型义
> **原型义**：建造、从无到有地构建
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻——从"物理建造"投射到"抽象构建"（关系、体系、信任等）

## 词根词缀

build 为日耳曼语族基础词汇，与 [[budget]] 同源（都来自"建造/构建"的概念族）
**叙事**：从一块砖到一栋楼，从一句话到一段**关系**——**建造**（build）就是从无到有地把东西**构建**起来。你的身体也是一种**构造**（build），你的信心需要**逐渐增强**（build up）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**建造、构建**"为统筹中心，沿具身路径向外扩展：
>
> 1. **建造**（物理层面：建造建筑物）
>    - → **建立，构建**：<抽象事物的"建造">
>      - 激活条件：搭配 relationship, system, confidence，抽象语境
>    - → **逐渐增强，发展**：<像建房一样逐步累积>
>      - 激活条件：搭配 up，搭配 tension, pressure, momentum
>    - → **体格，构造**：<身体的"建造"结果>
>      - 激活条件：名词用法，搭配 medium, heavy

### 统筹（选择适用的模式）

- **延伸中心**："建造"→ 建造建筑 → 建造关系 → 建造气势 → 建造结果（体格）
- **v + 不同宾语**：build a house（建房）→ build a relationship（建立关系）→ build confidence（建立信心）

> [!check]- 链路验证
> - [x] **可逆性**：从"建立关系"可反向推导——像建房一样构建 → 建造
> - [x] **可统筹**：所有义项都围绕"从无到有地构建"
> - [x] **有支撑**：build up / build a relationship 为考研高频用法

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> 想象一个建筑师**建造**（build）大楼——他一块砖一块砖地垒起来。同样，你**建立**（build）友谊需要一天天积累，你的身体**构造**（build）也是日积月累的结果。与 **budget**（预算）同源——因为预算就是为建造做资金规划。

## 搭配与短语

> [!example]- 搭配
> - **build up**：逐步建立，增强（She has built up a successful business over the years. 多年来她逐步建立了一家成功的企业。）
> - **build a relationship/confidence**：建立关系/信心（Building confidence in public speaking takes practice. 建立公开演讲的信心需要练习。）
> - **build on**：基于……发展（We should build on our previous achievements. 我们应该在已有成就的基础上继续发展。）
