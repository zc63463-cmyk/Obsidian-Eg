# vulgar

> [!info] 基础信息
> **音标** /ˈvʌlɡə/ | **词级** 必备词 | **语义场** [[社会习俗]]

## 核心释义

**adj.** ①==**粗俗的，庸俗的**== ; ②无教养的，粗鲁的 ;

> [!tip] 原型义
> **原型义**：普通大众的（拉丁语 vulgaris "属于平民的"）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（平民的→未经修饰的→粗俗的）

## 词根词缀

vulg-(普通大众，平民) + -ar(形容词后缀，表示"……的")
**叙事**：在古罗马，**普通平民**（vulg-）的语言和行为未经上层社会的修饰，被贵族视为**粗俗的**（vulgar）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**普通大众的**"为统筹中心，沿社会路径向外扩展：
>
> 1. **普通大众的**（社会层面——属于普通平民的）
>    - → **粗俗的，庸俗的**：平民文化被上层视为缺乏品位
>      - 激活条件：vulgar language / vulgar behavior
>    - → **无教养的，粗鲁的**：行为举止不符合上层礼仪
>      - 激活条件：a vulgar person / vulgar jokes

### 统筹（选择适用的模式）

- **一字一词概括**："俗"——普通→粗俗
- **延伸中心**："平民→缺乏品位"这一社会阶层判断贯穿所有义项

> [!check]- 链路验证
> - [x] **可逆性**：粗俗的→缺乏品位的→普通平民的，可逆
> - [x] **可统筹**："俗"字可串联所有义项
> - [x] **有支撑**：vulgar display of wealth（庸俗的炫富）、vulgar jokes（粗俗的笑话）

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 拉丁语 vulgaris 意为"属于平民的"。古罗马贵族认为平民的语言和行为缺乏教养，所以 vulgar 从"平民的"变成了"**粗俗的**"。就像中文里"俗"本来只是"大众的"，后来变成了"庸俗"。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> vulg(大众) + ar(的) → 大众的 → **粗俗的**
