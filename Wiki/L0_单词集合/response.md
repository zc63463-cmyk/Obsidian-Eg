# response

> [!info] 基础信息
> **音标** /rɪˈspɒns/ | **词频** 考研高频 | **语义场** [[行为态度]]

## 核心释义

**n.** ①==**回答，回应**==；②反应，响应；③（对治疗等的）反应；

> [!tip] 原型义
> **原型义**：回过头承诺的结果（回应的内容/行为）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（将"回过头承诺"的名词化结果映射为"回应/反应"）

## 词根词缀

re-(回/再) + spons(=spond, 承诺，拉丁语过去分词 *responsus*) = response
**叙事**：re（回）+ spons（承诺）→ 回过头来**承诺的结果** → 回应。[[respond]] 是动作，[[response]] 是结果。你 respond 了，你的 respond 就是 response。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**回过头承诺的结果（回应）**"为统筹中心，沿社会路径向外扩展：
>
> 1. **回过头承诺的结果**（语言层面）
>    - → **回答，回应**：回应的内容
>      - 激活条件：in response to, a quick response, written response
>    - → **反应，响应**：对事件的反应
>      - 激活条件：immune response, emergency response
> 2. **回过头承诺的结果**（身体层面）
>    - → **（对治疗等的）反应**：身体对药物的反应
>      - 激活条件：patient's response to treatment

### 统筹（选择适用的模式）

- **一字一词概括**：response 就是"回应的结果"——语言上的回应叫"回答"，事件上的回应叫"反应"，身体上的回应叫"疗效反应"
- **延伸中心**：从语言回应的结果延伸到身体反应的结果

> [!check]- 链路验证
> - [x] **可逆性**：从"免疫反应"能反向推导到"回过头承诺的结果"——免疫系统对入侵做出回应
> - [x] **可统筹**：一句话——"response 就是回应的结果"
> - [x] **有支撑**：in response to, immune response 均有语料支撑
