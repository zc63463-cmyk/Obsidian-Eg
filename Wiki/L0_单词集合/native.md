# native

> [!info] 基础信息
> **音标** /ˈneɪtɪv/ | **词频** 考研高频 | **语义场** [[社会习俗]]

## 核心释义

**adj.** ①==**本地的，本国的**== ; ②==**天生的，天赋的**== ; ③出生地的 ;
**n.** ①==**本地人，土生土长的人**== ;

> [!tip] 原型义
> **原型义**：出生地的（来自拉丁语 *nativus*，*nasci* "出生"的过去分词）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（以"出生"隐喻"天赋/本质"）

## 词根词缀

[[nat/nasc|nat-]]（出生）+ -ive（形容词后缀，表"有……倾向的/……的"）
**叙事**：你在哪里**出生**（nat），哪里就是你的 **native** land（祖国）；你**出生**时就有的才能，就是你的 **native** ability（天赋）。native 的灵魂是"与生俱来"。

建议创建词根笔记 [[nat/nasc]]（出生）

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**出生地的**"为统筹中心，沿社会路径向外扩展：
>
> 1. **出生地的**（空间/地缘层面）
>    - → **本地的，本国的**：与出生地相关的
>      - 激活条件：描述语言、物种、文化等的地域归属时
>    - → **天生的，天赋的**：从"出生时就有的"到"与生俱来的才能"（隐喻）
>      - 激活条件：描述才能、能力、性格等天赋特征时
>    - → **本地人**：在出生地长大的人（名词化）
>      - 激活条件：描述某地的原住民/本地人时

### 统筹（选择适用的模式）

- **一字一词概括**：生——出生地的→本地的→天生的
- **延伸中心**：以"出生"为核心，从地理归属延伸到天赋本质

> [!check]- 链路验证
> - [x] **可逆性**：从"天生的"可反向推导到"出生时就有的"
> - [x] **可统筹**："与出生相关"统摄所有义项
> - [x] **有支撑**：native speaker（母语者）、native ability（天赋）、native land（祖国）
