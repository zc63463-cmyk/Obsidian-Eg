# message

> [!info] 基础信息
> **音标** /ˈmesɪdʒ/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**消息，信息**== ; ②（政治/社会）启示，要旨，寓意 ;
**v.** ①给…发信息，留言 ;

> [!tip] 原型义
> **原型义**：送出（mit-/mess-）的东西（-age）——从一个人送到另一个人的信息
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻——将抽象的"思想传递"比作"物理上的物品传送"

## 词根词缀

mit-/mess-(送/放，来自拉丁语 mittere) + -age(名词后缀，表示集合/结果)
**叙事**：一个人把想法"送"到另一个人那里，中间传递的就是"消息"。

---

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**送出的信息**"为统筹中心，沿社会路径向外扩展：
>
> 1. **送出的信息**（沟通层面）
>    - → **消息，信息**（日常层面）：人与人之间传递的具体内容
>      - 激活条件：日常沟通、电话留言、短信等
    - → **启示，要旨，寓意**（深层层面）：信息背后的核心思想
      - 激活条件：演讲、文学作品、社会运动传达的核心观点时

### 统筹（选择适用的模式）

- **一字一词概括**："信息"——从具体消息到深层寓意
- **延伸中心**：从表面信息到深层含义，核心特征是"传递的内容"
- **一句话统筹**：从一个人传到另一个人的信息，可以是具体消息也可以是深层寓意

> [!check]- 链路验证
> - [x] **可逆性**：从"寓意""要旨"可反向推导到"传递的信息"
> - [x] **可统筹**：一句话"传递的信息"串联所有义项
> - [x] **有支撑**：真题中既见 text message，也见 the message of the speech

> **联想**：与 [[mess]]、[[messenger]] 同源。message = 送出的东西（消息）；mess = 放在一起（混乱）；messenger = 送东西的人（信使）。
