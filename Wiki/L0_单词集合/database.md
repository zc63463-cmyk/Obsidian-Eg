# database

> [!info] 基础信息
> **音标** /ˈdeɪtəbeɪs/ | **词级** 必备词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**数据库**==；②（非正式）==**信息库，资料库**==；

> [!tip] 原型义
> **原型义**：数据的基座/存放处（存放和管理结构化数据的系统）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（建筑的"基座" → 信息的"存储基础"）

## 词根词缀

**词根拆分**：[[data]]（数据，给定的事实）+ [[base]]（基础，基座）

**词源关联**：database 是一个英语复合词，由 data + base 构成，20 世纪 60 年代随计算机技术发展而产生。data 源自拉丁语 *datum*（给定的东西），是 *dare*（给予）的过去分词；base 源自拉丁语 *basis*（基座、底部），来自希腊语 *bainein*（走、站立）。database 的字面义就是"数据的基座"——存放数据的"地基"。1962 年前后开始出现 database system 的用法，1966 年出现 database management system。

**叙事**：想象一座巨大的图书馆——但里面存放的不是书，而是**数据**（data）。这座图书馆的**地基**（base）就是 database。每一个数据都整整齐齐地排列在"书架"上，随时可以被**检索**、**调用**、**更新**。从 20 世纪 60 年代的第一代数据库到今天的云端大数据，database 始终是信息世界的"地基"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**数据的基座/存放处**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **数据的基座/存放处**（技术层面）
>    - → **数据库**：计算机系统中组织、存储和管理数据的系统
>      - 激活条件：database management system, access a database
> 2. **数据的基座/存放处**（日常引申层面）
>    - → **信息库，资料库**：任何系统化的信息集合
>      - 激活条件：a database of knowledge, customer database

### 统筹（选择适用的模式）

- **延伸中心**：database 的核心特征是"系统化存放数据的基座"，所有用法都共享这个本质——无论是计算机数据库还是日常的信息库，都是"有组织地存放和检索信息的系统"
- **一句话统筹**："database 就是数据的家——有组织、有结构、随时可取"

> [!check]- 链路验证
> - [x] **可逆性**：从"信息库"能反向推导到"数据的基座"——信息库就是存放数据的"地基"
> - [x] **可统筹**：一句话统筹——"database 就是有组织地存放数据的系统"
> - [x] **有支撑**：database management system, customer database, search a database 均为考研常见搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> database 是 data（数据）+ base（基座）的完美组合。想象一座大厦，**地基**（base）里存放着所有的**数据**（data）——这就是 database。你的手机通讯录是一个 database，图书馆的检索系统是一个 database，互联网本身就是一个超级 database。记住：data 是"被给予的信息"，base 是"地基"，database 就是"信息的家"。
>
> **复合词拆分**（辅助）：
> data（数据，拉丁语"给予"）+ base（基础，希腊语"站立"）→ 数据的基础 → 数据库
