# description

> [!info] 基础信息
> **音标** /dɪˈskrɪpʃn/ | **词级** 必备词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**描述，描写**== ; ②种类，类型 ;

> [!tip] 原型义
> **原型义**：写下来的东西（描述的文字内容）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（文字记录是对现实的"书写"）

## 词根词缀

[[de]](向下/完全) + [[scrib|scrib-scrib]](写) + -tion(名词后缀，表动作结果)
**叙事**：完全地**写**（scrib）**下**来（de）的**结果**（-tion）→ **描述**的文字内容。

建议创建词根笔记 [[scrib]]

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**写下来的内容**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **写下来的内容**（文字记录）
>    - → **描述，描写**：用文字记录事物的特征
>      - 激活条件：描述某事物的文字内容
>    - → **种类，类型**：对事物进行分类描述的标签
>      - 激活条件：of all descriptions / of every description 等固定搭配

### 统筹（选择适用的模式）

- **一字一词概括**："写"——写下来的内容就是描述
- **延伸中心**："书写记录"贯穿描述和分类

> [!check]- 链路验证
> - [x] **可逆性**：从"种类"可回溯到"对事物的文字归类描述"
> - [x] **可统筹**："写下来的内容"统一两个义项
> - [x] **有支撑**：beyond description / of every description 均为常见搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> [[describe]]（描述）的名词形式。你**描述**（describe）一件事后，写下来的文字就是 **description**（描述）。就像画家画完一幅画后，画本身就是对风景的"描述"。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> de(详细地) + script(脚本/文字) + ion(名词) → 详细的文字脚本 → **描述**

## 搭配与短语

> [!example]- 搭配 · L3
> - **beyond description**：The beauty of the sunset was beyond description. 日落的美丽无法用言语形容。
> - **of every description**：People of every description attended the meeting. 各行各业的人参加了会议。

## 真题/语料关联

> [!example]- 语料 · L3

> - "The job description failed to mention the long working hours."（职位描述没有提到工作时间很长。）——考研高频表达
