# token

> [!info] 基础信息
> **音标** /ˈtəʊkən/ | **词频** 考研中频 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**象征，标志**== ; ②信物，纪念品 ; ③代价券，代币
**adj.** ①象征性的，装样子的

> [!tip] 原型义
> **原型义**：标记、符号、象征
> **延伸维度**：抽象路径
> **隐喻类型**：本体隐喻（用具体物件代表抽象概念/关系）

%% HERMES-L0: 判定原型义(物理动作优先>最具体义项优先>最早学到优先>词源义参考) %%

## 词根词缀

to-(朝向) + -ken(古英语"显示、表明"的词根)
**叙事**：用来向他人展示的东西，就是"标记、象征"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**标记、符号**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **标记、符号**（物理层面：看得见的标志物）
>    - → **象征、标志**（抽象层面：代表某种意义或关系）
>      - 激活条件：描述某物代表某种抽象概念（如 a token of appreciation）
>    - → **信物、纪念品**（情感层面：承载情感记忆的物件）
>      - 激活条件：描述作为纪念或情感纽带的小物件
>    - → **代币、代价券**（制度层面：替代货币的凭证）
>      - 激活条件：描述交易或通行凭证
>    - → **象征性的**（形容词：仅具形式而无实质）
>      - 激活条件：描述表面化的、敷衍的行为

### 统筹（选择适用的模式）

- **一字一词概括**：以"代表"为核心，一个"代"字概括所有义项——代币、代表、代替
- **延伸中心**：以"替代/代表"为特征，从物理标记延伸到抽象象征、情感信物、制度代币

> [!check]- 链路验证
> - [x] **可逆性**：从"象征性的"可反向推导到"标记"（只有标记的形式而无实质）
> - [x] **可统筹**：一句话"用一物代表另一物"串联所有义项
> - [x] **有支撑**：考研中"a token of..."为高频搭配

## 搭配与短语

> [!example]- 搭配 · L3
> - **a token of**：...的象征（As a token of our gratitude, we present this gift.）
> - **by the same token**：同样地、出于同样原因（By the same token, we should also consider the environmental impact.）
> - **token gesture**：象征性姿态（The apology was merely a token gesture.）
