# command

> [!info] 基础信息
> **音标** /kəˈmɑːnd/ | **词频** 考研高频 | **语义场** [[学术职业]]

## 核心释义

**v.** ①==**命令，指挥**==；②掌握，控制；③值得，应得（尊敬等）；④俯瞰，鸟瞰；
**n.** ①命令，指令；②指挥权，控制权；③掌握，运用能力；

> [!tip] 原型义
> **原型义**：下令让别人执行——具有权威性的指令
> **延伸维度**：社会路径——从军事命令延伸到控制权、掌握能力、值得尊敬
> **隐喻类型**：结构隐喻（军事指挥 = 知识/资源的掌控）

## 词根词缀

com-(完全，加强) + mand(命令，委托，[[mand]]变体)
**叙事**：完全地"委托/命令"别人去做——将军命令士兵，知识"命令"你的尊重。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**命令、指挥**"为统筹中心，沿社会路径向外扩展：
>
> 1. **命令、指挥**（权力层面——上级对下级的权威指令）
>    - → **掌握、控制**：能力化——对知识、资源的"指挥权"
>      - 激活条件：搭配 command respect / command attention
>    - → **值得、应得**：评价化——因为优秀而"拥有"别人的尊敬
>      - 激活条件：搭配 command respect / command support
>    - → **掌握、运用能力**（名词）：对技能/语言的驾驭
>      - 激活条件：搭配 have a good command of English

### 统筹（选择适用的模式）

- **一句话统筹**：command 的核心是"拥有权威性的控制力"——命令是控制人，掌握是控制知识，值得是控制尊重。

> [!check]- 链路验证
> - [x] **可逆性**：从"值得尊敬"回溯——值得尊敬是因为拥有权威→权威来自命令权→command
> - [x] **可统筹**：所有义项共享"权威性控制"这一核心
> - [x] **有支撑**：军事命令（权力）→控制权（社会）→掌握能力（知识）→值得尊敬（评价），路径清晰

## 搭配与短语

> [!example]- 搭配 · L3
> - **have a good command of**：精通……
  - She has a good command of both English and French.（她精通英语和法语。）
- **command respect**：赢得尊敬
  - His integrity commands respect from everyone.（他的正直赢得了每个人的尊敬。）
- **chain of command**：指挥链
  - Every soldier must follow the chain of command.（每个士兵都必须遵循指挥链。）

## 真题/语料关联

> [!example]- 语料 · L3
> > - "A good leader should have a clear command of the situation."（一位优秀的领导者应该对局势有清晰的掌控。）——考研阅读真题
> - "She has an excellent command of both spoken and written English."（她的英语口语和书面语都掌握得非常好。）——考研高频表达
