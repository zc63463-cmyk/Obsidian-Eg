# try

> [!info] 基础信息
> **音标** /traɪ/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**尝试，试图**== ; ②试用，试验 ; ③审问，审判 ;
**n.** ①==**尝试，努力**== ;

> [!tip] 原型义
> **原型义**：用力搓揉，筛选（古法语 trier，分拣、筛选）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（物理筛选→在行动中筛选出可行方案）

## 词根词缀

try 为日耳曼语族本族词，源自古法语 trier（分拣、筛选）。
**叙事**：在沙子里**筛选**金子（try），要一遍遍尝试才能找到——所以 try 就是**尝试**。

## 词义链路

> [!abstract]- 词义链路法
> 以"**筛选，分拣**"为统筹中心，沿具身路径向外扩展：
>
> 1. **筛选，分拣**（物理层面——从混合物中挑出有用的）
>    - → **尝试，试图**：在多种方案中"筛选"出可行的
>      - 激活条件：try to do / try doing
>    - → **试用，试验**：通过实际使用来"筛选"好坏
>      - 激活条件：try a new method / try on clothes
>    - → **审问，审判**：在法庭上"筛选"真相
>      - 激活条件：try a case / stand trial

### 统筹（选择适用的模式）

- **一字一词概括**："试"——筛选出可行方案
- **延伸中心**："筛选→检验"这一结构隐喻贯穿所有义项

> [!check]- 链路验证
> - [x] **可逆性**：审判→在法庭上筛选真相→物理筛选，可逆
> - [x] **可统筹**："试/筛选"可串联所有义项
> - [x] **有支撑**：try one's best（尽力）、try a new approach（尝试新方法）、try a criminal（审判罪犯）

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> 古法语 trier 意为"分拣、筛选"。淘金者在沙河中一遍遍**筛选**（try）沙砾，试图找到金子——每一次筛选都是一次**尝试**。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> try → 想象你在自助餐厅**试**吃（try）每道菜，从中**筛选**出最好吃的。
