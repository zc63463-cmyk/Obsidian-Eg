# following

> [!info] 基础信息
> **音标** /ˈfɑːloʊɪŋ/ | **词频** 考研高频 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**接下来的，其后的**；②下述的；
**n.** ①一批追随者，拥护者；②（与 the 连用）下面的内容；
**prep.** ①在……之后（时间上）；

> [!tip] 原型义
> **原型义**：在时间或顺序上紧接其后的
> **延伸维度**：时间路径——从"跟随"的时间化出发
> **隐喻类型**：方位隐喻（将"在后"映射为"在时间上随后"）

## 词根词缀

无明确前缀 + 无明确词根（源自 [[follow]]） + -ing（现在分词/形容词后缀，表示"正在进行或具有……性质的"）
**叙事**：跟在后面发生的事情——following 就是"接下来的"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**紧随其后的**"为统筹中心，沿时间路径向外扩展：
>
> 1. **紧随其后的**（时间层面——在……之后）
>    - → **接下来的**：<时间上紧接的，如 the following day>
>      - 激活条件：描述时间顺序上的下一个
>    - → **下述的**：<文本顺序上的"接下来"，如 the following points>
>      - 激活条件：列举或引用时引出下文
>    - → **追随者/拥护者**：<跟随某人的人，名词化>
>      - 激活条件：描述某人的支持者群体，如 a large following

### 统筹（选择适用的模式）

- **一句话统筹**：following 从"跟在后面"这个动作出发，时间化后变成"接下来的"，文本化后变成"下述的"，人化后变成"追随者"——始终是"跟随"的延伸。

> [!check]- 链路验证
> - [x] **可逆性**：跟随→接下来的→下述的→追随者，每一步都保留了"在后跟随"的核心
> - [x] **可统筹**：所有义项都围绕"跟在后面"这一核心关系
> - [x] **有支撑**：the following year、the following is... 都是高频用法

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> following 就是 follow 的"进行时"——正在跟随的东西就是"接下来的"，跟随你的人就是"追随者"。
>
> **词拆分记忆**（辅助）：
> follow + -ing → 跟随 + 正在 → 正在跟随的 → 接下来的
