# abstract

> [!info] 基础信息
> **音标** /ˈæbstrækt/（n./adj.）/əbˈstrækt/（v.） | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**抽象的**== `adj N` [通用]；②==**理论上的**== `adj N` [学术]；
**n.** ①==**摘要，梗概**== `N of N` [学术]；
**vt.** ①==**提取，抽取**== `V N from N` [科学]；②==**写…的摘要**== `V N` [学术]；

> [!tip] 原型义
> **原型义**：从具体中拉离（abs- 离开 + tract 拉 → 从具体事物中拉出来）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"从具体中拉离"→"抽象的"（非具体的）；"拉出要点"→"摘要"）

## 词根词缀

**abs-**（离开、远离，ab- 在 s 前的同化形式）+ **tract**（拉、拖，源自拉丁语 *trahere*，与 [[attract]]、[[extract]] 同源）

**叙事**：你从一棵具体的树中"拉出"树的本质特征——这就是 abstract 的原始画面。从"拉离具体事物"这个核心动作出发，引申出"抽象的"（非具体的），再延伸到"提取精华"和"写摘要"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**从具体中拉离**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **从具体中拉离**（认知层面）
>    - → **抽象的**：脱离具体形象的概念
>      - 激活条件：描述非具体的概念、艺术、理论时（abstract concept, abstract art）
>    - → **理论上的**：脱离实际的
>      - 激活条件：讨论理论与实际对比时（in the abstract）
> 2. **从具体中拉离**（动作层面）
>    - → **提取，抽取**：从整体中拉出部分
>      - 激活条件：描述提取数据/信息时（abstract information）
> 3. **从具体中拉离**（文本层面）
>    - → **摘要**：从全文中提取要点
>      - 激活条件：学术写作中（an abstract of the paper）

### 统筹（选择适用的模式）

- **一字一词概括**：以"**拉离**"为统筹中心——无论是从具体中拉离得到抽象概念，还是从全文中拉离得到摘要，都是 abstract
- **延伸中心**：从"从具体中拉离"出发，沿抽象路径延伸到"抽象概念"和"摘要"

> [!check]- 链路验证
> - [x] **可逆性**：从"摘要"能反向推导到"从具体中拉离"——摘要就是从全文中提取要点
> - [x] **可统筹**：一句话统筹——"abstract 就是从具体中拉离，提取本质"
> - [x] **有支撑**：abstract art, abstract information, write an abstract 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> abs（离开）+ tract（拉）= 从具体中拉离 = 抽象的。从具体事物中拉离出来，得到的就是抽象概念；从全文中拉出要点，就是摘要。
>
> **词族记忆**（辅助）：
> [[attract]]（吸引 = 拉过来），[[extract]]（提取 = 拉出来），[[distract]]（分散 = 拉向不同方向），[[contract]]（收缩 = 拉到一起）。注意作名词/形容词时重音在前 /ˈæbstrækt/，作动词时重音在后 /əbˈstrækt/。
