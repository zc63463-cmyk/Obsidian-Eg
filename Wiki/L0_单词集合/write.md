# write

> [!info] 基础信息
> **音标** /raɪt/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**vt.** ①==**写，书写**== `V N`；②==**写作，作曲**== `V N to N`；③==**写信给**== `V N`；④==**填写（表格等）**== `V N to N`；
**vi.** ①==**写，写字**== `V`；②==**写作**== `V prep N`；③==**写信**== `V`；

> [!tip] 原型义
> **原型义**：用工具在表面上刻画符号（将思想通过符号记录下来）
> **延伸维度**：具身路径
> **隐喻类型**：实体隐喻（从"物理刻画"→"创作文学作品/撰写文件"的抽象表达）

## 词根词缀

**词源关联**：write 源自古英语 *wrītan*（刻画、划线、书写），源自原始日耳曼语 *\*writan*（刮、划、刻），与古弗里西亚语 *writa*、古诺尔斯语 *rita*（写、刮、勾勒）、古高地德语 *rizan*（写、刮、撕裂）同源。其原始日耳曼语词根本义是"刮/刻"，因为在没有纸的时代，人们通过在木头或石头上刻画来记录信息。与德语 *reißen*（撕裂、素描）有亲缘关系。

**叙事**：在远古时代，人们没有纸笔，想要记录什么，就拿刀在木头上**刮刻**（原始日耳曼语 *\*writan*）。刮出来的痕迹就是最早的"文字"。后来有了笔和纸，"刮刻"变成了"书写"（write），但本质没变——都是在表面上留下符号来传递思想。从刻木记事到写小说、写代码、写邮件，write 一直在做同一件事：把脑子里的东西变成别人能看到的东西。

## 词义链路

> [!abstract]- 词义链路法
> 以"**用工具在表面上刻画符号**"为统筹中心，沿具身路径向外扩展：
>
> 1. **用工具在表面上刻画符号**（物理动作层面）
>    - → **书写，写字**：用笔在纸上写字
>      - 激活条件：日常书写、写字、做笔记
>    - → **填写（表格）**：在表格上写入信息
>      - 激活条件：fill in / write a check / write a form
> 2. **用工具在表面上刻画符号**（创作表达层面）
>    - → **写作，著述**：创作文章、书籍等文学作品
>      - 激活条件：write a book / write an essay / write a poem
>    - → **作曲**：创作音乐作品
>      - 激活条件：write a song / write music
>    - → **写信**：通过书写进行远程交流
>      - 激活条件：write to sb / write a letter
> 3. **用工具在表面上刻画符号**（引申表达层面）
>    - → **write off**：注销、认为不行（把某物从记录中划掉）
>      - 激活条件：商业语境、评价语境
>    - → **write down**：记下、记录（把信息写下来固定）
>      - 激活条件：记录信息、做笔记

### 统筹（选择适用的模式）

- **实体隐喻统筹**：write 的核心动作是"在表面上留下符号"，所有引申义都共享这个结构——无论是写字、写书、写歌还是写信，都是"把内在的思想转化为外在的符号"
- **延伸中心**：从具身的"刻画/书写"动作出发，沿实体隐喻路径延伸到"创作/表达"的抽象行为

> [!check]- 链路验证
> - [x] **可逆性**：从"写作"能反向推导到"刻画"——写作就是在纸上"刻画"你的思想
> - [x] **可统筹**：一句话统筹——"write 就是把脑子里的东西变成别人能看到的符号"
> - [x] **有支撑**：write a letter, write a book, write off, write down 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> write 的祖先是原始日耳曼语 *\*writan*，意思是"刮、刻"。想象远古人类拿着石刀在木头上刮刻记号——那就是最早的"写"。后来有了羽毛笔和羊皮纸，"刮刻"变成了"书写"，但 write 这个词一直没变。今天你 write an essay（写论文），本质上和远古人在木头上刻记号是一样的：把思想变成可见的符号。
>
> **词拆分记忆**（辅助）：
> wr（=wreak/wring，用力扭转/施加）+ ite（=ite，与动作相关）→ 用力在表面刻下痕迹 → 书写

## 搭配与短语

> [!example]- 搭配
> - **write a letter/essay/book/article**：写一封信/论文/书/文章
> - **write to sb**：给某人写信
> - **write down**：写下，记下
> - **write off**：注销（债务）；认为……不行/没有希望
> - **write back**：回信，回复
> - **write out**：全部写出，誊写
> - **write up**：详细写下来，撰写报道
> - **be written all over one's face**：（感情）明显地表现在脸上
> - **nothing to write home about**：没什么特别的，不值一提
> - **write a check**：开支票
