# create

> [!info] 基础信息
> **音标** /kriˈeɪt/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**创造，创作**== `V N`；②==**引起，产生**== `V prep N`；③设立，建立 `V N`；

> [!tip] 原型义
> **原型义**：增长（使事物从无到有地增长出来）
> **延伸维度**：时间路径
> **隐喻类型**：本体隐喻（"增长"→"创造"——从无到有的过程就是创造）

## 词根词缀

cre(=cres-, 增长，拉丁语 *crescere*) + -ate(动词后缀，使……)
**叙事**：cre（增长）+ -ate（使）→ 使事物增长出来 → **创造**。从一颗种子"增长"成一棵树，就是 create 的原始画面。上帝 create 世界，就是让世界从无到有地"增长"出来。建议创建词根笔记 [[cre-cresc-cret]]（增长，拉丁语 *crescere*）。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**增长（使从无到有）**"为统筹中心，沿时间路径向外扩展：
>
> 1. **增长**（从无到有的过程）
>    - → **创造，创作**：使新事物从无到有地产生
>      - 激活条件：create art, create a new method
>    - → **引起，产生**：使新情况从无到有地出现
>      - 激活条件：create jobs, create problems
>    - → **设立，建立**：使新机构从无到有地建立
>      - 激活条件：create a committee, create a system

### 统筹（选择适用的模式）

- **一字一词概括**：create 就是"从无到有"——从无到有地产生艺术=创造，从无到有地产生问题=引起
- **v + 不同宾语**：create art（创作）→ create jobs（创造就业）→ create problems（引起问题）

> [!check]- 链路验证
> - [x] **可逆性**：从"引起问题"能反向推导到"使问题从无到有地产生"
> - [x] **可统筹**：一句话——"create 就是使事物从无到有"
> - [x] **有支撑**：create jobs, create problems, create art 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> cre（增长）+ -ate（使）→ 使增长出来 → 创造。想象一颗种子在土壤中慢慢"增长"，最终破土而出——这就是 create 的原始画面。从一颗种子到一棵大树，从一张白纸到一幅画，从零到一个企业——create 就是"使从无到有"。
>
> **词拆分记忆**（辅助）：
> cre（生长）+ ate（吃过去式）→ 吃了就生长 → 创造
