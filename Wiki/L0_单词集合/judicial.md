# judicial

> [!info] 基础信息
> **音标** /dʒuˈdɪʃl/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**adj.** ①==**司法的，法院的**==；

> [!tip] 原型义
> **原型义**：与判断有关的→司法的（jud = 判断/法律，-ic + -ial = …性质的）
> **延伸维度**：制度路径
> **隐喻类型**：无隐喻（直接从"与判断有关"演变为"司法的"）

## 词根词缀

**词源关联**：judicial 来自拉丁语 *judicialis*（属于法庭的），来自 *judicium*（审判、判断），*judex*（法官），由 jus（法律）+ dicere（说）构成。与 **[[judge]]**（法官）、**[[judgment]]**（判断）、**[[justice]]**（正义）同源。

**叙事**：jud = 判断/法律，-ic = 与…有关的，-ial = 形容词后缀。judicial 就是"与判断/法律有关的"——具体来说就是"司法的、法院的"。它描述的是司法体系中的事物，比如 judicial system（司法系统）、judicial review（司法审查）。记住 jud = 判断/法律，judicial = 与法律判断有关的 = 司法的。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**与判断有关的→司法的**"为统筹中心，沿制度路径向外扩展：
>
> 1. **与判断有关的**（字面→制度层面）
>    - → ==**司法的，法院的**==（形容词）：属于司法体系的
>      - 激活条件：描述司法制度/程序（judicial system / judicial review / judicial process）
>    - → **审判的**（形容词）：与审判过程相关的
>      - 激活条件：描述审判活动（judicial proceedings / judicial inquiry）

### 统筹（选择适用的模式）

- **一字一词概括**：judicial = "司法的"——与法院、法律体系相关的一切
- **一句话统筹**：judicial 就是"与法律判断有关的"——司法的、法院的

> [!check]- 链路验证
> - [x] **可逆性**：从"司法的"能反向推导到"与判断有关的"——司法就是法律判断
> - [x] **可统筹**：一句话统筹——"judicial 就是与法律判断有关的"
> - [x] **有支撑**：judicial system, judicial review, judicial process 均为高频搭配
