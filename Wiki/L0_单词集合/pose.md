# pose

> [!info] 基础信息
> **音标** /pəʊz/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**造成，引起（问题、危险等）**== ; ②摆姿势 ; ③提出（问题等）
**n.** ①姿势，姿态 ;

> [!tip] 原型义
> **原型义**：放置、摆放（身体或物体到某个位置）
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻——将"摆放"从物理空间投射到抽象层面（摆放一个问题 = 造成一个问题）

## 词根词缀

[[pon/pos|pon/pos]](放置、放) — pose 本身为词根的直接体现
**叙事**：把身体**放**到某个角度就是摆**姿势**（pose），把一个问题**放**到面前就是**造成**问题（pose a threat）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**放置**"为统筹中心，沿具身路径向外扩展：
>
> 1. **放置**（物理层面：摆放身体/物体）
>    - → **摆姿势**：<把身体放置到特定姿态>
>      - 激活条件：描述模特、摄影、人物姿态时
>    - → **造成/引起**：<把问题/危险"放置"到某人面前>
>      - 激活条件：搭配 threat, danger, challenge, problem 等抽象名词
>    - → **提出（问题）**：<把问题"放置"出来供讨论>
>      - 激活条件：搭配 question, issue，用于学术或正式语境

### 统筹（选择适用的模式）

- **v + 不同宾语**：pose + body → 摆姿势；pose + threat/danger → 造成威胁；pose + question → 提出问题

> [!check]- 链路验证
> - [x] **可逆性**：从"造成问题"可反向推导——把问题"放置"到面前 → 放置
> - [x] **可统筹**：所有义项都围绕"放置"这一核心动作
> - [x] **有支撑**：pose a threat / pose a question 为考研高频用法
