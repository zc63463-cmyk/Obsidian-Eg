# hoist

> [!info] 基础信息
> **音标** /hɔɪst/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**vt.** ①==**举起，升起，吊起**== ; ②==**扯起（旗帜）**== ;
**n.** ①==**举起，吊起**== ; ②==**起重机，升降机**== ;

> [!tip] 原型义
> **原型义**：用力举起、升高
> **延伸维度**：具身路径
> **隐喻类型**：方位隐喻（升起 = 地位提高/力量增强）

## 词根词缀

hoist 为日耳曼语源词，与 [[hold]](握住) 同源，强调"握住并向上拉"的动作。
**叙事**：紧紧握住重物，用力向上拉 → 举起、吊起。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**用力举起**"为统筹中心，沿具身路径向外扩展：
>
> 1. **用力举起**（身体动作：向上提升重物）
>    - → **吊起/升起**：用机械或人力提升 → 激活条件：货物、重物提升语境
>    - → **扯起旗帜**：将旗帜升上去 → 激活条件：仪式、航海语境
>    - → **起重机**：用于举起的机械 → 激活条件：工业/建筑语境（名词）

### 统筹（选择适用的模式）

- **一字一词概括**："升"——升高
- **一句话统筹**：从举起重物到升起旗帜，都是"向上提升"

> [!check]- 链路验证
> - [x] **可逆性**：起重机 → 用于举起的机械 → 用力举起
> - [x] **可统筹**：所有义项围绕"向上举起"
> - [x] **有支撑**：hoist the flag / hoist cargo 为常见搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> hoist 与 hold 同源，hold 是"握住"，hoist 是"握住并向上拉"。想象你双手紧紧握住一根绳子，用力把一面旗帜拉上去。
>
> **词拆分记忆**：
> hoist → 听起来像"嗨！升起！" → 喊着号子把东西举起来
