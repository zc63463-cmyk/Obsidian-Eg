# mess

> [!info] 基础信息
> **音标** /mes/ | **词频** 考研高频 | **语义场** [[状态]]

## 核心释义

**n.** ①==**混乱，杂乱，脏乱**== ; ②困境，麻烦 ; ③（也作 mess）食堂，餐食 ;
**v.** ①弄乱，搞糟 ;

> [!tip] 原型义
> **原型义**：一锅混在一起的食物——各种东西搅和成一团
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻——将抽象的"混乱局面"比作"搅成一团的食物"

## 词根词缀

源自拉丁语 mittere（送/放），经古法语 mes（菜肴的份量）演变。与 [[message]]、[[messenger]] 同源。
**叙事**：各种菜"放"在一个盘子里搅在一起，看起来就是"一团糟"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**混在一起的一团糟**"为统筹中心，沿具身路径向外扩展：
>
> 1. **混在一起的食物**（物理层面）
>    - → **混乱，杂乱**（空间层面）：从食物混杂到物品杂乱
>      - 激活条件：描述房间、环境脏乱时
>    - → **困境，麻烦**（抽象层面）：从物理杂乱到局面混乱
>      - 激活条件：描述局面失控、陷入困境时
>    - → **食堂，餐食**（保留原义）：军队中的集体用餐
>      - 激活条件：军事语境中

### 统筹（选择适用的模式）

- **一字一词概括**："乱"——从物理杂乱到局面混乱
- **延伸中心**：从具体（食物/物品混杂）到抽象（局面混乱），核心特征是"缺乏秩序"
- **一句话统筹**：各种东西搅和在一起，从一锅粥到一团糟

> [!check]- 链路验证
> - [x] **可逆性**：从"混乱""困境"可反向推导到"搅成一团"
> - [x] **可统筹**：一句话"搅成一团"串联所有义项
> - [x] **有支撑**：真题中既见 in a mess，也见 mess up
