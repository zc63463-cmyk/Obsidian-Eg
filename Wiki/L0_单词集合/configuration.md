# configuration

> [!info] 基础信息
> **音标** /kənˌfɪɡəˈreɪʃn/ n. | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**配置，布局**== `N of N` `adj N` ; ②==**构型，结构**== `N of N` ; ③==**外形，形状**== `N of N`

> [!tip] 原型义
> **原型义**：塑造成某种形状（把各部分安排成特定形态）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（物理形状→抽象配置/布局）

## 词根词缀

con-(=together，一起) + figur(=shape/form，形状) + -ation(名词后缀，表示动作或结果)（建议创建词根笔记 [[fig]]/[[form]]，fig/form 同源，意为"形状/形成"）
**叙事**：con（一起）+ figur（形状）+ ation = 把各部分塑造成一个整体形状 → 配置、布局。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**塑造成某种形状**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **塑造成某种形状**（物理层面——把各部分组合成形）
>    - → **配置，布局**（n.）：系统/设备的各部分安排方式
>      - 激活条件：搭配 system configuration, hardware configuration
>    - → **构型，结构**（n.）：分子/原子的排列方式
>      - 激活条件：搭配 molecular configuration, atomic configuration
>    - → **外形，形状**（n.）：整体的几何形态
>      - 激活条件：搭配 the configuration of the coastline

### 统筹

- **一字一词概括**："形"——组合成形
- **一句话统筹**：configuration 就是把各部分"塑造成形"——计算机系统的配置、分子的构型、海岸线的外形。

> [!check]- 链路验证
> - [x] **可逆性**：配置→把各部分安排成特定形态→原型义，可逆
> - [x] **可统筹**：所有义项统一于"塑造成形"
> - [x] **有支撑**：system configuration 为科技类高频搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> con（一起）+ figur（形状）：想象你组装一台电脑，把CPU、内存、硬盘"一起塑造成"一个完整的系统——那就是 configuration（配置）。
>
> **词拆分记忆**：
> configuration = config（配置）+ uration → 计算机里的"配置"就是这个长词的缩写。

## 搭配与短语

> [!example]- 搭配
> - **system configuration**：系统配置
  > The software requires a specific system configuration to run properly. 该软件需要特定的系统配置才能正常运行。
> - **hardware/software configuration**：硬件/软件配置
  > We need to upgrade the hardware configuration of our servers. 我们需要升级服务器的硬件配置。
