# element

> [!info] 基础信息
> **音标** /ˈelɪmənt/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**元素**==（化学元素，构成物质的基本成分）；②==**要素**==（构成事物的关键部分）；③==**基础**==（基本原理，入门知识）；

> [!tip] 原型义
> **原型义**：最基本的组成部分（不可再分的最小单元）
> **延伸维度**：抽象路径
> **隐喻类型**：构成隐喻（物理的"基本成分"→ 抽象的"关键要素/基础"）

## 词根词缀

**词源**：来自拉丁语 *elementum*（基本原理、最初的原则），可能与 *eliminate*（消除）共享更古老的词根（门槛→入门→基本）。在古罗马，elementum 原指"字母表中的字母"——字母是语言最基本的组成单元，正如化学元素是物质最基本的组成单元。

**叙事**：element 就是"最基本的组成部分"。水由氢和氧两种化学**元素**组成——它们是物质世界最基本的砖块。一篇好文章有几个关键**要素**——主题、结构、论据，缺一不可。学一门新技能，先要掌握**基础**——element 就是这些"最基本的组成部分"。从化学元素到文章要素到入门基础，都是"最基本的组成部分"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**最基本的组成部分**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **最基本的组成部分**（物理/科学层面）
>    - → **元素**：化学元素，构成物质的最基本单位
>      - 激活条件：化学/科学语境（chemical element / the elements）
> 2. **最基本的组成部分**（抽象/构成层面）
>    - → **要素**：构成事物的关键部分
>      - 激活条件：分析/构成语境（key element / essential elements）
>    - → **基础，基本原理**：入门级别的知识
>      - 激活条件：学习/入门语境（the elements of music / grammar）

### 统筹（选择适用的模式）

- **一字一词概括**：element = "基本"——最基本的组成部分
- **一句话统筹**：element 就是"最基本的组成部分"——化学元素、关键要素、入门基础

> [!check]- 链路验证
> - [x] **可逆性**：从"基础"能反向推导到"最基本的组成部分"——基础就是知识最基本的组成部分
> - [x] **可统筹**：一句话统筹——"element 就是最基本的组成部分"
> - [x] **有支撑**：chemical element, key element, the elements of 均为高频搭配

## 搭配与短语

> [!example]- 搭配 · L3
> - **chemical element**：化学元素
> - **key / essential element**：关键要素
> - **the elements of**：...的基础/要素（the elements of grammar / music）
> - **in one's element**：如鱼得水，得心应手
> - **the elements**：自然力（风、雨、火等）
> - **element of surprise**：出其不意的因素

## 真题/语料关联

> [!example]- 语料 · L3
> - "Hydrogen and oxygen are the elements that make up water."（氢和氧是组成水的元素）——科学话题
> - "Trust is a key element of any successful relationship."（信任是任何成功关系的关键要素）——社会话题
> - "She was in her element when discussing literature."（她在讨论文学时如鱼得水）——常见表达
> - "The elements of style have been studied for centuries."（文体要素已经被研究了几个世纪）——学术话题
