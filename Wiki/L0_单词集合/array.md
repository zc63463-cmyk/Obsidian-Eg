# array

> [!info] 基础信息
> **音标** /əˈreɪ/ | **词级** 必备词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**一系列，大量**== `an N of N` ；②==**排列，阵列**== `N` ；③==**（计算机）数组**== `N` ；④==**盛装**== `in full N` ；
**vt.** ①==**排列，部署**== `V N` ；②==**打扮，盛装**== `V oneself` ；

> [!tip] 原型义
> **原型义**：排列整齐的一排、一系列（有序排列的事物集合）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（从"空间上的有序排列"到"抽象事物的系列/大量"）

## 词根词缀

**词源关联**：array 源自古法语 *areer*（排列，布置），源自通俗拉丁语 *\*arrēdāre*（安排，排列），前缀 ad-（去，向）+ rēdāre（排列，与 ready 同源）。核心意象是"把东西有序地排列好"。

**叙事**：将军把士兵"排列"（array）成整齐的方阵——这就是 array 的原型。后来不只是士兵，商店里排列整齐的商品（an array of products），计算机中排列整齐的数据（array/数组），都是 array。记住：array = 排列整齐的集合 = 一系列/阵列。

## 词义链路

> [!abstract]- 词义链路法
> 以"**排列整齐的集合**"为统筹中心，沿空间路径向外扩展：
>
> 1. **排列整齐的集合**（物理层面）
>    - → **排列，阵列**：有序排列的事物
>      - 激活条件：solar array, array of soldiers，描述物理排列
>    - → **vt. 排列，部署**：把事物排列整齐
>      - 激活条件：array the troops，描述部署军队
> 2. **排列整齐的集合**（抽象层面）
>    - → **一系列，大量**：有序排列的抽象事物集合
>      - 激活条件：an array of choices/options，描述一系列选择
>    - → **（计算机）数组**：排列整齐的数据集合
>      - 激活条件：data array, array in programming，描述计算机数组

### 统筹（选择适用的模式）

- **延伸中心**："有序排列"——无论是士兵的阵列、商品的展示还是数据的排列，array 都指向"有序的集合"
- **一句话统筹**：array 就是"排好队的集合"——士兵排队叫阵列，选择排队叫一系列，数据排队叫数组

> [!check]- 链路验证
> - [x] **可逆性**：从"一系列选择"能反向推导到"有序排列的选择集合"
> - [x] **可统筹**：一句话统筹——"array 就是排好队的集合"
> - [x] **有支撑**：an array of, solar array, data array 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> 中世纪战场上，将军把士兵排列成整齐的方阵（array），每个士兵都在自己的位置上——这就是 array 的原型。今天，超市货架上排列整齐的商品（an array of products），菜单上排列整齐的菜品（an array of dishes），计算机中排列整齐的数据（array），都是"排好队的集合"。记住：array = 排列整齐的集合 = 一系列/阵列。
>
> **词拆分记忆**（辅助）：
> ar（排列，联想 arrange）+ ray（光线）→ 像光线一样整齐排列 → 阵列
