# relative

> [!info] 基础信息
> **音标** /ˈrelətɪv/ | **词频** 考研高频 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**相对的，比较的**== ; ②相关的，有关系的 ;
**n.** ①==**亲戚，亲属**== ;

> [!tip] 原型义
> **原型义**：有连接的→相对的；亲戚
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"有连接的"→"相对于参照物而言的"）

## 词根词缀

re-(回) + lat/latus(携带、带来) + -ive(形容词/名词后缀，表倾向或人)
**叙事**：和你有"连接"的人——就是亲戚；和参照物有"连接"的——就是相对的。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**有连接的→相对的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **相对的、比较的**（认知层面——相对于参照物而言）
>    - → **相关的、有关系的**：与某事有"连接"的
>      - 激活条件：描述与某事有关时
>    - → ==**亲戚、亲属**==：与自己有血缘"连接"的人
>      - 激活条件：指代家族成员时

### 统筹（选择适用的模式）

- **一字一词概括**："对"——相对于参照而言
- **延伸中心**：一切义项都围绕"与某物有连接/关联"展开

> [!check]- 链路验证
> - [x] **可逆性**：亲戚→有血缘连接的人→有连接的→相对的，可逆
> - [x] **可统筹**："对"字可串联所有义项
> - [x] **有支撑**：relative to（相对于）、a close relative（近亲）、relative poverty（相对贫困）
