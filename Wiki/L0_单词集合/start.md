# start

> [!info] 基础信息
> **音标** /stɑːrt/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**v.** ①==**开始，着手**== `V N` [通用] ; ②出发，动身 `V` [通用] ; ③创办，发起 `V N` [通用] ;
**n.** ①==**开始，起点**== `N` [通用] ; ②惊跳，吃惊 `N` [通用] ;

> [!tip] 原型义
> **原型义**：猛然起身、跃起
> **延伸维度**：时间路径
> **隐喻类型**：方位隐喻（从"身体跃起"到"时间上的开端"）

## 词根词缀

**词源关联**：start 源自古英语 *styrtan*（跳跃，跃起，突然移动），与 [[stand]] 不同源。start 的 PIE 词根为 *\*stert-*（跳跃，抖动），与 stare（凝视）可能有远亲关系。虽然 start 和 stand 的词源不同，但在现代英语中共享 st- 开头的语音联系和"身体动作"的语义联想。

建议创建词根笔记 [[st/sta]]（站立/使...站立/使...坚定）——start 虽非直接派生，但 st- 族的语音联想值得记录。

**叙事**：赛跑时，发令枪一响，选手**猛然跃起**（start）冲出起跑线——这个"跃起的瞬间"就是"开始"，从起点出发就是"动身"，创办公司就是"让一件事跃起"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**猛然起身、跃起**"为统筹中心，沿时间路径向外扩展：
>
> 1. **猛然起身、跃起**（身体层面）
>    - → **惊跳，吃惊**：突然的跃起反应
>      - 激活条件：give sb. a start（吓某人一跳）
> 2. **猛然起身、跃起**（时间层面）
>    - → **开始，着手**：时间上的"跃起"
>      - 激活条件：start doing/to do, start a project
>    - → **出发，动身**：空间上的"跃起"
>      - 激活条件：start for, start on a journey
> 3. **猛然起身、跃起**（社会层面）
>    - → **创办，发起**：让一件事"跃起"
>      - 激活条件：start a business, start a movement

### 统筹（选择适用的模式）

- **一字一词概括**："起"——起身→开始→出发→创办
- **一句话统筹**：start 就是"跃起"——身体跃起是惊跳，时间跃起是开始，空间跃起是出发，事业跃起是创办

> [!check]- 链路验证
> - [x] **可逆性**：从"创办"能推导回"跃起"——创办就是让一件事从无到有地跃起
> - [x] **可统筹**：一句话——"start 就是让一切跃起来"
> - [x] **有支撑**：start a company, start from scratch, give me a start 均有语料支撑

## 搭配与短语

> [!example]- 搭配
> - **start with**：以...开始
  - Let's start with a brief overview of the problem.
- **start from scratch**：从零开始
  - She built the company from scratch.
- **to start with**：首先，起初
  - To start with, we need to understand the basic principles.
- **start up**：创办，启动
  - They decided to start up their own business.
