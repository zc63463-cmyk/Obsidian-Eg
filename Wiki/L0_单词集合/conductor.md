# conductor

> [!info] 基础信息
> **音标** /kənˈdʌktə(r)/ | **词级** 必备词 | **语义场** [[人本世界]]

## 核心释义

**n.** ①==**指挥家（乐队）**== `N` ; ②==**导体**== `N` ; ③==**售票员，列车长**== `N` ;

> [!tip] 原型义
> **原型义**：引导者、带领者
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（导体 = 引导电流的"人"）

## 词根词缀

con-(共同/一起) + [[duct|duct/duc]](引导) + -or(名词后缀，做...的人/物)
**叙事**：引导大家的人/物 → 指挥家、导体。

建议创建词根笔记 [[duct/duc]]

## 词义链路

> [!abstract]- 词义链路法
> 以"**引导者**"为统筹中心，沿社会路径向外扩展：
>
> 1. **引导者**（社会层面：带领大家的人）
>    - → **指挥家**：引导音乐方向的人 → 激活条件：音乐语境
>    - → **售票员/列车长**：引导乘客的人 → 激活条件：交通语境
>    - → **导体**：引导电流/热量的"物" → 激活条件：物理/科学语境

### 统筹（选择适用的模式）

- **一字一词概括**："导"——引导者
- **一句话统筹**：无论是指挥乐队还是传导电流，都是"引导者"

> [!check]- 链路验证
> - [x] **可逆性**：导体 → 引导电流的物 → 引导者
> - [x] **可统筹**：所有义项围绕"引导者"
> - [x] **有支撑**：orchestra conductor / metal conductor 为常见搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> con（一起）+ duct（引导）+ or（人）→ 引导大家一起做的人 → 指挥家。想象一个穿着燕尾服的人站在乐队前面，用指挥棒引导所有乐手。
>
> **词拆分记忆**：
> conductor = conduct（引导）+ or（人）→ 引导者
