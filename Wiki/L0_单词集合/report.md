# report

> [!info] 基础信息
> **音标** /rɪˈpɔːt/ | **词频** 考研高频 | **语义场** [[言语交流]]

## 核心释义

**v.** ①==**报告，报道**== ; ②报到 ;
**n.** ①报告，报道 ; ②成绩单 ;

> [!tip] 原型义
> **原型义**：把信息带回来（re-回 + port-携带）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（报道=把远方信息带回来给公众）

## 词根词缀

re-(回) + [[port|port]](携带、运送) → 把信息带回来 → 报告
**叙事**：记者跑到现场，把新闻信息带回来告诉公众，这就是 report。与 [[transport]]（运输到远处）同源。

---

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**把信息带回来**"为统筹中心，沿社会路径向外扩展：
>
> 1. **把信息带回来**（行为层面：将所见所闻带回来告诉他人）
>    - → **报告，报道**：正式地传达信息
>      - 激活条件：report sth. to sb. 或新闻语境
>    - → **报到**：到指定地点报告自己的到达
>      - 激活条件：report to the office / report for duty
>    - → **报告（文件）**：带回来的信息整理成文
>      - 激活条件：作名词，指书面报告

### 统筹（选择适用的模式）

- **一字一词概括**："报"——把信息带回来传达
- **一句话统筹**：从新闻报道到书面报告再到报到，核心都是"把信息带回来"。

> [!check]- 链路验证
> - [x] **可逆性**：从"书面报告"可反向推导至"把信息带回来"
> - [x] **可统筹**：一个"报"字贯穿所有义项
> - [x] **有支撑**：report the news / annual report 均为常见搭配
