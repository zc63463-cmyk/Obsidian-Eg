# chop

> [!info] 基础信息
> **音标** /tʃɒp/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

v. ①==**砍；劈；剁**== `V N` / `V N into N`；②削减；终止 `V N by N` / `V N`；
n. ①==**排骨；肉块**== `a N`；②砍；劈 `a N` / `a N of N`；

> [!tip] 原型义
> **原型义**：用刀斧用力砍劈
> **延伸维度**：具身路径
> **隐喻类型**：本体隐喻

## 词根词缀

chop（砍/劈，拟声词源）
**叙事**：刀斧落下，咔嚓一声，物体被劈开

### 统筹（选择适用的模式）

- **一句话统筹**：从'用力砍劈'到'削减终止'——chop 的核心是'一刀切下去'的果断动作

> [!check]- 链路验证
> - [x] **可逆性**：chop 既是砍的动作，也是砍的结果（肉块），核心都是'劈砍'

> - [x] **有支撑**：chop 的引申义'削减'保留了'砍掉一部分'的具身意象
