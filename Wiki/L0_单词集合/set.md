# set

> [!info] 基础信息
> **音标** /set/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**vt.** ①==**放，置，设置**== `set a table/goal`; ②==**设定，确立**== `set a standard/limit`; ③==**使开始，使着手**== `set out to do sth`; ④==**（日、月）落山**== `the sun sets`;
**vi.** ①==**（日、月）落山**== `set below the horizon`; ②==**凝固，凝结**== `the cement sets`;
**n.** ①==**一套，一组**== `a set of rules/tools`; ②==**集合**== `a data set`; ③==**布景**== `stage set`;
**adj.** ①==**固定的，不变的**== `a set routine/menu`;

> [!tip] 原型义
> **原型义**：使某物处于特定位置或状态
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（将"放置到某个位置"映射到"设定规则/标准/开始某事"）

## 词根词缀

set ← 古英语 settan（使坐、放置）← 原始日耳曼语 *satjan（使坐）

%% 建议创建词根笔记 [[set/sed/sit]]（源自原始印欧语 *sed-"坐"，常见于 set, sit, settle, session, sediment 等） %%

**叙事**：set 的最原始含义是"使坐"——让某物"坐"到一个位置上。放一本书在桌上是 set，设定一个目标是 set（把目标"放"好），太阳落山是 set（太阳"坐"到地平线以下）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**使某物处于特定位置或状态**"为统筹中心，沿空间路径向外扩展：
>
> 1. **使某物处于特定位置**（本义：放置到某处）
>    - → **放/置/设置**：<保持空间义，放置具体物品>
>      - 激活条件：描述放置物品、设置设备时
>    - → **设定/确立**：<将"放置"抽象化为"设定标准/规则/目标">
>      - 激活条件：描述设定目标、标准、日期时
>    - → **使开始/使着手**：<将"放置到起点"引申为"开始">
>      - 激活条件：描述开始某事时
>    - → **（日、月）落山**：<将"坐到某处"映射到天体"坐"到地平线以下>
>      - 激活条件：描述日落时
>    - → **一套/一组**：<名词化，将"被放在一起的东西"称为一个 set>
>      - 激活条件：描述成套物品时

### 统筹（选择适用的模式）

- **延伸中心**：使处于特定位置/状态
- **一句话统筹**：set 的核心是"放置"——放置物品、放置目标、放置到起点、放置到地平线下。

> [!check]- 链路验证
> - [x] **可逆性**：从"日落"能反向联想到"坐到地平线以下"
> - [x] **可统筹**：放置→设定→开始→日落→一套，统一于"使处于特定位置"
> - [x] **有支撑**：set a goal（设定目标）/ set out（出发）/ sun sets（日落）/ a set of（一套）

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> set 源自古英语 settan（使坐）。想象你让一个孩子"坐"到椅子上——这就是 set 的原型义。后来从"使坐"扩展到"放置"任何东西，再扩展到"设定"目标、"开始"旅程、"日落"（太阳坐到地平线下）。
>
> **词拆分记忆**：
> s(四) + e(鹅) + t(踢) → 四只鹅踢了一脚 → 把它们"放"在一起 → "一套"。

## 搭配与短语

> [!example]- 搭配
> - **set up**：They set up a new company last year.（他们去年成立了一家新公司。）
> - **set out**：She set out to write a novel.（她着手写一部小说。）
> - **a set of**：I bought a set of tools.（我买了一套工具。）
