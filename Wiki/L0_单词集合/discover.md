# discover

> [!info] 基础信息
> **音标** /dɪˈskʌvə(r)/ | **词频** 考研高频 | **语义场** [[理性世界]]

## 核心释义

**vt.** ①==**发现，找到**== ; ②==**了解到，认识到**==（事实/真相） ;

> [!tip] 原型义
> **原型义**：移除覆盖物、暴露出隐藏之物
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（发现 = 移除覆盖物）

## 词根词缀

dis-(移除/打开) + [[cover|cover]](覆盖) → 移除覆盖
**叙事**：把覆盖的东西拿掉 → 发现隐藏的事物。

建议创建词根笔记 [[cover]]

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**移除覆盖**"为统筹中心，沿空间路径向外扩展：
>
> 1. **移除覆盖**（物理层面：拿掉遮挡物）
>    - → **发现/找到**：移除遮挡后发现隐藏之物 → 激活条件：探索、研究语境
>    - → **了解到/认识到**：移除认知上的"覆盖" → 激活条件：认知、领悟语境

### 统筹（选择适用的模式）

- **一字一词概括**："现"——发现
- **一句话统筹**：从发现新大陆到认识到真相，都是"移除覆盖"

> [!check]- 链路验证
> - [x] **可逆性**：发现 → 移除覆盖后看到 → 移除覆盖
> - [x] **可统筹**：所有义项围绕"移除覆盖/发现"
> - [x] **有支撑**：discover a new species / discover the truth 为常见搭配
