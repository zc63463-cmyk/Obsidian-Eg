# anonymous

> [!info] 基础信息
> **音标** /əˈnɒnɪməs/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①匿名的，无名的 ; ==** `adj N`②无特色的，不具名的**== ; `be adj`

> [!tip] 原型义
> **原型义**：没有名字的（人名信息被隐藏）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接从"没有名字"抽象化）

## 词根词缀

an-(无，没有) + [[onym]](名字) + -ous(形容词后缀，充满...的)

建议创建词根笔记 [[onym]]（名字），关联词根 [[an/anim]]（呼吸/生命→无→an-前缀）

**叙事**：一个人没有（an-）名字（onym），他就是anonymous（匿名的）——像空气一样存在却看不见是谁。

## 词义链路

> [!abstract]- 词义链路法
> 以"**没有名字的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **没有名字的**（信息层面：姓名缺失）
>    - → **匿名的**：主动隐藏身份或来源不明
>      - 激活条件：描述信件、捐赠、评论等不署名的情况
>    - → **无特色的，不具名的**：因没有名字而缺乏个性特征
>      - 激活条件：描述普通、平庸、无法辨识的事物时

### 统筹

- **一字一词概括**：无名——从隐藏姓名到缺乏个性
- **延伸中心**：名字是身份的标识，没有名字就失去了独特性
- **一句话统筹**：没有名字的人是匿名的，没有特色的事物也是匿名的。

> [!check]- 链路验证
> - [x] **可逆性**：无特色→没有独特名字→匿名
> - [x] **可统筹**：所有义项围绕"无名"展开
> - [x] **有支撑**：anonymous donor, anonymous source 等搭配
