# function

> [!info] 基础信息
> **音标** /ˈfʌŋkʃn/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①功能、作用 ; ②==**职责、职务**== ; ③函数 ;
**v.** ①==**运转、运行**== ; ②起作用 ;

> [!tip] 原型义
> **原型义**：执行、运作
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻

## 词根词缀

[[fac|fac]](做) + -tion(名词后缀，表示动作结果)
**叙事**：工厂里的机器"做"出产品，这就是它的功能。

> [!note] 建议创建词根笔记 [[func-funct]]

## 词义链路

> [!abstract]- 词义链路法
> 以"**执行、运作**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **执行、运作**（物理层面）
>    - → **功能、作用**：机器执行任务产生的效果
>      - 激活条件：描述设备、器官等的作用时
>    - → **职责、职务**：人在组织中执行的任务
>      - 激活条件：描述职业角色时
>    - → **函数**：数学中输入到输出的执行关系
>      - 激活条件：数学语境

### 统筹（选择适用的模式）

- **一字一词概括**：做
- **一句话统筹**：function 指任何"执行运作"的过程或结果
