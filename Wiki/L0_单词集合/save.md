# save

> [!info] 基础信息
> **音标** /seɪv/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**vt.** ①==**拯救，挽救**==（使脱离危险）；②==**节省，节约**==（减少消耗）；③==**保存，储蓄**==（留待后用）；④==**救（球）**==（体育语境）；
**prep.** ①==**除……之外**==（except 的口语用法）；

> [!tip] 原型义
> **原型义**：使安全→拯救/节省（来自拉丁语 *salvare*，"使安全、拯救"）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接从"使安全"衍生出"拯救"和"节省"——节省就是"使资源安全"）

## 词根词缀

**词源拆分**：拉丁语 *salvare*（拯救，使安全）→ 古法语 *salver* → 英语 *save*

**词根 salv/salvus**（安全的）：来自拉丁语 *salvus*（安全的、完好的），与 **safety**（安全）、**salvation**（拯救）、**salvage**（打捞/抢救）同源

**叙事**：save 来自拉丁语 *salvare*，本义就是"使安全"。救人脱离危险就是"拯救"（save a life），让钱不被花掉就是"节省/储蓄"（save money），让数据不丢失就是"保存"（save a file）。记住 save = 使安全→拯救/节省/保存。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**使安全→拯救/节省**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **使安全**（生命/人身层面）
>    - → **拯救，挽救**：使脱离危险
>      - 激活条件：紧急/灾难/医疗语境（save a life, save someone from drowning）
>    - → **救（球）**：阻止对方得分
>      - 激活条件：体育语境（save a goal, a brilliant save）
> 2. **使安全**（资源层面）
>    - → **节省，节约**：减少消耗，使资源不被浪费
>      - 激活条件：日常/经济/环保语境（save money, save time, save energy）
>    - → **保存，储蓄**：留待后用，使资源安全
>      - 激活条件：金融/科技语境（save money in the bank, save a file）
> 3. **使安全**（特殊用法）
>    - → **除……之外**（介词）：口语中相当于 except
>      - 激活条件：口语/非正式语境（save for the rain, we had a good trip）

### 统筹（选择适用的模式）

- **一字一词概括**：save = "救"——拯救、节省、保存
- **一句话统筹**：save 就是"使安全"——救人是使生命安全，省钱是使资源安全，存文件是使数据安全

> [!check]- 链路验证
> - [x] **可逆性**：从"节省"能反向推导到"使安全"——节省就是使资源不被浪费（安全）
> - [x] **可统筹**：一句话统筹——"save 就是使安全"
> - [x] **有支撑**：save a life, save money, save a file 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> save 来自拉丁语 *salvare*（使安全）。想象一个消防员冲进火场，把一个人从火海中拉出来——这就是 save（拯救）。你每个月把工资的一部分存进银行——这也是 save（储蓄），因为你的钱"安全"了。你在电脑上按 Ctrl+S——这还是 save（保存），因为你的文件"安全"了。记住 save = 使安全→拯救/节省/保存。
>
> **词拆分记忆**（辅助）：
> save 本身就是基础词，来自拉丁语 salvare（使安全）。联想：save → safe（安全的），save 就是使……safe。

## 搭配与短语

> [!example]- 搭配 · L3
> - **save one's life**：拯救某人的生命
> - **save money / time / energy**：省钱/省时/省力
> - **save for a rainy day**：未雨绸缪（存钱以备不时之需）
> - **save the day**：扭转局面，化险为夷
> - **save sb. from sth.**：把某人从……中救出
> - **save a file / document**：保存文件
> - **save for**：除……之外（save for a few exceptions）

## 真题/语料关联

> [!example]- 语料 · L3
> - "Technology has saved us countless hours of work."（科技为我们节省了无数工作时间）——科技话题
> - "The doctor saved the patient's life."（医生挽救了病人的生命）——医疗话题
> - "save money for retirement"（为退休存钱）——经济话题
> - "save the document before closing"（关闭前保存文档）——日常表达
> - "It was the goalkeeper's brilliant save that won the match."（正是守门员精彩的扑救赢得了比赛）——体育话题
