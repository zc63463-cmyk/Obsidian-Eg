# elementary

> [!info] 基础信息
> **音标** /ˌelɪˈmentri/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**基本的**== `elementary knowledge/principle` `elementary to sth`（最基础、最根本的）；②==**初级的**== `elementary school/education` `elementary level`（入门级别的，最初阶段的）；③==**简单的**== `elementary question/mistake`（容易理解的，不复杂的）；

> [!tip] 原型义
> **原型义**：属于基本要素的（与 element"最基本的组成部分"直接关联）
> **延伸维度**：抽象路径
> **隐喻类型**：层级隐喻（从"基本要素"→ "入门级别"→ "简单易懂"）

## 词根词缀

**词根拆分**：[[element]]（基本要素）+ -ary（形容词后缀，"属于...的"）→ 属于基本要素的 → 基本的

**词源**：elementary 直接派生自 [[element]]（最基本的组成部分）。-ary 是常见的形容词后缀，表示"与...有关的、属于...的"，如 primary（首要的）、secondary（次要的）。

**叙事**：elementary = element（基本要素）+ ary（属于...的）→ "属于基本要素的"。小学叫 elementary school，因为小学教的是知识最"基本"的部分——识字、算术。一道题很"简单"，因为它只涉及最"基本"的概念。记住 element = 基本组成，elementary = 属于基本要素的 = 基本的。

## 词义链路

> [!abstract]- 词义链路法
> 以"**属于基本要素的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **属于基本要素的**（抽象层面）
>    - → **基本的**：最基础、最根本的
>      - 激活条件：描述概念/原理（elementary knowledge / principle）
> 2. **属于基本要素的**（层级层面）
>    - → **初级的**：入门级别的，最初阶段的
>      - 激活条件：教育/学习语境（elementary school / elementary level）
> 3. **属于基本要素的**（难度层面）
>    - → **简单的**：不复杂的，容易理解的
>      - 激活条件：描述难度（elementary question / mistake）

### 统筹（选择适用的模式）

- **一字一词概括**：elementary = "基本"——基本的、初级的、简单的
- **一句话统筹**：elementary 就是"属于基本要素的"——基本原理、初级阶段、简单问题

> [!check]- 链路验证
> - [x] **可逆性**：从"简单的"能反向推导到"属于基本要素的"——简单因为只涉及基本要素
> - [x] **可统筹**：一句话统筹——"elementary 就是属于基本要素的"
> - [x] **有支撑**：elementary school, elementary knowledge, elementary mistake 均为高频搭配
