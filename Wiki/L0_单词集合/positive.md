# positive

> [!info] 基础信息
> **音标** /ˈpɒzətɪv/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**积极的，正面的**== ; ②确定的，肯定的 ; ③正的，阳性的（数学/科学） ; ④确实的，明确的

> [!tip] 原型义
> **原型义**：放置好的、确定的（被牢牢放定的）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻——从"放置稳固"投射到"确定无疑"，再到"积极正面"

## 词根词缀

[[pon/pos|pos]](放置、放) + -itive(形容词后缀，表示"具有……性质的")
**叙事**：一个事实被牢牢**放**定在那里，就是**确定的**（positive）；把好的东西**放**在前面，就是**积极的**（positive attitude）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**放置好的、确定的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **放置好的、确定的**（认知层面：事实被"放定"）
>    - → **肯定的、明确的**：<对某事有确定的判断>
>      - 激活条件：搭配 proof, evidence, answer，表示确凿
>    - → **积极的、正面的**：<从"确定"延伸为"建设性的、好的">
>      - 激活条件：搭配 attitude, effect, role，表示正面评价
>    - → **正的、阳性的**：<数学/科学中"确定方向"的量>
>      - 激活条件：搭配 number, charge，科学语境

### 统筹（选择适用的模式）

- **延伸中心**："放置稳固"→ 确定 → 积极 → 正向
- **一句话统筹**：被牢牢"放定"的东西是确定的、积极的、正向的

> [!check]- 链路验证
> - [x] **可逆性**：从"积极的"可反向推导——好的东西被"放定"在前 → 放置好的
> - [x] **可统筹**：所有义项共享"确定/正向"的核心语义
> - [x] **有支撑**：positive evidence / positive attitude 为考研高频搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**：
> 想像一个天平——重物被**放**定在一边，倾斜方向是**确定的**（positive）。在生活中，确定的好事就是**积极的**（positive），数学中确定方向的数就是**正数**（positive number）。
>
> **词拆分记忆**：
> positive = [[pon/pos|pos]](放) + -itive(形容词) → 放置好的 → 确定的 → 积极的
