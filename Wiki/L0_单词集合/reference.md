# reference

> [!info] 基础信息
> **音标** /ˈrefrəns/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**参考，查阅**== ; ②提到，提及 ; ③推荐信，证明人 ; ④参考文献
**vt.** ①提到，涉及

> [!tip] 原型义
> **原型义**：带回信息的动作或来源
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（将"带回"映射为"参考来源"或"提及"）

## 词根词缀

[[re]](回) + [[fer]](带来/承载) + -ence(名词后缀，表动作或状态) → 把信息带回来的来源 = 参考
**叙事**：re-(回) + fer(带) + -ence(名词) = 把目光"带回"来的那个来源，就是"参考资料"。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**带回信息的动作或来源**"为统筹中心，沿空间路径向外扩展：
>
> 1. **带回信息的动作或来源**（物理动作层面）
>    - → **参考，查阅**：把目光带回的来源
>      - 激活条件：学术或工作场景中（for your reference, reference book）
>    - → **提到，提及**：在话语中把某事带回
>      - 激活条件：描述说话内容时（make reference to）
>    - → **推荐信，证明人**：把某人的信息"带回"给雇主的人
>      - 激活条件：求职或申请场景（academic references）
>    - → **参考文献**：论文中"带回"的信息来源
>      - 激活条件：学术写作场景（list of references）

### 统筹（选择适用的模式）

- **一字一词概括**："信息来源"——参考的来源、提及的内容、推荐的人
- **延伸中心**：refer 的名词化，所有义项围绕"信息被带回的来源或动作"

> [!check]- 链路验证
> - [x] **可逆性**：从"参考"可反向推导到"把目光带回的信息来源"
> - [x] **可统筹**：所有义项都是"带回信息"这一动作的名词化体现
> - [x] **有支撑**：for reference, make reference to 为考研高频搭配
