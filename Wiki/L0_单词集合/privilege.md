# privilege

> [!info] 基础信息
> **音标** /ˈprɪvəlɪdʒ/ | **词级** 必备词 | **语义场** [[政治法律]]

## 核心释义

**n.** ①==**特权，优待**== ; ②（因地位而享有的）特殊待遇
**vt.** ①给予特权，特批

> [!tip] 原型义
> **原型义**：关于个人的法律（针对特定个人的特殊法律）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（特权=法律为特定个人制定的"特殊规则"，从法律概念→社会优势）

## 词根词缀

priv(个人) + [[leg]](法律) + -e(后缀) = privilege（关于个人的法律→特权）

建议创建词根笔记 [[pri]]

**叙事**：古罗马为**个人**（priv）制定的**特殊法律**（leg），让少数人拥有了**特权**（privilege）——法律面前并非人人平等。

---

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**关于个人的法律**"为统筹中心，沿社会路径向外扩展：
>
> 1. **关于个人的法律**（法律层面：针对特定个人的特殊法规）
>    - → **特权，优待**：法律赋予个人的特殊权利
>      - 激活条件：enjoy/have a privilege / privilege of doing sth.
>    - → **特殊待遇**：因地位而享有的好处
>      - 激活条件：special privilege / class privilege
>    - → **给予特权**（动词）：赋予某人特殊权利
>      - 激活条件：privilege sb. to do sth. / be privileged to do sth.

### 统筹（选择适用的模式）

- **一字一词概括**："特殊"——针对特定个人的特殊法律→特殊权利
- **延伸中心**：个人法律→个人权利→社会优势

> [!check]- 链路验证
> - [x] **可逆性**：特殊待遇→个人法律→原型义"关于个人的法律"，可逆
> - [x] **可统筹**：所有义项围绕"特殊权利/待遇"展开
> - [x] **有支撑**：enjoy privilege / privileged class 为考研高频用法

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 古罗马元老院为**个人**（priv）制定了**特殊法律**（leg），让贵族拥有免税的**特权**（privilege）——特权，本质上就是"只为你服务的法律"。

## 搭配与短语

> [!example]- 搭配 · L3
> - **enjoy/have the privilege of**：享有……的特权/荣幸
>   Only members of the club have the privilege of using the swimming pool.（只有俱乐部成员才有使用游泳池的特权。）
> - **privileged class**：特权阶层
>   The gap between the privileged class and the working class continues to widen.（特权阶层与工人阶级之间的差距持续扩大。）
> - **be privileged to do sth.**：有幸做某事
>   I was privileged to work with such a talented team.（我有幸与如此有才华的团队合作。）

## 真题/语料关联

> [!example]- 语料 · L3
> - "Education should be a right, not a privilege reserved for the wealthy few."（教育应该是一项权利，而不是少数富人的特权。）——考研高频表达
> - "In many societies, access to clean water is still considered a privilege rather than a basic human right."（在许多社会中，获得清洁用水仍被视为一种特权，而非基本人权。）——考研高频表达
