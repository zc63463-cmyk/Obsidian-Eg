# proceeding

> [!info] 基础信息
> **音标** /prəˈsiːdɪŋ/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**诉讼程序，诉讼**== ; ②（会议等的）进程，事项 ; ③行动，做法 ;
**adj.** ①在先的，前面的（仅用于 proceeding year 等固定搭配） ;

> [!tip] 原型义
> **原型义**：进行中的事务——正在向前推进的事情
> **延伸维度**：时间路径
> **隐喻类型**：结构隐喻（事务进程=时间上的推进）

## 词根词缀

`pro-`(向前) + [[ced-cess|ced]](走/前进) + `-ing`(动名词后缀)
**叙事**：正在向前推进的事情——proceeding就是进行中的事务或程序

## 词义链路

> [!abstract]- 词义链路法
> 以"**进行中的事务**"为统筹中心，沿时间路径向外扩展：
>
> 1. **进行中的事务**（时间层面——正在推进的事情）
>    - → **诉讼程序**：<法律事务的推进过程>
>      - 激活条件：法律语境中描述法庭程序时
>    - → **会议进程、事项**：<会议中正在推进的议程>
>      - 激活条件：会议/活动语境中
    - → **在先的**（adj.）：<时间上在前面推进的>
      - 激活条件：proceeding year 等固定搭配

### 统筹（选择适用的模式）

- **延伸中心**：推进过程——从一般事务推进→法律诉讼→会议议程，核心都是"正在向前推进的事务"
- **一句话统筹**：proceeding 描述的是正在按步骤推进的事务过程，尤指法律或正式场合

> [!check]- 链路验证
> - [x] **可逆性**：从"诉讼程序"可反向推导到"法律事务的推进"→"进行中的事务"
> - [x] **可统筹**：一句话"正在推进的事务过程"串联所有义项
> - [x] **有支撑**：legal proceedings（法律诉讼）、conference proceedings（会议录）
