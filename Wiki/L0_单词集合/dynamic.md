# dynamic

> [!info] 基础信息
> **音标** /daɪˈnæmɪk/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**adj.** ①==**动态的，不断变化的**== ; ②充满活力的，有活力的 ; ③动力的，动力学的 ;
**n.** ①动力，动态 ; ②动力学 ;

> [!tip] 原型义
> **原型义**：有力量、有动力的——不断运动变化的
> **延伸维度**：抽象路径
> **隐喻类型**：本体隐喻（将"变化/活力"视为一种内在的"力量/能量"）

## 词根词缀

dyn(力量，动力) + -am(连接) + -ic(与...有关的)
**叙事**：与力量(dyn)有关的——充满力量就会不断运动变化，就是"动态的"。

---

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**有力量/动力的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **有力量/动力的**（物理层面）
>    - → **动态的，不断变化的**：有动力就会运动变化
      - 激活条件：描述系统、环境、过程等处于变化中
    - → **充满活力的，有活力的**：人有力量就有活力
      - 激活条件：描述人、团队、经济等的活力
    - → **动力学的**：物理学中研究力的学科
      - 激活条件：科学语境

### 统筹（选择适用的模式）

- **延伸中心**：这个词的核心特征是"内在力量驱动变化"——有力量的东西是动态的、有活力的
- **一句话统筹**：dynamic 就是有"劲儿"——系统有劲儿就不断变化，人有劲儿就充满活力

> [!check]- 链路验证
> - [x] **可逆性**：从"充满活力的"反推——活力来自内在的力量/动力
> - [x] **可统筹**：所有义项统一于"力量驱动的"
> - [x] **有支撑**：真题高频词，dynamic system / group dynamics 等搭配极常见

## 搭配与短语

> [!example]- 搭配 · L3
> - **dynamic system**：The economy is a complex dynamic system.（经济是一个复杂的动态系统。）

> - **dynamic economy**：China has maintained a dynamic economy for decades.（中国几十年来保持了充满活力的经济。）
