# theme

> [!info] 基础信息
> **音标** /θiːm/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**主题，主旨**==（谈话、作品、活动的核心话题）；②==**（音乐的）主旋律**==；③（学生的）==**作文，短文**==；（语言学）==**主位**==；
**adj.** ①主题的（仅用于复合词：theme park, theme song）；

> [!tip] 原型义
> **原型义**：被放置的东西、命题（希腊语 *thema* = 被放置之物）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（"被放置在中心的东西"→ 作品的中心话题/音乐的核心旋律）

## 词根词缀

**词源关联**：theme 源自希腊语 *thema*（被放置之物、命题），是 *tithenai*（放置、设立）的过去分词。经拉丁语 *thema*、古法语 *teme* 进入英语。与 **thesis**（论点、论文，*tithenai* 的另一派生）同源。

**叙事**：希腊语 *thema* 就是"被放在那里"的东西——一篇文章**放在最中心**的就是主题（theme），一首乐曲**反复出现**的就是主旋律（theme），一场演讲**围绕展开**的就是主旨（theme）。记住 theme = 被放在中心的东西 = 主题。

## 词义链路

> [!abstract]- 词义链路法
> 以"**被放置的东西、命题**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **被放置的东西**（文本/作品层面）
>    - → **主题、主旨**：作品/讨论的核心话题
>      - 激活条件：文学分析、讨论、写作时（the central theme, recurring theme）
>    - → **（学生的）作文，短文**：围绕一个命题展开的写作
>      - 激活条件：教育语境（write a theme on...）
> 2. **被放置的东西**（音乐/活动层面）
>    - → **（音乐的）主旋律**：乐曲中被"放置"在核心的旋律
>      - 激活条件：音乐分析、描述时（the main theme of the symphony）
>    - → **主题公园/主题曲**（复合词）：围绕某个主题构建
>      - - 激活条件：日常/娱乐语境（theme park, theme song）

### 统筹（选择适用的模式）

- **一字一词概括**：theme = "题"——主题、命题、题目
- **一句话统筹**：theme 就是"放在中心的东西"——文章的主题、音乐的主旋律、作文的题目

> [!check]- 链路验证
> - [x] **可逆性**：从"主旋律"能反向推导到"被放置的东西"——主旋律就是被放在乐曲中心的东西
> - [x] **可统筹**：一句话统筹——"theme 就是放在中心的东西"
> - [x] **有支撑**：central theme, recurring theme, theme park, theme song 均为高频搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> theme 来自希腊语 thema（被放置的东西）。想象你写一篇文章，把最重要的观点**放在最中心**——那就是 theme（主题）。一首交响乐里反复出现的那段旋律，也是被作曲家**放在中心**的——也是 theme（主旋律）。记住 theme = 被放在中心的东西 = 主题。
>
> **词拆分记忆**（辅助）：
> the（那个）+ me（我）→ 那个关于"我"的东西 → 主题
