# hold

> [!info] 基础信息
> **音标** /həʊld/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**vt.** ①==**拿着，握住**== ; ②==**举行，举办**== ; ③==**持有（观点等）**== ; ④==**容纳，装下**== ; ⑤==**保持，持续**== ;
**n.** ①==**握住，抓住**== ; ②==**控制力，影响力**== ;

> [!tip] 原型义
> **原型义**：用手握住、保持不放
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（持有观点 = 握住；举办活动 = 握住活动）

## 词根词缀

hold 为日耳曼语源本族词（非拉丁/希腊借词），无前缀后缀拆分。
**叙事**：手紧紧握住东西不放 → 引申为持有、举办、容纳等。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**用手握住**"为统筹中心，沿具身路径向外扩展：
>
> 1. **用手握住**（身体层面：手抓住物体）
>    - → **拿着/握住**：手握住物品 → 激活条件：描述持物动作
>    - → **持有（观点）**：认知上"握住"想法 → 激活条件：表达观点时
>    - → **举行/举办**：社会性"握住"活动 → 激活条件：会议、活动语境
>    - → **容纳/装下**：空间上"握住"内容 → 激活条件：容器、大厅等
>    - → **保持/持续**：时间上"握住"状态 → 激活条件：hold true / hold on
>    - → **控制力/影响力**：抽象"握住"权力 → 激活条件：政治、商业语境

### 统筹（选择适用的模式）

- **一字一词概括**："持"——保持、握住
- **一句话统筹**：从手握物品到持有观点，都是"握住不放"的延伸

> [!check]- 链路验证
> - [x] **可逆性**：持有观点 → 认知上握住 → 用手握住
> - [x] **可统筹**：所有义项围绕"握住/保持"
> - [x] **有支撑**：hold a meeting / hold a view / hold true 为高频搭配

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**：
> hold 是最基础的英语本族词之一，原始含义就是"手握住"。想象你紧紧握住一根绳子，无论风吹雨打都不松手——这就是 hold 的核心精神：握住、保持、坚持。
>
> **词拆分记忆**：
> hold → 联想"hold住"（网络流行语）→ 保持住、坚持住
