# grow

> [!info] 基础信息
> **音标** /ɡrəʊ/ | **词级** 必备词 | **语义场** [[自然物理]]

## 核心释义

**v.** ①==**生长，成长**== ; ②==**增加，发展**== ; ③种植，栽培 ; ④逐渐变得 ;

> [!tip] 原型义
> **原型义**：生长，发育（植物从种子到成熟的过程）
> **延伸维度**：时间路径
> **隐喻类型**：结构隐喻（发展/增加像植物生长一样"逐渐变大"）

## 词根词缀

无前缀 + grow(古英语 *grōwan*，生长) + 无后缀
**叙事**：一粒种子在泥土中慢慢**生长**（grow），破土而出，长成参天大树。生命在时间中不断**成长**、**发展**。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**生长，发育**"为统筹中心，沿时间路径向外扩展：
>
> 1. **生长，发育**（自然层面：植物/生物的生长过程）
>    - → **增加，发展**：从生物生长延伸到数量、规模的增加
>      - 激活条件：描述经济、人口、数量的增长
>    - → **种植，栽培**：使植物生长的行为
>      - 激活条件：农业、园艺语境
>    - → **逐渐变得**：随时间"生长"出的新状态
>      - 激活条件：grow + 形容词补语

### 统筹（选择适用的模式）

- **一字一词概括**："长"——一切随时间增长
- **不同程度/过程**：从植物生长→数量增加→状态变化，都是"逐渐变大"的不同程度

> [!check]- 链路验证
> - [x] **可逆性**：从"逐渐变得"可回溯到"随时间生长"
> - [x] **可统筹**："随时间增长"统一所有义项
> - [x] **有支撑**：grow up / grow into / grow old 均为常见用法

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 古英语 *grōwan*，最基本的"生长"之意。想象一棵小树苗，年复一年地**生长**（grow），从幼苗**长成**大树，树荫越来越**大**（grow），最终你**变得**（grow）可以在树下乘凉。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> g(高) + row(排) → 一排排长得越来越**高** → **生长**
