# type

> [!info] 基础信息
> **音标** /taɪp/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**类型，种类**== ; ②典型，代表 ; ③铅字，字体 ;
**v.** ①==**打字**== ;

> [!tip] 原型义
> **原型义**：打击留下的印记（希腊语 typos "印记、模型"）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（印记→模型→类型）

## 词根词缀

type 源自希腊语 typos（印记、打击的痕迹），与拉丁语 typus 同源。
**叙事**：古代工匠用模具**打**出一个**印记**（type），所有用同一个模具打出来的东西都属于同一个**类型**（type）。后来用打字机**打字**（type），也是在纸上留下印记。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**打击留下的印记**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **打击留下的印记**（物理层面——模具打出的痕迹）
>    - → **类型，种类**：用同一模具打出的东西属于同一类
>      - 激活条件：type of / different types of
>    - → **典型，代表**：某一类别的代表性印记
>      - 激活条件：a type of person / the quiet type
>    - → **打字**：在键盘上敲击留下印记
>      - 激活条件：type a letter / type on the computer

### 统筹（选择适用的模式）

- **一字一词概括**："类"——印记→类别
- **延伸中心**："印记→模型→类别"这一结构隐喻贯穿所有义项

> [!check]- 链路验证
> - [x] **可逆性**：类型→同一模具打出的东西→打击的印记，可逆
> - [x] **可统筹**："类/印记"可串联所有义项
> - [x] **有支撑**：type of personality（性格类型）、blood type（血型）、type a document（打一份文件）
