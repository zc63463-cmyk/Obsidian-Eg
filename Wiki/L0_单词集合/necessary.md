# necessary

> [!info] 基础信息
> **音标** /ˈnesəsəri/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**必要的，必需的**== ; ②必然的，不可避免的 ;
**n.** ①必需品（通常用复数 necessaries） ;

> [!tip] 原型义
> **原型义**：必要的，必需的——不能缺少的、必须具备的
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（直接抽象概念）

## 词根词缀

ne-(否定前缀，"不") + cess(走/退让) + -ary(形容词后缀，"与…有关的")
**叙事**：ne(不) + cess(退让) + ary(的)——"不能退让的"，即 **necessary**（必要的），没有它不行。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**必要的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **必要的**（不可缺少的）
>    - → **必然的**：从"不可缺少"引申为逻辑上的必然性
>      - 激活条件：描述逻辑推理中必然产生的结论时
>    - → **必需品**：从形容词转名词，指代不可缺少的东西
>      - 激活条件：描述生活必需品时（daily necessaries）

### 统筹（选择适用的模式）

- **延伸中心**：以"不可缺失性"为中心，从具体必需到逻辑必然
- **一句话统筹**：凡是不可缺失的，就是必要的；逻辑上不可缺失的，就是必然的

> [!check]- 链路验证
> - [x] **可逆性**：从"必然的"可反推回"不可缺失的"
> - [x] **可统筹**：所有义项围绕"不可缺失性"串联
> - [x] **有支撑**：necessary condition / daily necessaries 等常见用法

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 想象一扇门，上面写着"ne(不) cess(退让)"——这扇门你不能绕过、不能后退，必须穿过它。这就是 **necessary**（必要的），没有替代方案。

> **词拆分记忆**：
> ne(不) + cess(像"cess"→cessation 停止) + ary(的) → 不能停止需要的 → **必要的**
