# value

> [!info] 基础信息
> **音标** /ˈvæljuː/ | **词频** 考研高频 | **语义场** [[价值与评估]]

## 核心释义

**n.** ①==**价值**==；②==**重要性，有用性**==；③==**价值观**==（values）；④==**（数学）值**==；
**vt.** ①==**重视，珍视**==；②==**给……估价**==；③==**给……定价**==；

> [!tip] 原型义
> **原型义**：强壮的、值得的（身体强健→值得拥有）
> **延伸维度**：抽象路径
> **隐喻类型**：经济隐喻（身体的"强壮"→ "值得"→ "价值"→ "重视"）

## 词根词缀

**词源关联**：value 源自古法语 *value*，是 *valoir*（值得）的阴性过去分词名词化，源自拉丁语 *valere*（强壮、有价值），与 **valid**（有效的）、**valor**（英勇）、**available**（可用的）同源，均来自原始印欧语根 \*wal-（强壮）。

**叙事**：一个战士**强壮**（valere）→ 他**值得**被尊敬（valoir）→ 他的**价值**被认可（value）→ 人们**重视**他（value him）。从身体的力量到社会的认可，value 是"值得"的名词化结晶。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**值得、有价值**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **值得、有价值**（经济层面）
>    - → **价值**：物品值多少钱
>      - 激活条件：讨论价格、市场、经济时
>    - → **给……估价/定价**（动词）：确定某物的金钱价值
>      - 激活条件：商业、拍卖、评估语境
> 2. **值得、有价值**（社会层面）
>    - → **重要性，有用性**：抽象的价值
>      - 激活条件：讨论信息、经验、资源的价值时
>    - → **价值观**（values）：社会或个人认为值得追求的东西
>      - 激活条件：讨论文化、道德、社会准则时（常作复数）
> 3. **值得、有价值**（情感层面）
>    - → **重视，珍视**（动词）：认为某人/某事有价值
>      - 激活条件：描述人际关系、友谊、建议等（常与 highly 连用）

### 统筹（选择适用的模式）

- **经济隐喻统筹**：value 的核心意象是"值得"，所有引申义都围绕"值得拥有/值得投入"展开——金钱价值是最直接的体现，价值观是社会层面的"值得"，重视是个人情感层面的"值得"
- **延伸中心**：从"值得拥有"出发，沿经济隐喻路径延伸到各个抽象领域

> [!check]- 链路验证
> - [x] **可逆性**：从"重视某人"能反向推导到"值得"——重视就是认为值得
> - [x] **可统筹**：一句话统筹——"value 就是'值得'：名词是价值，动词是重视"
> - [x] **有支撑**：cultural values, value friendship, the value of education 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> value 和 valid（有效的）是亲兄弟——都来自拉丁语 valere"强壮"。一个**强壮**的人**值得**信赖，他的**价值**自然被认可，人们也会**重视**他。记住：value = 值得 = 价值/重视。
>
> **词拆分记忆**（辅助）：
> val（=valere，强壮/值得）+ -ue（名词后缀）→ 值得的东西 → 价值
