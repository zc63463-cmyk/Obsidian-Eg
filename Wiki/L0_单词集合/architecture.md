# architecture

> [!info] 基础信息
> **音标** /ˈɑːrkɪtektʃər/ | **词级** 必备词 | **语义场** [[物品工具]]

## 核心释义

**n.** ①==**建筑学，建筑术**==；②==**建筑风格，建筑式样**==；③==**结构，构造**==；④体系结构（计算机）；

> [!tip] 原型义
> **原型义**：首席建造的艺术与科学（关于如何设计和建造建筑物的知识体系）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（从"建筑物的设计构造"到"任何复杂系统的结构设计"）

## 词根词缀

archi-（首席的）+ tect（建造者）+ -ure（名词后缀，表示行为/结果/领域）
建议创建词根笔记 [[arch]]（首席的/统治的）
**叙事**：archi（首席）+ tect（建造）+ ure（领域）= "首席建造的学问"——这就是 architecture 的原型。后来不只是造房子的学问，计算机的"骨架设计"（计算机体系结构），一个组织的"框架设计"（组织架构），都是 architecture。记住：architecture = architect（建筑师）的学问 = 建筑学/结构设计。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**首席建造的艺术与科学**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **首席建造的艺术与科学**（建筑层面）
>    - → **建筑学，建筑术**：设计和建造建筑物的学科
>      - 激活条件：study architecture, school of architecture，描述建筑学科
>    - → **建筑风格，建筑式样**：建筑物的设计风格
>      - 激活条件：Gothic architecture, modern architecture，描述建筑风格
> 2. **首席建造的艺术与科学**（抽象层面）
>    - → **结构，构造**：任何复杂系统的框架设计
>      - 激活条件：the architecture of the brain/internet，描述系统结构
>    - → **体系结构（计算机）**：计算机系统的整体设计
>      - 激活条件：computer architecture, software architecture，描述计算机架构

### 统筹（选择适用的模式）

- **延伸中心**："骨架设计"——无论是房子的骨架、大脑的骨架还是计算机的骨架，architecture 都是关于"如何搭建框架"
- **一句话统筹**：architecture 就是"骨架设计学"——设计房子的骨架叫建筑学，设计软件的骨架叫体系结构

> [!check]- 链路验证
> - [x] **可逆性**：从"计算机体系结构"能反向推导到"计算机系统的骨架设计"
> - [x] **可统筹**：一句话统筹——"architecture 就是骨架设计学"
> - [x] **有支撑**：computer architecture, brain architecture, modern architecture 均有大量语料支撑

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 建筑师（architect）把蓝图变成现实，而 architecture 就是这位"首席建造者"所掌握的全部学问。从古埃及金字塔到现代摩天大楼，从人脑神经网络到计算机芯片，所有复杂系统都需要"骨架设计"——这就是 architecture。记住：architecture = architect（建筑师）+ ure（学问）= 建筑学/结构设计。
>
> **词拆分记忆**（辅助）：
> arch（拱门/首席）+ i + tect（建造）+ ure（领域）→ 首席建造的领域 → 建筑学
