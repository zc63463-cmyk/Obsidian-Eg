# elegant

> [!info] 基础信息
> **音标** /ˈelɪɡənt/ | **词级** 必备词 | **语义场** [[人本世界]]

## 核心释义

**adj.** ①==**优雅的，精美的**==（举止、风格、外观优美高雅）；②==**简洁的，精炼的**==（方案、证明等简洁而巧妙）；

> [!tip] 原型义
> **原型义**：精心挑选的→优雅的（从众多选项中精心挑选出最好的，因此品质出众）
> **延伸维度**：抽象路径
> **隐喻类型**：选择隐喻（从"精心挑选"→ "品质出众"→ "优雅/简洁"）

## 词根词缀

**词根拆分**：e-（=ex-，出）+ [[leg]]（选择）+ -ant（形容词后缀）→ 挑选出来的 → 精致的

**词根 leg**（选择）：核心词根，衍生词汇——[[elect]]（选举，选出）、[[select]]（选择，se-分开+leg选）、[[collect]]（收集，col-一起+leg选→选到一起）

**叙事**：elegant = e（出来）+ leg（选择）+ ant → 从众多选项中"挑选出来的"。想象一个裁缝，从上百种布料中精心挑选出最好的一款——做出来的衣服自然"优雅精美"。在学术中，一个数学证明从众多方法中选出了最简洁优美的一种——这就是 elegant（简洁巧妙的）。记住 leg = 选择，elegant = 挑选出来的 = 优雅的。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**精心挑选的→优雅的**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **精心挑选的**（品质层面）
>    - → **优雅的，精美的**：品质出众、品味高雅
>      - 激活条件：描述人/风格/外观（elegant woman / style / dress）
>    - → **简洁的，精炼的**：在学术/技术语境中，指方案简洁而巧妙
>      - 激活条件：学术/工程语境（elegant solution / proof / design）

### 统筹（选择适用的模式）

- **一字一词概括**：elegant = "精选"——精心挑选的，品质出众
- **一句话统筹**：elegant 就是"精心挑选出来的"——优雅精美、简洁巧妙

> [!check]- 链路验证
> - [x] **可逆性**：从"简洁的"能反向推导到"精心挑选的"——简洁是因为选出了最优方案
> - [x] **可统筹**：一句话统筹——"elegant 就是精心挑选出来的"
> - [x] **有支撑**：elegant style, elegant solution, elegant woman 均为高频搭配
