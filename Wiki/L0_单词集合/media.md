# media

> [!info] 基础信息
> **音标** /ˈmiːdiə/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**媒体，新闻界**==（大众传播媒介的总称，如电视、报纸、互联网等）；

> [!tip] 原型义
> **原型义**：medium 的复数形式（多种媒介的集合→大众媒体）
> **延伸维度**：抽象路径
> **隐喻类型**：集合转义（从"多个媒介"到"新闻界/大众媒体"的整体概念）

## 词根词缀

**词源**：[[media]] 是 [[medium]]（媒介）的拉丁语复数形式。medium = [[medi]]（中间）+ -um（名词后缀）→ 中间的东西 → 媒介。复数 media = 多种媒介 → 大众媒体。

**词根 medi**（中间）：核心词根，衍生大量词汇——[[mediate]]（调解）、[[immediate]]（立即的）、[[medieval]]（中世纪的）、[[medicine]]（医学）

**叙事**：一个电视频道是一种 medium（媒介），一份报纸也是一种 medium，一个网站也是一种 medium——把它们全部加在一起，就是 media（媒体）。所以 media 本质上就是"所有媒介的集合"。在现代社会中，media 已经特指"大众媒体/新闻界"——那些站在信息源和公众之间传递信息的力量。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**medium 的复数→媒体**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **medium 的复数**（集合层面）
>    - → **媒体，新闻界**：所有大众传播媒介的总称
>      - 激活条件：传播/新闻/社会语境（mass media / social media / media coverage）
>    - → **新闻界人士**（集合用法）：从事媒体工作的人
>      - 激活条件：描述舆论/报道（the media reported / media attention）

### 统筹（选择适用的模式）

- **一字一词概括**：media = "媒体"——大众传播媒介的总称
- **一句话统筹**：media 就是 medium 的复数——所有媒介加在一起就是"媒体"

> [!check]- 链路验证
> - [x] **可逆性**：从"新闻界"能反向推导到"medium 的复数"——新闻界就是各种媒介的集合
> - [x] **可统筹**：一句话统筹——"media 就是 medium 的复数形式"
> - [x] **有支撑**：mass media, social media, media coverage, media attention 均为高频搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> media 就是 medium（媒介）的复数。一个电视频道是 medium，一份报纸是 medium，一个网站是 medium——全部加在一起就是 media（媒体）。记住 medium = 媒介，media = 媒体（复数）。就像 bacterium→bacteria 一样，这是拉丁语复数。
>
> **词拆分记忆**（辅助）：
> me（我）+ di（地）+ a → 我站在地上，面对所有人 → 媒体（面向大众传播）

## 搭配与短语

> [!example]- 搭配 · L3
> - **mass media**：大众媒体
> - **social media**：社交媒体
> - **media coverage**：媒体报道
> - **media attention**：媒体关注
> - **the media**：新闻界（the + media 表集合概念）
> - **media hype**：媒体炒作

## 真题/语料关联

> [!example]- 语料 · L3
> - "The media plays a crucial role in shaping public opinion."（媒体在塑造公众舆论方面发挥着关键作用）——社会/传播话题
> - "Social media has transformed the way we communicate."（社交媒体改变了我们的交流方式）——科技/社会话题
> - "The event received extensive media coverage."（该事件受到了媒体的广泛报道）——新闻话题
> - "The media were accused of biased reporting."（新闻界被指控报道有偏见）——注意 media 作复数动词
