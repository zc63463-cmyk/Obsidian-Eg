# memory

> [!info] 基础信息
> **音标** /ˈmeməri/ | **词频** 考研高频 | **语义场** [[科学逻辑]]

## 核心释义

**n.** ①==**记忆，记忆力**==；②存储器，内存；③回忆，留存的记忆；

> [!tip] 原型义
> **原型义**：大脑中存储和提取过去经验的能力
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（记忆-容器/存储）

## 词根词缀

memor(记忆，mind) + -y(名词后缀，表状态/能力)
**叙事**：大脑中用来"记忆"的那部分能力或空间

---

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**存储和提取信息的能力**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **存储和提取信息的能力**（认知层面：大脑的记忆功能）
>    - → **记忆/记忆力**（心理层面：记住和回忆的能力）
>      - 激活条件：描述人的记忆能力、记忆好坏时取此义
>    - → **回忆/留存的记忆**（内容层面：被记住的具体内容）
>      - 激活条件：描述某段具体的回忆、童年记忆时取此义
>    - → **存储器/内存**（技术层面：计算机的数据存储空间）
>      - 激活条件：计算机语境中描述内存、存储时取此义

### 统筹（选择适用的模式）

- **一句话统筹**：存储信息、保存经验、随时可以提取的能力或空间

> [!check]- 链路验证
> - [x] **可逆性**：从"内存"可以回溯到"存储信息"的原型
> - [x] **可统筹**：所有义项都围绕"存储-提取"的信息处理关系
> - [x] **有支撑**：memor(记忆) + -y(状态/能力) 的词源结构直接支撑"记忆能力"的原型义

## 搭配与短语

> [!example]- 搭配 · L3
> - **in memory of**：为纪念……
  - A scholarship was established in memory of the late professor.（为纪念已故教授设立了一项奖学金。）
> - **from memory**：凭记忆
  - The pianist played the entire piece from memory.（钢琴家凭记忆弹奏了整首曲子。）
> - **short-term/long-term memory**：短期/长期记忆
  - Sleep plays a crucial role in consolidating long-term memory.（睡眠在巩固长期记忆方面起着关键作用。）

## 真题/语料关联

> [!example]- 语料 · L3
> - Research has shown that regular exercise can improve memory and cognitive function in older adults.（研究表明，定期锻炼可以改善老年人的记忆力和认知功能。）
> - The computer's memory needs to be upgraded to run the new software.（计算机的内存需要升级才能运行新软件。）
