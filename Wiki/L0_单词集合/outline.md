# outline

> [!info] 基础信息
> **音标** /ˈaʊtlaɪn/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**大纲，提纲**== ; ②轮廓，外形 ;
**v.** ①概述，略述 ; ②画出…的轮廓 ;

> [!tip] 原型义
> **原型义**：轮廓——物体外缘的线条
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（大纲=思想的"轮廓线条"）

## 词根词缀

out(外面) + line(线条) → "外面的线条"
**叙事**：out(外) + line(线)——画出事物外面的线条，就是 **outline**（轮廓）。写文章前先画"思想的轮廓"，就是大纲。

---

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**轮廓**"为统筹中心，沿空间路径向外扩展：
>
> 1. **轮廓**（物理层面：物体外缘的线条）
>    - → **大纲，提纲**：从物理轮廓隐喻为思想/文章的结构框架
>      - 激活条件：描述文章、演讲的结构框架时
>    - → **概述**（动词）：从画出轮廓引申为概括描述
>      - 激活条件：描述简要说明某事时

### 统筹（选择适用的模式）

- **延伸中心**：以"外部线条/框架"为中心，从物理轮廓到思想框架
- **一句话统筹**：outline 就是"画出外部的线条"——无论是物体的轮廓还是思想的框架

> [!check]- 链路验证
> - [x] **可逆性**：从"大纲"可反推回"思想的轮廓"
> - [x] **可统筹**：所有义项围绕"外部线条/框架"串联
> - [x] **有支撑**：course outline / outline the main points 等常见用法

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 想象一个画家先在画布上勾勒出人像的 **outline**（轮廓）——只有线条，没有细节。写论文也一样，先写 **outline**（大纲），再填充内容。

> out(外面) + line(线) → 画在外面的线 → **轮廓 → 大纲**
