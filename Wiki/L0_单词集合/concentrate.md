# concentrate

> [!info] 基础信息
> **音标** /ˈkɒnsntreɪt/ | **词频** 考研高频 | **语义场** [[认知思维]]

## 核心释义

**v.** ①==**集中（注意力），全神贯注**== ; ②==**集中，聚集**==（资源/力量） ; ③浓缩 ;
**n.** ①浓缩物，浓缩液 ;

> [!tip] 原型义
> **原型义**：聚到中心，使汇聚到一个焦点
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（注意力/资源 = 物质，向中心汇聚）

## 词根词缀

con-(一起) + centr(中心) + -ate(动词后缀) = concentrate（聚到中心）
**叙事**：把分散的光线**一起汇聚到中心**，形成一束强光——这就是"集中"。

---

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**聚到中心**"为统筹中心，沿空间路径向外扩展：
>
> 1. **聚到中心**（物理层面——物质向中心汇聚）
>    - → **浓缩**：溶液中物质向中心聚集，浓度增大
>      - 激活条件：orange juice concentrate（浓缩橙汁）
>    - → **n. 浓缩物**：聚集后的产物
>      - 激活条件：fruit juice concentrate（浓缩果汁）
> 2. **聚到中心**（认知层面——注意力向一个焦点汇聚）
>    - → **集中注意力，全神贯注**：把分散的注意力聚到中心
>      - 激活条件：concentrate on sth.（集中注意力于…）
> 3. **聚到中心**（社会层面——资源/力量汇聚）
>    - → **集中，聚集**：把分散的资源/力量汇聚到一处
>      - 激活条件：concentrate efforts/resources on（集中精力/资源于）

### 统筹（选择适用的模式）

- **一字一词概括**："聚"——聚到中心
- **一句话统筹**：从注意力集中到资源聚集再到溶液浓缩，都是"聚到中心"

> [!check]- 链路验证
> - [x] **可逆性**：集中注意力 → 把注意力聚到中心 → 聚到中心
> - [x] **可统筹**：所有义项都围绕"聚到中心"展开
> - [x] **有支撑**：concentrate on study（集中学习），concentrated juice（浓缩果汁）
