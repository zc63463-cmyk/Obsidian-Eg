# disappear

> [!info] 基础信息
> **音标** /ˌdɪsəˈpɪə(r)/ | **词频** 考研高频 | **语义场** [[自然物理]]

## 核心释义

**vi.** ①==**消失，不见**== ; ②==**消亡，灭绝**==（物种等） ;

> [!tip] 原型义
> **原型义**：从视线中消失、不再出现
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻（消失 = 从视野中移走）

## 词根词缀

dis-(离开/取消) + [[cover|appear]](出现) → 不再出现
**叙事**：从视野中离开，不再出现 → 消失。

建议创建词根笔记 [[cover]]

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**从视线中消失**"为统筹中心，沿空间路径向外扩展：
>
> 1. **从视线中消失**（空间层面：离开视野）
>    - → **消失/不见**：人或物从视野中离开 → 激活条件：日常描述事物不见时
>    - → **消亡/灭绝**：物种从地球上消失 → 激活条件：生态/历史语境

### 统筹（选择适用的模式）

- **一字一词概括**："没"——消失不见
- **一句话统筹**：从眼前消失到物种灭绝，都是"不再出现"

> [!check]- 链路验证
> - [x] **可逆性**：消亡 → 从世界上消失 → 不再出现
> - [x] **可统筹**：所有义项围绕"不再出现"
> - [x] **有支撑**：disappear from view / species disappear 为常见搭配

> [!note]- 词性-词义链接 · L1
