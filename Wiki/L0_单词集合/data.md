# data

> [!info] 基础信息
> **音标** /ˈdeɪtə/ | **词频** 考研高频 | **语义场** [[信息概念]]

## 核心释义

**n.** ①==**数据，资料**==；②==**事实，信息**==；（datum 的复数形式）

> [!tip] 原型义
> **原型义**：给定的事实（作为推理或计算基础而被"给予"的东西）
> **延伸维度**：抽象路径
> **隐喻类型**：无隐喻（从"给定的事实"直接引申为"数据/资料"，属于抽象概念的直接扩展）

## 词根词缀

**词源关联**：data 是拉丁语 *datum*（给定的东西）的复数形式，*datum* 是 *dare*（给予）的中性过去分词。可追溯到原始印欧语 *\*do-*（给予），同源词包括 donate（捐赠）、dose（剂量）、date（日期——源自"given at Rome"的文书标注）。在古典用法中，data 最初指"作为数学问题计算基础而给定的事实"，17 世纪起在科学和哲学中被广泛使用，19 世纪末开始指"为将来参考而收集的数值事实"，20 世纪计算机时代成为"可传输和存储的信息"的代名词。

**叙事**：在拉丁语中，data 就是"**被给予的东西**"（datum 的复数）。科学家做实验时，实验结果就是大自然**给予**他们的 data；计算机处理的信息也是被**输入给予**的 data。从数学题的"已知条件"到大数据时代的"海量数据"，data 始终是那个"被给予、被收集、被处理的信息"。

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**给定的事实**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **给定的事实**（学术/数学层面）
>    - → **已知条件，给定事实**：作为推理或计算基础的信息
>      - 激活条件：数学、逻辑推理语境
> 2. **给定的事实**（科学/信息层面）
>    - → **数据，资料**：收集到的数值事实或信息
>      - 激活条件：collect/analyze/process data, data analysis
>    - → **可传输和存储的信息**：计算机科学中的数字化信息
>      - 激活条件：data processing, data storage, big data

### 统筹（选择适用的模式）

- **延伸中心**：data 的核心特征是"被给予的信息/事实"，所有用法都共享这个本质——无论是数学已知条件、科学观测数据还是计算机数据，都是"被提供、被收集、被处理的信息"
- **一句话统筹**："data 就是被给予的信息——从数学题的已知条件到计算机的海量数据"

> [!check]- 链路验证
> - [x] **可逆性**：从"计算机数据"能反向推导到"给定的事实"——数据就是被输入的信息
> - [x] **可统筹**：一句话统筹——"data 就是被给予/收集的信息"
> - [x] **有支撑**：collect data, analyze data, big data, data processing 均为考研高频搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> data 来自拉丁语 datum（给定的东西），是 dare（给予）的过去分词。想象一个数学老师对你说："这些**已知条件**是我**给予**你的 data。"科学家从实验中**收集**（collect）data，分析师**分析**（analyze）data，计算机**处理**（process）data——data 就是那个被"给予"的信息，从古罗马的数学课堂到今天的硅谷数据中心，从未改变。
>
> **词根记忆**（辅助）：
> da（= give，给予，同源 donate 捐赠）+ ta → 被给予的东西 → 数据
