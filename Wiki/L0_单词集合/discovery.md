# discovery

> [!info] 基础信息
> **音标** /dɪˈskʌvəri/ | **词级** 必备词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**发现，发觉**== ; ②==**被发现的事物**==（尤指科学发现） ;

> [!tip] 原型义
> **原型义**：移除覆盖后暴露出的东西
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（发现 = 移除覆盖物）

## 词根词缀

dis-(移除) + [[cover|cover]](覆盖) + -y(名词后缀，表状态/结果) → 移除覆盖的结果
**叙事**：移除覆盖后得到的结果 → 发现、被发现的事物。

建议创建词根笔记 [[cover]]

## 词义链路

> [!abstract]- 词义链路法
> 以"**移除覆盖的结果**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **移除覆盖的结果**（认知层面：发现的过程）
>    - → **发现/发觉**：发现这个动作本身 → 激活条件：描述研究过程
>    - → **被发现的事物**：发现的结果 → 激活条件：科学发现、重大发现

### 统筹（选择适用的模式）

- **一字一词概括**："现"——发现
- **一句话统筹**：发现的过程和发现的结果，都是"移除覆盖"

> [!check]- 链路验证
> - [x] **可逆性**：科学发现 → 被发现的事物 → 移除覆盖的结果
> - [x] **可统筹**：所有义项围绕"发现"
> - [x] **有支撑**：scientific discovery / make a discovery 为常见搭配
