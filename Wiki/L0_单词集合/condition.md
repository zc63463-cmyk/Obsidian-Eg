# condition

> [!info] 基础信息
> **音标** /kənˈdɪʃn/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**条件，前提**== `on condition that-clause` ; ②==**状况，状态**== `in good/poor condition` ; ③==**疾病，健康状况**== `N` ;
**vt.** ①==**决定，制约**== `be conditioned by N` ; ②==**使适应，使习惯**== `condition sb. to V` ;

> [!tip] 原型义
> **原型义**：共同商定的状态、约定好的前提
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（条件 = 约定框架）

## 词根词缀

con-(共同/一起) + [[dict|dict/dic]](说) + -ion(名词后缀) → 共同说好的事
**叙事**：大家共同说好、约定好的事 → 条件、状况。

建议创建词根笔记 [[dict/dic]]

## 词义链路

> [!abstract]- 词义链路法
> 以"**共同约定的状态**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **共同约定的状态**（社会层面：双方说好的前提）
>    - → **条件/前提**：做事前约定好的要求 → 激活条件：谈判、合同、协议语境
>    - → **状况/状态**：事物所处的"约定状态" → 激活条件：描述事物情况时
>    - → **健康状况**：身体的"状态" → 激活条件：医疗语境
>    - → **制约/决定**：用条件来约束 → 激活条件：被动语态 be conditioned by
>    - → **使适应**：使进入某种状态 → 激活条件：condition sb. to do

### 统筹（选择适用的模式）

- **一字一词概括**："态"——所处的状态
- **一句话统筹**：从约定条件到身体状态，都是事物所处的"态"

> [!check]- 链路验证
> - [x] **可逆性**：条件 → 约定好的前提 → 共同说好的事
> - [x] **可统筹**：所有义项围绕"状态/条件"
> - [x] **有支撑**：on condition that / in good condition 为高频搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> con（共同）+ dict（说）→ 大家共同商量说好的事 → 条件。想象两个人谈判，你一句我一句，最后说好"在...条件下成交"。
>
> **词拆分记忆**：
> con + di + tion → 大家(con)一起讨论(di)的状态(tion) → 条件

## 搭配与短语

> [!example]- 搭配
> - **on condition that**：在...条件下
> - **in good/poor condition**：状况良好/糟糕
> - **living conditions**：生活条件
> - **be conditioned by**：受...制约
