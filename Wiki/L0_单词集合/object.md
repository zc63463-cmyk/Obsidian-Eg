# object

> [!info] 基础信息
> **音标** /ˈɒbdʒɪkt/（n.） /əbˈdʒekt/（v.） | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**n.** ①==**物体，东西**==；②==**目标，目的**==；③==**客体，对象**==（哲学/语法）；④宾语（语法）；
**vi.** ①==**反对，不赞成**==（object to sth./doing sth.）；
**vt.** ①以…为理由反对（object that...）；

> [!tip] 原型义
> **原型义**：摆在眼前的东西（被投掷到面前的物体）
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（物理的"摆在面前的东西"→ 抽象的"目标/对象/被反对的事物"）

## 词根词缀

**词根拆分**：ob-（朝向、对面）+ [[ject]]（投掷）→ 投掷到面前 → 摆在眼前的东西

**词根 ject**（投掷）：来自拉丁语 *jacere*（投掷），衍生大量词汇

**叙事**：拉丁语 obiectum 就是"被扔到面前的东西"。想象你在路上走，突然有人把一个**东西扔到你面前**——这就是 object 的本义"物体"。后来，你心里有个"摆在面前的目标"要追求，或者你对"摆在面前的提议"说"不"——反对。记住 ject = 扔，object = 扔到你面前的东西。

## 词义链路

> [!abstract]- 词义链路法
> 以"**摆在眼前的东西**"为统筹中心，沿空间路径向外扩展：
>
> 1. **摆在眼前的东西**（物理层面）
>    - → **物体、东西**：被感知到的实体
>      - 激活条件：描述物理对象（a strange object / everyday objects）
> 2. **摆在眼前的东西**（抽象层面）
>    - → **目标、目的**：摆在面前的追求对象
>      - 激活条件：描述目标/目的（the object of the exercise / study）
>    - → **客体、对象**：哲学/语法中被观察/被作用的对象
>      - 激活条件：学术/语法语境（object of study / direct object）
>    - → **反对**：对"摆在面前的提议"投掷反对（动词用法）
>      - 激活条件：表达反对意见（object to the plan / I object!）

### 统筹（选择适用的模式）

- **结构隐喻统筹**：object 的核心意象是"摆在面前"，所有引申义共享这个结构——物体是摆在面前的实体，目标是摆在面前的追求，反对是对摆在面前的提议说"不"
- **一句话统筹**：object 就是"摆在面前的东西"——面前有物体、面前有目标、面前有提议（反对它）"

> [!check]- 链路验证
> - [x] **可逆性**：从"反对"能反向推导到"摆在面前"——反对就是对摆在面前的提议说不
> - [x] **可统筹**：一句话统筹——"object 就是摆在面前的东西"
> - [x] **有支撑**：physical object, object of study, object to 均为高频搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> object = ob（对面）+ ject（扔）→ 扔到面前 → 摆在眼前的东西。想象开会时有人提出一个方案，你把反对意见**扔到对方面前**——这就是 object（反对）。记住 ject = 扔，ob = 对面，object 就是"扔到面前的"。
>
> **词拆分记忆**（辅助）：
> ob（反）+ ject（扔）→ 把反对扔过去 → 反对

## 搭配与短语

> [!example]- 搭配
> - **object to sth. / doing sth.**：反对某事/做某事（⚠️ 后接 to + 名词/动名词，不接动词原形）
> - **object that...**：提出…作为反对理由
> - **the object of the exercise / study**：…的目标/目的
> - **no object**：不成问题（money is no object = 钱不是问题）
> - **direct / indirect object**：直接/间接宾语

## 真题/语料关联

> [!example]- 语料
> - "Many people object to experimentation on animals."（许多人反对动物实验）——经典搭配，高频出现
> - "He objected that the plan was impractical."（他反对说该计划不可行）——object that 从句用法
> - "The object of the research is to identify the cause."（研究的目的是找出原因）——学术语境
> - "Money is no object."（钱不是问题）——日常/商业语境
