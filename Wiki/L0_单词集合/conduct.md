# conduct

> [!info] 基础信息
> **音标** /kənˈdʌkt/ (v.) ; /ˈkɒndʌkt/ (n.) | **词频** 考研高频 | **语义场** [[人本世界]]

## 核心释义

**vt.** ①==**组织，实施，进行**== ; ②==**指挥（乐队）**== ; ③==**引导，带领**== ; ④==**传导（热/电）**== ;
**n.** ①==**行为，举止**== ; ②==**管理方式，实施方法**== ;

> [!tip] 原型义
> **原型义**：引导、带领前行
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（组织活动 = 引导方向）

## 词根词缀

con-(共同/一起) + [[duct|duct/duc]](引导) → 引导大家一起做
**叙事**：引导大家朝一个方向走 → 组织、指挥、引导。

建议创建词根笔记 [[duct/duc]]

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**引导**"为统筹中心，沿社会路径向外扩展：
>
> 1. **引导**（物理层面：带领前行）
>    - → **指挥（乐队）**：引导音乐方向 → 激活条件：音乐语境
>    - → **组织/实施**：引导活动的进行 → 激活条件：研究、调查、实验等
>    - → **传导**：引导热/电流动 → 激活条件：物理/科学语境
>    - → **行为/举止**：引导自己的方式 → 激活条件：描述人的行为时（名词）
>    - → **管理方式**：引导组织的方式 → 激活条件：商业/管理语境（名词）

### 统筹（选择适用的模式）

- **一字一词概括**："导"——引导
- **一句话统筹**：从指挥乐队到组织研究，都是"引导"的不同场景

> [!check]- 链路验证
> - [x] **可逆性**：组织研究 → 引导研究进行 → 引导
> - [x] **可统筹**：所有义项围绕"引导"
> - [x] **有支撑**：conduct research / conduct an experiment 为高频搭配

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**：
> con（一起）+ duct（引导，管道）→ 用管道把大家引导到一起 → 组织、指挥。想象你拿着指挥棒，引导整个交响乐团一起演奏。
>
> **词拆分记忆**：
> con + duct（管道/导管）→ 通过管道引导 → 传导、引导
