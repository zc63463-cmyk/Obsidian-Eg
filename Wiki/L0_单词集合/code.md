# code

> [!info] 基础信息
> **音标** /kəʊd/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**代码；编码**==；②法典，法规；③密码，代号；④道德准则，行为规范

**v.** ①编码；将……转换成代码

> [!tip] 原型义
> **原型义**：法典、系统化的规则（a systematic collection of laws or regulations）
> **延伸维度**：抽象路径——从"法律条文"到"符号系统"再到"道德规范"
> **隐喻类型**：结构隐喻（将"法律规则"的结构映射到"符号系统"和"行为规范"——都是系统化的规则体系）

## 词根词缀

code 源自拉丁语 codex（树干、木板、法典书），codex 原指在木板上刻写的法律条文
**叙事**：古罗马人在木板上刻写法律条文，编成法典（codex → code）。后来所有"系统化的符号规则"都叫 code——计算机代码是机器的规则，密码是秘密的规则，道德准则做人的规则。
