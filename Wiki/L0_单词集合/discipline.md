# discipline

> [!info] 基础信息
> **音标** /ˈdɪsəplɪn/ | **词级** 必备词 | **语义场** [[社会习俗]]

## 核心释义

**n.** ①==**纪律，风纪**== ; ②==**学科，专业领域**== ; ③==**训练，管教**== ;
**vt.** ①==**训练，管教**== ; ②==**惩罚，处罚**== ;

> [!tip] 原型义
> **原型义**：学习、训练（源自拉丁语 discipulus 学习者）
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（学科 = 训练体系）

## 词根词缀

[[dis-di|dis-]](分开/学习) + [[cip/cap|cip]](抓取) + -line(线) → 沿着一条线学习
**叙事**：沿着一条线系统地学习 → 学科、纪律。

## 词义链路

> [!abstract]- 词义链路法
> 以"**学习训练**"为统筹中心，沿社会路径向外扩展：
>
> 1. **学习训练**（教育层面：系统学习）
>    - → **学科/专业**：系统学习的领域 → 激活条件：学术语境
>    - → **纪律**：训练中必须遵守的规则 → 激活条件：学校、军队语境
>    - → **管教/训练**：对人的系统训练 → 激活条件：教育、育儿语境
>    - → **惩罚**：训练中违反规则后的手段 → 激活条件：惩罚语境

### 统筹（选择适用的模式）

- **一字一词概括**："训"——训练
- **一句话统筹**：从学科到纪律到管教，都是"系统训练"的不同面向

> [!check]- 链路验证
> - [x] **可逆性**：纪律 → 训练中的规则 → 系统训练
> - [x] **可统筹**：所有义项围绕"系统训练"
> - [x] **有支撑**：academic discipline / strict discipline 为常见搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> 源自拉丁语 discipulus（学习者，即 disciple 弟子的词源）。学习者需要沿着一条线(line)系统地抓取(cip)知识 → 学科。军队里沿着一条线训练 → 纪律。
>
> **词拆分记忆**：
> dis + cip（抓）+ line（线）→ 沿着一条线抓取知识 → 学科、纪律
