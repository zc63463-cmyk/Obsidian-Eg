# model

> [!info] 基础信息
> **音标** /ˈmɒdl/ | **词级** 必备词 | **语义场** [[理性世界]]

## 核心释义

**n.** ①==**模型，模式**== ; ②模特 ; ③模范，典型 ;
**v.** ①模仿，建模 ;

> [!tip] 原型义
> **原型义**：以特定方式呈现的小型实物（缩小的样式）
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻——"模型"如小型实物般代表更大的系统

## 词根词缀

[[mod]](方式/样式) + -el(指小后缀) → 以特定方式呈现的小型物 → 模型
**叙事**：建筑师用**小型的方式**（mod + el）呈现大楼的样子，这就是模型。

## 词义链路

> [!abstract]- 词义链路法
> 以"**以特定方式呈现的小型实物**"为统筹中心，沿**抽象路径**向外扩展：
>
> 1. **以特定方式呈现的小型实物**（物理层面：缩小的实物模型）
>    - → ==**模型，模式**==：代表更大系统的简化版本
>      - 激活条件：描述科学模型、商业模式、理论框架时
>    - → **模特**：以身体展示服装样式的人
>      - 激活条件：描述时尚行业中的展示者时
>    - → **模范，典型**：值得模仿的样式
>      - 激活条件：描述值得学习的榜样时
>    - → **模仿，建模**：按某种样式制作
>      - 激活条件：描述按模型构建或模仿行为时

### 统筹

- **一字一词概括**："样"——样式即核心
- **延伸中心**：mod-族的"方式/样式"核心

> [!check]- 链路验证
> - [x] **可逆性**：从"模型/模特/模范"可反向推导回"小型样式"
> - [x] **可统筹**：所有义项都围绕"样式/方式"这一核心
> - [x] **有支撑**：role model / business model / model student 等高频搭配

## 搭配与短语

> [!example]- 搭配
> - **role model**：榜样，模范

> - **model on**：模仿……的模式
>   The new system is modeled on the previous successful framework.
