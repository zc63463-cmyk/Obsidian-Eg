# refresh

> [!info] 基础信息
> **音标** /rɪˈfreʃ/ | **词级** 必备词 | **语义场** [[人体动作]]

## 核心释义

**vt.** ①==**使恢复精力，使清凉**== `refresh sb./oneself` ; ②刷新（记忆/页面） `refresh one's memory` ; ③提醒，使记起 ;
**vi.** ①恢复精神 ;

> [!tip] 原型义
> **原型义**：使重新变得新鲜、恢复活力
> **延伸维度**：具身路径
> **隐喻类型**：本体隐喻（精力=可被补充的液体，如"清凉饮料"）

## 词根词缀

re-(再次) + [[fresh|fresh]](新鲜的) → 使重新变得新鲜 → 恢复精力
**叙事**：炎炎夏日喝一杯冰水，让身体重新变得新鲜有活力，这就是 refresh。

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**使重新变得新鲜**"为统筹中心，沿具身路径向外扩展：
>
> 1. **使重新变得新鲜**（物理层面：使恢复清凉、新鲜）
>    - → **使恢复精力**：使人重新充满活力
>      - 激活条件：主语为休息、饮料、空气等，宾语为人
>    - → **刷新（记忆/数据）**：使信息重新更新
>      - 激活条件：宾语为 memory, page, data 等信息类名词
>    - → **提醒，使记起**：使记忆重新变得清晰
>      - 激活条件：refresh one's memory 固定搭配

### 统筹（选择适用的模式）

- **一字一词概括**："新"——使重新焕然一新
- **一句话统筹**：无论是喝杯茶恢复精力，还是刷新网页更新数据，都是让事物"重新变得新鲜"。

> [!check]- 链路验证
> - [x] **可逆性**：从"刷新记忆"可反向推导至"使重新变得新鲜"
> - [x] **可统筹**：一个"新"字贯穿所有义项
> - [x] **有支撑**：refresh one's memory / refresh the page 均为常见用法
