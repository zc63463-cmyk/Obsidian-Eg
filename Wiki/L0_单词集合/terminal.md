# terminal

> [!info] 基础信息
> **音标** /ˈtɜːmɪnl/ | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**adj.** ①==**晚期的，不治的**== `adj N` [医学]；②==**末端的，终点的**== `adj N` [通用]；
**n.** ①==**航站楼，终端**== `N` [通用]；②==**终端机**== `N` [通用]；③==**终点站**== `N` [通用]；
> [!tip] 原型义
> **原型义**：边界处的终点（源自拉丁语 *terminalis*，"属于边界的"，来自 *terminus* "边界/终点"）
> **延伸维度**：空间路径
> **隐喻类型**：空间边界隐喻（物理上的"边界/终点" → 疾病的"晚期" → 交通/计算的"终端"）

## 词根词缀

**词源关联**：terminal 源自拉丁语 *terminalis*（属于边界的、终点的），由 *terminus*（边界、终点、界碑）+ *-alis*（形容词后缀）构成。*terminus* 在古罗马既是标记土地边界的石头，也是掌管边界的神。同源词包括 [[term]]、[[terminate]]、[[determine]]、[[exterminate]]。

**叙事**：古罗马的 *terminus* 是一块界碑，标记"到此为止"。*terminalis* 就是"属于这块界碑的"——也就是"终点的、边界的"。疾病的**晚期**（terminal illness）就是到了生命的边界；机场的**航站楼**（terminal）是旅程的起点或终点；计算机的**终端**（terminal）是数据传输的终点。从一块石头到一台电脑，terminal 始终标记着"终点"。

## 词义链路

> [!abstract]- 词义链路法
> 以"**边界处的终点**"为统筹中心，沿空间路径向外扩展：
>
> 1. **边界处的终点**（空间/物理层面）
>    - → **末端的/终点的**：位于某事物的末端或边界
>      - 激活条件：描述物理位置、结构时（terminal building, terminal station）
>    - → **航站楼/终点站/终端机**：交通或信息传输的终点设施
>      - 激活条件：旅行、计算机语境（airport terminal, computer terminal）
> 2. **边界处的终点**（隐喻层面）
>    - → **晚期的/不治的**（疾病）：到了生命的边界
>      - 激活条件：医学语境（terminal illness, terminal patient）
>    - → **致命的**：导致死亡的终点
>      - 激活条件：医学/极端语境（terminal disease）

### 统筹（选择适用的模式）

- **空间边界隐喻统筹**：terminal 的核心是"边界处的终点"，所有引申义都围绕"到达终点"展开——无论是物理的终点站、数据的终端还是生命的晚期，都是"到了边界"
- **延伸中心**：从"空间的终点"出发，沿空间边界隐喻路径延伸到"生命的终点/疾病的晚期"

> [!check]- 链路验证
> - [x] **可逆性**：从"晚期疾病"能反向推导到"终点"——晚期就是到了生命的终点
> - [x] **可统筹**：一句话统筹——"terminal 就是到了终点：航班的终点是航站楼，数据的终点是终端，生命的终点是晚期"
> - [x] **有支撑**：airport terminal, terminal illness, computer terminal 均有语料支撑

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> terminal 来自拉丁语 terminus（边界/终点）。想象古罗马的界碑——到了这里就不能再往前了。机场的 **terminal**（航站楼）是你旅程的终点或起点；计算机的 **terminal**（终端机）是数据传输的终点；而 **terminal illness**（晚期疾病）意味着生命到了终点。记住：terminal 的一切都和"终点"有关。
>
> **词拆分记忆**（辅助）：
> termin（=terminus，终点）+ -al（形容词后缀，"属于…的"）→ 属于终点的 → 终端的/晚期的

## 搭配与短语

> [!example]- 搭配
