# output

> [!info] 基础信息
> **音标** /ˈaʊtpʊt/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**产量，产出**== ; ②==**输出，输出功率**== ; ③输出信息 ;
**v.** ①输出 ;

> [!tip] 原型义
> **原型义**：产出——生产过程中产出的产品或结果
> **延伸维度**：空间路径
> **隐喻类型**：结构隐喻（产出=从系统"向外放出的东西"）

## 词根词缀

out(向外) + put(放/放置) → "向外放出"
**叙事**：工厂的流水线把产品 out(向外) put(放)——放到市场上，这些产品就是工厂的 **output**（产量）。

---

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**产出**"为统筹中心，沿空间路径向外扩展：
>
> 1. **产出**（生产层面：生产过程的结果）
>    - → **输出，输出功率**：从生产产出引申为技术/工程中的输出
>      - 激活条件：描述机器、系统的输出功率时
>    - → **输出信息**：从物理产出引申为信息/数据的输出
>      - 激活条件：描述计算机、系统的数据输出时（data output）

### 统筹（选择适用的模式）

- **延伸中心**：以"向外放出的结果"为中心，从生产产出到技术输出到信息输出
- **一句话统筹**：output 就是"系统向外放出的东西"——无论是产品、能量还是数据

> [!check]- 链路验证
> - [x] **可逆性**：从"输出信息"可反推回"向外放出的结果"
> - [x] **可统筹**：所有义项围绕"向外放出的结果"串联
> - [x] **有支撑**：annual output / power output / data output 等常见用法

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> 想象一个工厂的传送带，原材料从一端进去，成品从另一端 out(向外) put(放)出来——这些成品就是工厂的 **output**（产量）。

> **词拆分记忆**：
> out(出去) + put(放) → 把东西放出去 → **产出，输出**
