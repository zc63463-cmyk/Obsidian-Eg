# phrase

> [!info] 基础信息
> **音标** /freɪz/ | **词级** 必备词 | **语义场** [[社会专业]]

## 核心释义

**n.** ①==**短语，词组**== `a set phrase` / `a noun phrase` ; ②==**措辞，表达方式**== `a choice of phrase` / `coin a phrase` ; ③==**乐句**== `a musical phrase` ;
**vt.** ①==**用言语表达，措辞**== `phrase sth carefully` / `phrase it as ...` ;

> [!tip] 原型义
> **原型义**：一种表达方式，简短的言语组合
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻（将言语的"表达"结构映射到音乐等其他表达形式）

## 词根词缀

phra(表达/说出) + -se(名词后缀)

%% 建议创建词根笔记 [[phas]]（源自希腊语 phrazein"告诉、表达"，与 phainein"显现"同源） %%

**叙事**：phrase 源自希腊语"表达、说出"——把想法用简短的词语组合"表达"出来，就是一个 phrase（短语/措辞）。

## 词义链路

> [!abstract]- 词义链路法
> 以"**一种表达方式**"为统筹中心，沿抽象路径向外扩展：
>
> 1. **一种表达方式**（语言层面：简短的词语组合）
>    - → **短语/词组**：<语法化，指没有完整主谓结构的词语组合>
>      - 激活条件：语法分析、语言学习中
>    - → **措辞/表达方式**：<语用化，关注"怎么说"而非"说什么">
>      - 激活条件：讨论说话方式、用词选择时
>    - → **乐句**：<跨域映射，将"表达方式"从语言映射到音乐>
>      - 激活条件：音乐语境中指旋律的一个片段

### 统筹（选择适用的模式）

- **延伸中心**：简短的"表达单元"
- **一句话统筹**：一切"简短的表达单元"——语言中的是短语，音乐中的是乐句。

> [!check]- 链路验证
> - [x] **可逆性**：从"乐句"能反向联想到"表达方式"
> - [x] **可统筹**：表达方式→短语→措辞→乐句，统一于"简短的表达单元"
> - [x] **有支撑**：a set phrase（固定短语）/ a well-phrased sentence（措辞优美的句子）

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**：
> phrase 和 [[phase]] 是"表兄弟"——phase 源自"显现"（月亮的外观），phrase 源自"表达"（把想法说出来）。一个是视觉上的"显现"，一个是语言上的"表达"。
>
> **词拆分记忆**：
> ph(发音似"翻") + r(人) + a(一) + se(色) + → 翻译时一个人要翻一色 → 注意"措辞"。

## 搭配与短语

> [!example]- 搭配
> - **a set phrase**："By the way" is a set phrase in English.（"By the way"是英语中的固定短语。）
> - **coin a phrase**：To coin a phrase, practice makes perfect.（套用一句老话，熟能生巧。）
> - **phrase it differently**：Let me phrase it differently.（让我换一种说法。）
