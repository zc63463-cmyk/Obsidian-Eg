# rescue

> [!info] 基础信息
> **音标** /ˈreskjuː/ | **词级** 必备词 | **语义场** [[社会习俗]]

## 核心释义

**vt.** ①==**营救，拯救**== ; ②挽救（经济/事业等） ;
**n.** ①营救，救援 ;

> [!tip] 原型义
> **原型义**：从危险或困境中把人（或事物）救出来
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（危险=牢笼/深渊，救援=打破牢笼/拉出深渊）

## 词根词缀

re-(再次、回) + [[scu|scue]](shelter 保护、庇护) → 反复保护 → 救援
**叙事**：在暴风雨中反复把受困者拉回安全的庇护所，就是 rescue。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**从危险中救出**"为统筹中心，沿具身路径向外扩展：
>
> 1. **从危险中救出**（物理层面：把人从灾害/事故中救出）
>    - → **挽救（抽象事物）**：从困境中拯救经济、事业等
>      - 激活条件：宾语为抽象名词（economy, career, project）时取此义

### 统筹（选择适用的模式）

- **一字一词概括**："救"——从危险/困境中把人或事物拉出来
- **一句话统筹**：无论是从洪水中救人，还是从破产边缘挽救经济，都是把对象从"危险"拉向"安全"。

> [!check]- 链路验证
> - [x] **可逆性**：从"挽救经济"可反向推导至"从危险中救出"
> - [x] **可统筹**：一个"救"字贯穿所有义项
> - [x] **有支撑**：rescue the economy / rescue survivors 均为常见搭配

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**（优先）：
> re-(反复) + scue(庇护) → 在灾难中反复把人拉回安全庇护所 = 营救。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> re(回) + scue(谐音"死球") → 从"死球"的绝境中把人拉回来 = 营救。
