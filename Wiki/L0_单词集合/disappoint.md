# disappoint

> [!info] 基础信息
> **音标** /ˌdɪsəˈpɔɪnt/ | **词级** 必备词 | **语义场** [[人本世界]]

## 核心释义

**vt.** ①==**使失望，使沮丧**== `V N` ; ②==**使（希望/计划）落空**== `V N` ;

> [!tip] 原型义
> **原型义**：打破约定、剥夺任命
> **延伸维度**：社会路径
> **隐喻类型**：结构隐喻（失望 = 期望被剥夺）

## 词根词缀

dis-(剥夺/取消) + [[cover|appoint]](任命/约定) → 取消约定
**叙事**：取消了原本的约定/任命 → 让人失望。

建议创建词根笔记 [[cover]]

## 词义链路

> [!abstract]- 词义链路法
> 以"**打破约定**"为统筹中心，沿社会路径向外扩展：
>
> 1. **打破约定**（社会层面：取消原本的安排）
>    - → **使失望**：打破了别人的期望 → 激活条件：描述人的情感反应
>    - → **使落空**：使计划/希望无法实现 → 激活条件：描述计划或期望未能实现

### 统筹（选择适用的模式）

- **一字一词概括**："负"——辜负
- **一句话统筹**：从取消约定到让人失望，都是"辜负期望"

> [!check]- 链路验证
> - [x] **可逆性**：使失望 → 辜负期望 → 打破约定
> - [x] **可统筹**：所有义项围绕"辜负/打破期望"
> - [x] **有支撑**：be disappointed at / disappointing result 为高频搭配
