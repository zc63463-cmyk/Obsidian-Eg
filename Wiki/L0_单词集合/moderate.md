# moderate

> [!info] 基础信息
> **音标** /ˈmɒdərət/ (adj.) /ˈmɒdəreɪt/ (v.) | **词级** 必备词 | **语义场** [[人本世界]]

## 核心释义

**adj.** ①==**适度的，中等的**== ; ②温和的，不极端的 ;
**v.** ①使缓和，节制 ;

> [!tip] 原型义
> **原型义**：保持在适度（边界）范围内，不走极端
> **延伸维度**：抽象路径
> **隐喻类型**：结构隐喻——"适度"如物理尺度上的中间位置

## 词根词缀

[[mod]](适度/测量) + -er(比较级) + -ate(动词/形容词后缀) → 使之适度 → 适度的
**叙事**：一个好厨师知道调料要**适度**（moderate），太多太少都不行——恰到好处才是最好的。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**保持在适度范围内**"为统筹中心，沿**抽象路径**向外扩展：
>
> 1. **保持在适度范围内**（度量层面：不超出边界）
>    - → ==**适度的，中等的**==：程度适中，不过分
>      - 激活条件：描述数量、程度、速度等适中时
>    - → **温和的，不极端的**：态度或立场不走极端
>      - 激活条件：描述政治立场、态度观点等温和时
>    - → **使缓和，节制**：使某物回到适度范围
>      - 激活条件：描述调节、控制程度时

### 统筹

- **一字一词概括**："度"——适度即核心
- **不同程度/过程**：极端 → 回到中间 → 适度

> [!check]- 链路验证
> - [x] **可逆性**：从"适度/温和/缓和"可反向推导回"保持在适度范围内"
> - [x] **可统筹**：所有义项都围绕"适度"这一核心
> - [x] **有支撑**：moderate exercise / moderate views 是考研常见搭配
