# dim

> [!info] 基础信息
> **音标** /dɪm/ | **词级** 必备词 | **语义场** [[自然物理]]

## 核心释义

**adj.** ①==**暗淡的，昏暗的**== ; ②模糊的，隐约的 ; ③（前景）暗淡的，不乐观的
**v.** ①（使）变暗淡 ; ②（使）变模糊

> [!tip] 原型义
> **原型义**：光线不足、暗淡的
> **延伸维度**：具身路径
> **隐喻类型**：方位隐喻——从"光线暗淡"投射到"前景不乐观"、"记忆模糊"

## 词根词缀

与 [[dis-di|di-]](分散) 同源——光线被**分散**→ 不集中 → **暗淡**（dim）
**叙事**：当光线被**分散**到各个方向，没有聚焦到一点，眼前就变得**暗淡**（dim）。记忆被时间分散，就变得**模糊**（dim memory）。前景的光被遮住，就是**暗淡的**（dim prospects）。

## 词义链路

> [!abstract]- 词义链路法 · L1
> 以"**暗淡的**"为统筹中心，沿具身路径向外扩展：
>
> 1. **暗淡的**（物理视觉层面：光线不足）
>    - → **模糊的，隐约的**：<视觉不清晰>
>      - 激活条件：搭配 memory, view, sound，表示感知模糊
>    - → **前景暗淡的**：<抽象层面的"光线不足">
>      - 激活条件：搭配 prospects, future, chances，表示不乐观

### 统筹（选择适用的模式）

- **延伸中心**："暗"——光线暗 → 视觉暗（模糊）→ 前景暗（不乐观）
- **一字一词概括**："暗"——暗淡、模糊、暗淡

> [!check]- 链路验证
> - [x] **可逆性**：从"前景暗淡"可反向推导——看不到光明 → 暗淡
> - [x] **可统筹**：所有义项都围绕"暗/不清晰"这一核心感知
> - [x] **有支撑**：dim prospects / dim memory 为考研常见搭配

> 想象你走进一间只有微弱灯光的房间——光线太**暗**（dim），看什么都**模糊**（dim view），你对未来的预期也变得**暗淡**（dim prospects）。一切从"暗"开始。
