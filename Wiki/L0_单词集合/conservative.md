# conservative

> [!info] 基础信息
> **音标** /kənˈsɜːvətɪv/ | **词级** 必备词 | **语义场** [[政治法律]]

## 核心释义

**adj.** ①==**保守的，守旧的**== `a N estimate/approach` ; ②==**谨慎的，稳健的**== `a N estimate` ;
**n.** ①==**保守主义者**== ; ②==**保守派**== ;

> [!tip] 原型义
> **原型义**：倾向于保持现状的、不愿改变的
> **延伸维度**：社会路径
> **隐喻类型**：无隐喻（直接从"保持"的社会态度抽象而来）

## 词根词缀

con-(共同，一起) + [[serv|serv]](保持，保存) + -ative(形容词后缀，表示"有...倾向的")
**叙事**：con-（共同）+ serv-（保持）+ -ative（倾向...的）→ 倾向于保持现状的 → 保守的

---

## 词义链路

> [!abstract]- 词义链路法
> 以"**保持现状**"为统筹中心，沿社会路径向外扩展：
>
> 1. **保持现状**（社会态度层面）
>    - → **保守的，守旧的**：不愿改变传统或现状
>      - 激活条件：描述政治立场、社会态度、审美偏好
    - → **谨慎的，稳健的**：从"不愿冒险改变"引申为"小心谨慎的"
>      - 激活条件：描述估计、投资、决策等需要谨慎的语境

### 统筹

- **一字一词概括**：守——守住现有的就是保守
- **延伸中心**：以"保持不变"为核心，从政治保守延伸到行为谨慎
- **一句话统筹**：保持现状→政治保守→做事谨慎

> [!check]- 链路验证
> - [x] **可逆性**：从"谨慎的"可反向推导到"不愿冒险改变"
> - [x] **可统筹**：所有义项都围绕"保持/守旧"这一核心
> - [x] **有支撑**：conservative estimate（保守估计）、conservative party（保守党）

## 搭配与短语

> [!example]- 搭配
> - **conservative estimate**：保守估计（A conservative estimate suggests the project will cost $10 million.）
> - **conservative party**：保守党（The Conservative Party won the general election.）
> - **conservative approach**：保守的方法（We should adopt a conservative approach to this problem.）
> - **conservative with**：对...保守/节约（He is conservative with his money.）
