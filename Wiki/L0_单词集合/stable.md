# stable

> [!info] 基础信息
> **音标** /ˈsteɪbl/ (a.) | /ˈseɪbl/ (n.) | **词级** 必备词 | **语义场** [[抽象关系]]

## 核心释义

**a.** ①==**稳定的，稳固的**== `adj N` [通用] ; ②（人）沉稳的，理智的 `adj N` [通用]
**n.** ①马厩，牛棚 `N` [通用] ; ②（同一老板或机构下的）一群人 `N` [通用]

> [!tip] 原型义
> **原型义**：能站稳的
> **延伸维度**：具身路径
> **隐喻类型**：结构隐喻（将身体"站稳"映射为状态/性格的"稳定"）

## 词根词缀

[[st-sta-stat|sta]](站立) + -ble(形容词后缀，表"能够……的") → 能够站住的 = 稳定的
**叙事**：sta(站) + ble(能……的) = 能够稳稳站住的。桌子四条腿站得稳，就是 stable（稳定的）。一个人情绪不波动，内心"站得住"，也是 stable。

## 词义链路

> [!abstract]- 词义链路法
> 以"**能站稳的**"为统筹中心，沿具身路径向外扩展：
>
> 1. **能站稳的**（身体动作层面）
>    - → **稳定的，稳固的**：系统能"站稳"不倒
>      - 激活条件：描述价格、关系、状态（stable prices, stable relationship）
>    - → **沉稳的，理智的**：内心能"站稳"不动摇
>      - 激活条件：描述性格（a stable personality, emotionally stable）
>    - → **马厩**：马"站立"的地方（名词用法，同源异义）
>      - 激活条件：农业或历史语境

### 统筹（选择适用的模式）

- **一字一词概括**："站得住"——价格站得住→稳定，情绪站得住→沉稳
- **延伸中心**：所有义项围绕"站得住/不倒"这一核心特征

> [!check]- 链路验证
> - [x] **可逆性**：从"稳定的"可反向推导到"能站稳的"
> - [x] **可统筹**：形容词义项都围绕"站得住"这一核心
> - [x] **有支撑**：stable prices, stable relationship 为考研高频搭配

## 记忆锚点

> [!quote]- 记忆方式
>
> **叙事化词源**（优先）：
> sta(站) + ble(能……的) = 能站住的。想象一个三脚架稳稳地站在地上，风吹不倒——那就是 stable。引申到价格、关系、情绪，都是"站得住、不倒"的意思。
>
> **词拆分记忆**（标准词根无法解释时使用）：
> s(石) + table(桌子) → 石头桌子 → 稳定的
