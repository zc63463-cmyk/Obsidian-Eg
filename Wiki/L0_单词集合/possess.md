# possess

> [!info] 基础信息
> **音标** /pəˈzes/ | **词频** 考研中频 | **语义场** [[抽象关系]]

## 核心释义

**v.** ①==**拥有，具有**== ; ②支配，控制（指情感、力量等）

> [!tip] 原型义
> **原型义**：坐在上面 → 占据 → 拥有
> **延伸维度**：空间路径
> **隐喻类型**：方位隐喻——从"坐在某物上面"（物理占据）投射到"拥有/控制"（抽象占有）

## 词根词缀

[[pon/pos|pos]](放置) + -sess(来自拉丁语 sedere，坐) → 坐在放置的东西上面 → 占据 → 拥有
**叙事**：把东西**放**好，然后**坐**在上面，表示这个东西归你了——这就是**拥有**（possess）。被愤怒"坐在上面"，就是被愤怒**支配**（possessed by anger）。

---

## 词义链路

> [!tip]- 词义链路法 · L1
> 以"**坐在上面 → 拥有**"为统筹中心，沿空间路径向外扩展：
>
> 1. **坐在上面 → 占据**（物理层面：坐在某物上表示占有）
>    - → **拥有，具有**：<对财产、品质、技能等的占有>
>      - 激活条件：搭配 property, qualities, skills，表示拥有某物
>    - → **支配，控制**：<被某种力量"坐在上面"即被其控制>
>      - 激活条件：被动语态 be possessed by/with，搭配 fear, anger, desire

### 统筹（选择适用的模式）

- **延伸中心**："坐在上面"→ 占据 → 拥有 → 被控制
- **一字一词概括**："占"——占据、占有、占控

> [!check]- 链路验证
> - [x] **可逆性**：从"拥有"可反向推导——坐在上面 → 占据 → 拥有
> - [x] **可统筹**：所有义项都围绕"占据/占有"这一核心
> - [x] **有支撑**：possess the qualities / possessed by fear 为考研常见用法

## 记忆锚点

> [!quote]- 记忆方式 · L1
>
> **叙事化词源**：
> 想象一个国王**坐**在自己的宝座上——他**坐**在王国的最高处，所以**拥有**（possess）整个王国。如果恐惧**坐**在你身上，你就是被恐惧**支配**（possessed by fear）。
>
> **词拆分记忆**：
> possess = [[pon/pos|pos]](放) + -sess(坐) → 放好然后坐上去 → 拥有
