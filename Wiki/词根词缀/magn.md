# magn-/maj-/max-（大、伟大）

> [!info] 核心信息
> - **词根/词缀**：magn-/maj-/max-
> - **含义**：大、伟大
> - **来源**：拉丁语 *magnus*（大的）
> - **类型**：词根

## 叙事记忆

[[magnificent]]：拉丁语 *magnus* 就是"大"。加上 -ific（做）和 -ent（形容词后缀），变成"做得大的"——这就是 magnificent。一座宫殿又大又美，它是 **magnificent**（壮丽的）；一个人的表现远超预期，也是 **magnificent**（极好的）。记住 magn = 大，-ific = 做，-ent = ……的，magnificent = 做得大的 = 大而美的。
[[magnify]]：拉丁语 *magnus* 就是"大"。加上 -ify（使……）变成"使变大"——这就是 magnify。用放大镜看蚂蚁，蚂蚁被 **magnified**（放大了）10 倍。一个人把小事说成天大的事，他在 **magnify** the problem（夸大问题）。记住 magn = 大，-ify = 使，magnify = 使变大 = 放大/夸大。
[[magnitude]]：拉丁语 *magnus* 就是"大"。加上 -itude 变成"巨大的状态"——这就是 magnitude。地震有多"大"用 magnitude 衡量（震级），一个问题有多"大"用 magnitude 描述（严重程度），一个成就有多"大"用 magnitude 评价（重要性）。记住 magn = 大，magnitude 就是"大"的名词形式。
[[major]]：拉丁语 *magnus* 就是"大"，它的比较级 *major* 就是"较大的"。较大的东西自然就是**主要的**——这就是 major。大学里你选的**主要科目**就是你的 **major**（专业）。军队里比上尉高一级的军官是 **major**（少校）。记住 maj = 大（magn 的变体），major = 较大的 = 主要的。
