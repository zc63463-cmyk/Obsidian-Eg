# graph-/gram-（写、画）

> [!info] 核心信息
> - **词根/词缀**：graph-/gram-
> - **含义**：写、画
> - **来源**：希腊语 *graphein*（写、画）
> - **类型**：词根

## 叙事记忆

[[character]]：古希腊人用尖棍子（kharax）在蜡板上**刻**下印记（kharakter），用来标记和区分物品。一个人的"性格"就是他灵魂上的**刻印**——独一无二的特征。小说中的"角色"也是作者**刻**画出来的印记。连电脑上的"字符"都是最原始的"刻印"——一切 character 都是"刻出来的标记"。
[[paragraph]]：古希腊人在抄写文本时，会在新段落开始的地方**旁边写**一个标记（¶），告诉读者"这里换了一段"。这个"在旁边写标记"的动作就是 *paragraphein*。后来，这个标记的名字变成了被标记的内容本身——**段落**（paragraph）。从"旁边的标记"到"段落"本身，就像"皇冠"从"头上的装饰"变成了"王权的象征"。

## 基础词

> [!note]- L0_基础词关联
> 以下基础词笔记引用了本词根，可通过词根线索辅助记忆：

> [[geography]]：geo（地球）+ graph（写）+ y（名词后缀）→ 写地球 → 描述地球表面的学科 → 地理学。geo- 出现在 geology（地质学）、geometry（几何学）中。
>
> [[graphic]]：graph（写、画）+ ic（与……有关的）→ 与画画有关的 → 图形的。graphic description 就是像画一样生动的描述。graphic violence 就是画面感太强的暴力——生动到让人不适。
>
> [[graph]]：graph 就是"写、画"的意思。用线条画出数据就是 graph（图表），用线条画出关系就是 graph（关系图）。graph 本身就是"画出来的东西"。
>
> [[telegraph]]：tele（远处的城市）+ graph（写下信息）→ **从远处写** → 电报。19世纪人们想快速传递信息，于是发明了 telegraph——不用信使跑腿，用电信号在远处"写下"文字。
