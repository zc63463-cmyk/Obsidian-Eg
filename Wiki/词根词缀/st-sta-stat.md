# st-/sta-/stat-（站立/放置/状态）

> [!info] 核心信息
> - **词根/词缀**：st-/sta-/stat-
> - **含义**：站立、放置、状态
> - **来源**：拉丁语 *stare*（站立）+ *statuere*（使站立/放置），源自 PIE *\*sta-*（站立，使...站立，使...坚定）
> - **类型**：词根

## 叙事记忆

> [!tip] 词源故事
> 想象一个古老的广场中央，矗立着一尊**雕像**——它**站**在那里千年不动，成为城市的**标准**。人们从四面八方走来，在它面前**停留**、**安顿**下来，逐渐形成了一个**国家**。有人站在雕像旁**陈述**自己的主张，有人**建立**了法律，有人用数字**统计**人口。一切文明的起点，不过是有人决定在某个地方**站住**——stand，stay，state，statue，status，statute，全都是从那个"站住"的瞬间开始的。
>
> **叙事五要素**：
> - **具象**：广场中央矗立千年的雕像
> - **情感**：站住的坚定感、安顿下来的安全感
> - **简洁**：站住 → 定住 → 立国 → 立法 → 立言
> - **关联**：stand → standard → state → statue → status → statute → statistics
> - **独特**：从"双脚钉地"这一个身体动作，衍生出整个文明的基本概念

## 含义延伸链路

> [!note] 含义延伸
> **站立（物理动作）** → 放置/安顿（使站立） → 状态/地位（站立的方式） → 站立之物（雕像/标准） → 国家（共同站立的政治实体） → 立法/陈述（把道理"立"出来）

## 相关词根

- [[fac]]：做、制造——与 st- 常组合（如 establish 中 -ish 与 fac 同源）
- [[ced-cess]]：行走、退让——与 st-（站立）形成"动与静"的语义对照
- [[tend-tens]]：伸展、倾向——与 st-（站立不动）形成"伸展"与"站定"的对比
- [[form]]：形状、形式——"站立之物"自然具有"形状"
- [[pos]]：放置——与 statuere（使站立/放置）语义相近
