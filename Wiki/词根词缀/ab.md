# ab-/abs-（离开）

> [!info] 核心信息
> - **词根/词缀**：ab-/abs-
> - **含义**：离开
> - **来源**：拉丁语 *ab*（离开）
> - **类型**：前缀

## 叙事记忆

[[absence]]：一个人从房间里"离开"了，他的座位空着——这就是最原始的"不在"画面。从物理空间的缺席，延伸到抽象层面的"缺乏"：某种东西不在了，就是"缺乏"了。
[[absent]]：一个学生没出现在教室里——他"不在这里"，这就是 absent 最核心的画面。从物理空间的不在，延伸到抽象层面的"缺乏"：某种特质不存在于某人身上，就是"缺乏的"。
[[absolute]]：一根绳子被"松开"了，不再被束缚——这就是 absolute 的原始画面。从"不受约束"这个核心概念出发，延伸出"绝对的、完全的"（没有任何限制），再进一步引申为"确定的、毫无疑问的"（不受质疑的约束）。
[[absorb]]：一块海绵把水"吸进去"——这就是 absorb 最原始的画面。从物理上的"吸收液体"，延伸到精神上的"全神贯注"（注意力被吸走），再延伸到组织层面的"吞并"（把别的公司吸进来）。
[[abstract]]：你从一棵具体的树中"拉出"树的本质特征——这就是 abstract 的原始画面。从"拉离具体事物"这个核心动作出发，引申出"抽象的"（非具体的），再延伸到"提取精华"和"写摘要"。

## 基础词

> [!note]- L0_基础词关联
> 以下基础词笔记引用了本词根，可通过词根线索辅助记忆：
>
> [[adhere]]：ad-(朝向) + her(粘附) → **粘附**。ad（朝向）+ her（粘附）→ 朝着一个东西粘上去 → 粘附。引申为"粘住不放"→ 坚持、遵守（原则、规则）。
>
> [[beneath]]：be-(加强) + neath(下面) → **在……下方**。be（加强）+ neath（下面）→ 在正下方。地面之下（beneath the ground），地位之下（marry beneath her），有失身份（beneath him）。beneath 就是"在下面"——空间下面→地位下面→不值得。
>
> [[cancel]]：源自 *cancelli*(格栅) → **取消**。cancelli（格栅）→ 在文件上画交叉线 → 划掉、使无效 → 取消。想象在一份合同上画一个大大的"X"——这份合同就被 cancel 了。
>
> [[deficiency]]：de-(不足) + fic(做) + -iency → **缺乏**。de（不够）+ fic（做）+ iency（状态）→ 做得不够的状态 → deficiency。营养做得不够就是 vitamin deficiency（维生素缺乏）。能力做得不够就是 a deficiency in ability（能力不足）。
>
> [[desert]]：de-(分离) + sert(加入) → **沙漠**。de（分离）+ sert（加入）→ 没有人愿意加入的地方 → 荒漠。沙漠就是被遗弃的土地。动词 desert 就是"遗弃"——像抛弃一片荒地一样抛弃某人。
>
> [[embark]]：em-(进入) + bark(船) → **上船**。em（进入）+ bark（船）→ 进入船中 → 上船。后来引申为"开始做某事"——就像上船开始一段旅程一样。embark on a new career 就像"登上新事业的船"。
>
> [[emit]]：e-(出) + mit(发送) → **发出**。e（出）+ mit（发送）→ 向外发送 → 发出、排放。emit 的核心是"从内部向外发送"：工厂 emit 废气（排放），太阳 emit 光（发出），人 emit 声音（发出）。
>
> [[kidnap]]：kid(小孩) + nap(偷) → **绑架**。kid（小孩）+ nap（偷偷抓走）→ kidnap = 偷偷把小孩抓走→ 绑架。后来词义扩大，不仅限于绑架小孩，也指绑架任何人。
>
> [[launch]]：源自古法语 *lanchier*(投掷) → **发射**。launch 原意是"投掷长矛"→ 发射火箭→ 发起活动→ 推出产品。像投掷长矛一样，把新事物"投"向世界。
>
> [[lean]]：日耳曼语源 → **倾斜**。lean（倾斜）就是身体向某个方向偏过去。你 lean on someone（倚靠某人）→ 引申为"依赖"某人。lean meat（瘦肉）→ 脂肪少，"倾斜"到只剩肉。lean year（歉收年）→ 产出"倾斜"到很少。
>
> [[pinch]]：pin(尖锐物) + -ch(动作后缀) → **捏**。pin（尖锐物）+ -ch（动作后缀）→ 用尖锐物夹住 → 捏、掐。一根针（pin）扎一下是 pinch，别针夹住也是 pinch。
>
> [[plentiful]]：plent-(充足) + -ful(充满) → **丰富的**。plentiful = plent（充足）+ ful（充满）= 充满充足的 → 丰富的。plentiful supply = 充足的供应。plentiful resources = 丰富的资源。
>
> [[rear]]：古英语 *rǣran*(使升起) → **后部**。rear 的核心是"后面"——the rear of the building（建筑物的后面），rear-view mirror（后视镜）。引申为"抚养"——把孩子从后面"抬"到前面（成长）。
>
> [[reclaim]]：re-(回) + claim(喊叫/索取) → **取回**。re（回）+ claim（喊叫/要求）→ 向回喊叫要求→ 取回，收回。reclaim land = 把荒地"取回"为可用土地→ 开垦。reclaim waste = 把废料"取回"为可用材料→ 回收利用。
>
> [[regarding]]：regard(关注) + -ing(介词化) → **关于**。regard（关注）+ -ing → 关注的方向 → "关于"。I'm writing regarding your letter（我写信是关于你的来信）。regarding 就是 regard 的介词用法，引出"关注"的对象。
>
> [[shed]]：古英语 *scēadan*(分离) → **脱落**。蛇每年蜕一次皮——旧的皮自然脱落，新的皮露出来。这就是 shed 的核心画面。从蛇蜕皮（shed skin）到树落叶（shed leaves），从流泪（shed tears）到散发温暖（shed light/warmth），shed 始终围绕"分离、脱落"这一核心。
>
> [[sheer]]：日耳曼语源 → **纯粹的**。sheer 本义是"清澈的、纯净的"。水清澈见底——没有任何杂质。延伸到"纯粹的"——sheer luck（纯粹的运气）。延伸到"陡峭的"——悬崖没有任何倾斜，完全是垂直的——a sheer cliff。
>
> [[shepherd]]：sheep(羊) + herd(看管) → **牧羊人**。sheep（羊）+ herd（看管牧群）→ 看管羊群的人 → 牧羊人。牧羊人的核心工作是保护和引导——把羊群带到安全的草地，远离危险。延伸到人类世界——老师带领学生上公交车——shepherding the children into the bus。
>
> [[shortage]]：short(短/不够) + -age(状态) → **短缺**。short（短、不够）+ -age（状态）→ 不够用的状态 → 短缺。东西被"切短了"，自然就不够用了——water shortage 就是水不够用了。
>
> [[shorthand]]：short(短) + hand(手) → **速记**。short（短）+ hand（手）→ 用"短"的方式写字 → 速记。手写得"短"了——每个字都缩写，写得飞快，这就是 shorthand。记者开会时用 shorthand 记录，把长句子缩成几个符号。
>
> [[shot]]：shoot 的过去式/过去分词 → **射击**。shot 原本是 shoot（射出）的过去式。一次射击就是 a shot。医生用针"射出"药液就是"注射"——a shot of penicillin。相机"射出"一次就是"一个镜头"——a camera shot。尝试就像"射出一发"——give it a shot。
>
> [[skill]]：古诺斯语 *skil*(区分) → **技能**。sk-（切割/区分）→ 能把事物区分开来 → 有技能。skill 就是从"区分好坏"到"掌握技能"。
>
> [[undo]]：un-(否定/反转) + do(做) → **撤销**。un（反转）+ do（做）→ 把做过的事反转回去 → 撤销。你系了鞋带，undo 就是解开。你做了决定，undo 就是取消。你建了房子，undo 就是拆毁。undo 就是时间的倒带键。
