# mod-（量度/方式/模式）

> [!info] 核心信息
> - **词根/词缀**：mod-
> - **含义**：量度、方式、模式
> - **来源**：拉丁语 *modus*（量度、方式、限度），源自 PIE *\*med-*（采取适当措施）
> - **类型**：词根

## 叙事记忆

> [!tip] 词源故事
> 想象一位老裁缝，他不用尺子，全凭手感来**量度**布料——这种独特的**方式**（mode）让他做出的衣服与众不同。他不追求极端，永远保持**适度**（moderate），既不过紧也不过松。他的**模型**（model）成为全城裁缝的标杆。有人问他秘诀，他**谦虚地**（modest）说："没什么，只是找到了合适的**尺度**（mod）而已。"从量度到方式，从适度到谦虚，mod-族词根的核心意象是：**找到恰到好处的那条线**。
>
> **叙事五要素**：
> - **具象**：老裁缝用手指丈量布料的场景
> - **情感**：恰到好处的满足感、谦逊的自持感
> - **简洁**：量度 → 方式 → 适度 → 谦虚 → 模型 → 修改
> - **关联**：mode → model → moderate → modest → modify → modern → mock → accommodate
> - **独特**：一个"量度"的概念，延伸出"方式""适度""谦虚"等多维含义，核心都是"把握分寸"

## 含义延伸链路

> [!note] 含义延伸
> **量度（测量尺寸）** → 方式/模式（做事的"尺度"） → 适度/节制（不超过限度） → 谦虚（自我评价适度） → 修改（调整到合适的尺度） → 模型/模特（按标准尺度制作的样品）

## 派生词族

| 单词 | 构词分析 | 释义 |
|------|---------|------|
| [[mode]] | mod-(方式) + -e | 方式，模式——"做事的尺度/方法" |
| [[model]] | mod-(方式/尺度) + -el(小) | 模型，模特——"按标准尺度做的小样" |
| [[moderate]] | mod-(适度) + -er + -ate | 适度的，温和的——"不超限度" |
| [[modify]] | mod-(方式) + -ify(使) | 修改，调整——"使方式发生改变" |
| [[modern]] | mod-(当下方式) + -ern(属于...的) | 现代的——"属于当下方式/模式的" |
| [[modernization]] | modern + -ization(名词后缀) | 现代化 |
| [[modest]] | mod-(适度) + -est(最高级) | 谦虚的，适度的——"自我评价保持在最低适度" |
| [[mock]] | mod-(模仿) → 模仿变化 | 嘲笑，模拟——"模仿别人的方式" |
