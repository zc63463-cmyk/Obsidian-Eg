# div-（分）

> [!info] 核心信息
> - **词根/词缀**：div-
> - **含义**：分、分开
> - **来源**：拉丁语 *dividere*（分割），*divinus*（神圣的，与"分"引申相关）
> - **类型**：词根

## 叙事记忆

[[individual]]：in-（不）+ dividu-（可分的，div- 变体）+ -al（形容词后缀）→ **不可再分**的。在拉丁语中，*individuum* 指的是"不能再分割的最小单位"——一个**个体**（individual）就是不可再分的人。从哲学上的"不可分割的存在"到日常的"个人"，individual 的核心始终是"独一无二、不可再分"——每个人都是独立的、不可被进一步拆分的完整存在。

[[diverge]]：di-（=dis-，分开）+ verg（转向）→ 向不同方向**分**开。当一条河**分**成两条支流，它们就**分歧**了（diverge）；当两个人的观点向不同方向发展，他们的思想就**分道扬镳**了（diverge in opinion）。diverge 的精髓在于"从一个点出发，向不同方向散开"——与 converge（汇聚）恰好相反。

## 相关词根

- [[ver-vert]]：diverse 和 divert 中 vers-/vert-（转）与 div-（分）组合，"分转"即分歧
- [[id-ident]]：individual 中 in- + dividu-（可分的），与 id-（同一性）形成对比——个体是"不可分的同一"
- [[dis-di]]：diverge 和 diverse 中 di- 是 dis- 的变体，与 div-（分）语义呼应

## 基础词

> [!note]- L0_基础词关联
> 以下基础词笔记引用了本词根，可通过词根线索辅助记忆：
>
> [[adverse]]：ad-(朝向) + vers(转) → **不利的**。ad（朝向）+ vers（转）→ 转向对面 → 不利的、有害的。advertise 是"转向大众"→ 做广告，adverse 是"转向对面"→ 不利的。
>
> [[advertise]]：ad-(朝向) + vert(转) + -ise → **做广告**。ad（朝向）+ vert（转）+ ise（使……）→ 使（注意力）转向 → 做广告、宣传。adverse 是"转向对面"→ 不利的，advertise 是"转向大众"→ 做广告。
>
> [[align]]：a-(=ad-, 向) + line(线) → **使对齐**。a（向）+ line（线）→ 使向同一条线 → 对齐、排列。物理上把东西排成一条线是 align，抽象上让立场、目标一致也是 align with。
>
> [[alliance]]：all(全部) + -iance(状态) → **联盟**。all（全部）+ iance（状态）→ 全部绑在一起的状态 → 联盟。alliance 的核心就是"全部在一起"——多个国家/政党绑在一起就是 alliance。
>
> [[bond]]：源自古英语 *bindan*(捆绑) → **纽带**。bond 就是"绑"——bond 来源于 bind（绑）。绑住两个人→ emotional bond（情感纽带）。绑住借债关系→ government bond（政府债券）。绑住两个人→ a solemn bond（庄严的契约）。
>
> [[coalition]]：co-(共同) + alit(生长) + -ion → **联盟**。co（共同）+ alit（生长）+ -ion（名词）→ 共同生长在一起 → 联盟。想象不同政党像不同植物一样，原本各自独立生长，但为了应对共同的挑战，它们的根系交织在一起，共同生长——这就是 coalition。
>
> [[marital]]：源自拉丁语 *maritalis*(婚姻的) → **婚姻的**。marital 来自拉丁语"丈夫"（maritus）——与丈夫有关的，就是"婚姻的"。婚姻关系是 marital relations，婚姻问题是 marital problems。
>
> [[married]]：marry 的过去分词形式 → **已婚的**。married 是 marry（结婚）的过去分词形式——已经结婚的。已婚夫妇是 a married couple，已婚女人是 a married woman，已婚生活是 married life。
>
> [[plunge]]：源自拉丁语 *plumbicare*(使铅垂下) → **跳入**。plumb（铅锤）→ 铅锤垂直落下 → 像铅锤一样猛然跳入水中 → plunge。股价像铅锤一样垂直落下 → 暴跌。
>
> [[plural]]：plur-(更多/复数) + -al → **复数的**。plur（更多）+ al（的）→ 多于一个的 → 复数的。一个叫 singular（单数），两个及以上叫 plural（复数）。plural society（多元社会）就是由多种文化组成的社会。
>
> [[shed]]：古英语 *scēadan*(分离) → **脱落**。蛇每年蜕一次皮——旧的皮自然脱落，新的皮露出来。这就是 shed 的核心画面。从蛇蜕皮（shed skin）到树落叶（shed leaves），从流泪（shed tears）到散发温暖（shed light/warmth），shed 始终围绕"分离、脱落"这一核心。
>
> [[vest]]：源自拉丁语 *vestis*(衣服) → **背心**。vest 原义就是"衣服"。穿在身上的贴身衣物就是 vest（背心/内衣）。后来，法律上把"权利"也像衣服一样"穿"在人身上——权力 vested in somebody（权力归属于某人）。
