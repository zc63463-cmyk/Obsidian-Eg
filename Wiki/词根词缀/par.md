# par-/parat-（准备/相等/显现）

> [!info] 核心信息
> - **词根/词缀**：par-/parat-
> - **含义**：准备、相等、显现
> - **来源**：拉丁语 *parare*（准备、安排）+ *parere*（显现、可见），源自 PIE *\*pere-*（生产、获得）
> - **类型**：词根

## 叙事记忆

> [!tip] 词源故事
> 想象一位将军在战前**准备**（prepare）一切——他让士兵排成**平行**（parallel）的队列，仔细**比较**（compare）敌我兵力。他清楚自己的**准备**（preparation）是否充分，因为只有充分准备，胜利才会**显现**（appear）。战场上，士兵们并肩而立，每个人都是彼此的**同等者**（peer/peerless），没有谁比谁更重要。战后，他**修理**（repair）破损的装备，把一切重新安排好。从准备到显现，从比较到平等，par-族词根的核心意象是：**把一切安排到位，让真相显现**。
>
> **叙事五要素**：
> - **具象**：将军在战前排列士兵、清点装备的场景
> - **情感**：准备就绪的踏实感、真相显现的豁然开朗
> - **简洁**：准备 → 排列 → 比较 → 显现 → 平等 → 修理
> - **关联**：prepare → compare → appear → apparent → separate → parallel → repair
> - **独特**：一个"准备"的动作，延伸出"显现""平等""比较"等看似不相关却内在统一的含义

## 含义延伸链路

> [!note] 含义延伸
> **准备（安排就绪）** → 排列/安排（为准备而排列） → 分离（分开安排） → 显现（安排好后展示出来） → 比较（将两者并排对照） → 平等（并排时地位相同） → 修理（重新准备/修复）

## 基础词

> [!note]- L0_基础词关联
> 以下基础词笔记引用了本词根，可通过词根线索辅助记忆：
>
> [[ally]]：al-（=ad-，向）+ ly（=lig，绑） → **同盟者**。al（向）+ ly（绑）→ 向某人绑在一起 → 结盟。ally 就是和你"绑"在一起的人——你的盟友。alliance 是结盟的状态，ally 是结盟的人。
>
> [[blanket]]：blank（白色/空白）+ -et（指小后缀） → **毯子**。blanket 的字面意思是"白色的小毛布"——blank（白色）+ et（小）→ 一块白色的小毛布。后来这种毛布变成了冬天盖在身上的"毯子"。再后来，"毯子"的功能——覆盖全身——被隐喻化：大雪覆盖大地叫 a blanket of snow（厚厚的积雪），不加区分地适用于所有人叫 a blanket ban（全面禁令）。
>
> [[chapter]]：源自拉丁语 *capitulum*（小头） → **章**。caput（头）→ capitulum（小头）→ chapter。一本书被分成很多"小头"→ 每个部分就是一个 chapter（章节）。人生也被分成不同的"小头"→ a new chapter of life（人生新篇章）。
>
> [[farewell]]：fare（旅行）+ well（好） → **告别**。fare（旅行）+ well（好）→ 祝你旅途平安 → 告别。古人在分别时说"fare thee well"（祝你旅途平安），后来缩合成 farewell，成为"告别"的代名词。
>
> [[feast]]：源自古法语 *feste* → **盛宴**。feast 原指宗教节日，人们在节日上共享丰盛的食物，后来"盛宴"成为核心含义。feast on the delicious food——尽情享用美食。
>
> [[fellow]]：fee（钱）+ -lag（放置） → **家伙**。fee（钱）+ lag（放）→ 一起放钱做生意的人 → 合伙人 → 同伴、伙伴。你和朋友一起凑钱开了一家店，你们就是 fellow——合伙人，后来泛指一切"同伴"。
>
> [[heaven]]：源自古英语 *heofon*（天空） → **天堂**。heaven 就是"天空"——抬头看到的就是 heaven。古人认为天空之上是神居住的地方，所以 heaven 从"天空"变成了"天堂"。heaven 是"极乐之地"，所以 move heaven and earth（竭尽全力）。
>
> [[march]]：源自古法语 *marchier*（行军） → **行军**。march 来自拉丁语"战神 Mars"——行军是士兵为战争准备的行进方式。march 的核心是"有节奏地齐步行走"。士兵行军是 march，民众游行示威也是 march，进行曲是 march（配合行军节奏的音乐）。
>
> [[meet]]：源自古英语 *mētan*（相遇） → **遇见**。meet 是最基础的英语词汇之一，本义就是"面对面走到一起"。两个人从不同方向走来，在某个点 meet（相遇）。需求和要求也像两个人一样，走到一起"对接"上了就是 meet（满足）。
>
> [[member]]：源自拉丁语 *membrum*（肢体） → **成员**。member 原指身体的"肢体"，后来延伸为团体的"成员"——一个组织的成员就像身体的肢体一样，缺一不可。
>
> [[neutral]]：ne-（不）+ uter（任何一个）+ -al → **中立的**。neither（两者都不）是 neutral 的核心逻辑。ne（不）+ uter（任何一个）→ 不偏向任何一个 → 中立的。瑞士在战争中保持中立（neutral），记者应该保持中立态度（neutral tone）。
>
> [[passage]]：pass（通过）+ -age → **段落**。pass（通过）+ age（名词后缀）→ 通过的动作或结果 → 通道（通过的地方）、段落（阅读通过的部分）、通过（通过的事件）、时间流逝（时间通过）。
>
> [[section]]：sect（切）+ -ion → **部分**。sect（切）+ -ion（结果）→ 切割后的结果 → 部分。一篇文章被"切"成几个 section（章节），一个组织被"切"成几个 section（部门），一根木头被"切"开后的面就是 cross-section（截面）。
>
> [[senate]]：sen（老）+ -ate → **参议院**。sen（老）+ ate（机构）→ 由老人组成的机构 → 参议院。古罗马的元老院（Senate）就是由最有经验的长者组成的最高决策机构。美国的 Senate 也继承了这一传统。
>
> [[sentence]]：sent（感觉/判断）+ -ence → **句子**。sent（感觉/判断）+ ence → 表达判断的完整话语 → 句子。法官在法庭上表达的最终判断 → 判决。sentence 的两个核心义项"句子"和"判决"都来自"表达判断"——一个是语言上的判断，一个是法律上的判断。
