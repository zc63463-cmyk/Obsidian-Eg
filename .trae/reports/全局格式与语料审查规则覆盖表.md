# 全局格式与语料审查规则覆盖表

## 已覆盖问题

| 类别 | 现有规则 | 说明 |
|------|---------|------|
| 旧模板残留 | `old_mastery` / `old_tag_mastery` / `old_callout_level_suffix` / `old_review_section` | 由 `alignment_scan.py` 的 `detect_structure_issues()` 覆盖 |
| 语料缺失 | `missing_corpus_block` / `missing_corpus_bullets` | 能识别语料区缺块或无 bullet |
| tag 合法性 | `missing_tag` / `invalid_tag` | 能识别无 tag 或 tag 语法非法 |
| 基础清洗残留 | `chinese_residue` / `space_before_punctuation` / `explanation_or_mcq_residue` | 能识别中文残留、句末空格、题干/说明型残留 |
| 句子形式 | `not_full_sentence` | 能识别明显非完整句 |
| 目标词命中 | `missing_target_word` | 能识别目标词未出现 |
| 去重与数量 | `duplicate_sentence` / `insufficient_corpus_count` | 能识别重复句与数量不足 |

## 未覆盖问题

| 类别 | 缺口 | 风险说明 |
|------|------|---------|
| 模板语料识别 | 无 `template_corpus` | 大量自动生成句能通过现有校验，但学习价值低 |
| 伪真题 | 无 `fake_exam_tag` | 自动生成/重写句仍可挂 `[真题]`，污染来源可信度 |
| 功能词用法 | 无 `function_word_invalid_usage` | `if`、`while` 等只要出现在句中就算命中，无法保证真实语法用法 |
| 语义场景失配 | 无 `semantic_mismatch` | `redwood` 等实体名词可被塞进抽象政策模板 |
| 主动产出占位 | 无 `output_placeholder_residue` | `<自己在写作/翻译中使用该词的例句>` 这类占位不会被识别 |
| 区块命名漂移 | 无 `noncanonical_output_section_title` | `主动产出` 与 `内化标记` 混用，破坏模板统一性 |

## 当前验收边界

- `alignment_validate.py` 只组合：
  - `detect_structure_issues()`
  - `scan_corpus_issues()`
- 因此当前 `bad_count=0` 的含义是：
  - 结构格式大体合规
  - 语料在“句法与形式层面”通过
- 当前 `bad_count=0` 不代表：
  - 语料自然
  - 语料可信
  - `[真题]` 真实可追溯
  - 功能词例句可用于学习

## 直接证据样本

- `Wiki/L0_基础词/if.md`
  - `The report highlights the importance of if in the final decision. [真题]`
- `Wiki/L0_超纲词/redwood.md`
  - `The committee discussed the latest redwood during the meeting. [例]`
- `Wiki/L0_单词集合/ability.md`
  - 连续三条模板名词句，形式合法但语义弱

## 审查结论

- 现有规则足以支撑“结构与基础格式验收”
- 现有规则不足以支撑“全局格式与语料质量审查”
- 下一阶段必须新增问题码并先写红测，再扩展扫描器
