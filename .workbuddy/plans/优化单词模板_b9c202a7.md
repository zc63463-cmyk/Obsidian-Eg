## 产品概述

优化 Obsidian 词汇知识库的"单词笔记"模板，解决当前模板的结构性缺陷、效率问题和内容质量问题，使其更精简、更规范、更利于 Dataview 查询，并输出一份可供 Trae 批量修正 1500+ 笔记的模板规范文档。

## 核心需求

- 设计优化后的 `_模板-单词笔记.md`，解决 HERMES 注释膨胀、Dataview 路径不一致、内容冗余重复等问题
- 将音标等关键信息提升到 frontmatter 以支持 Dataview 查询
- 将网络激活从正文章节迁移为 frontmatter 字段
- 统一 callout 类型语义，消除词根词缀与记忆锚点的叙事重复
- 输出一份"模板修正规范"文档，包含逐字段的修正规则，供 Trae 批量执行
- 同步更新 `指令实现.md`，将 HERMES 注释内容迁移为操作规程
- 修复所有 Dataview 查询中的路径前缀问题（`VocabVault/` → 实际路径）

## 技术栈

- **知识库平台**：Obsidian（纯 Markdown + Dataview 插件）
- **模板系统**：手动模板文件（无 Templater/Core Templates 插件）
- **查询引擎**：Dataview（依赖 frontmatter 元数据 + 文件路径）
- **批量修正**：Trae（外部工具，按规范文档执行）

## 实现方案

### 核心优化策略

采用"Frontmatter 增强 + 正文瘦身"策略：

1. **Frontmatter 增强**：新增 `phonetic`、`pos`、`metaphor_type`、`word_root`、`network_activation` 字段，使关键数据可被 Dataview 直接查询
2. **正文瘦身**：移除所有 HERMES 注释（约 25% 行数）、移除重复的词尾定性速查、简化复习记录和主动产出、消除网络激活专节
3. **去重**：明确词根词缀 section 与记忆锚点 section 的叙事边界，禁止重复

### Frontmatter 变更对照

| 字段 | 现状 | 优化后 | 理由 |
| --- | --- | --- | --- |
| `phonetic` | 不存在 | `/.../` | 音标纳入 frontmatter，支持 Dataview 按音标筛选 |
| `pos` | 不存在 | `v./n./adj.` | 主词性纳入 frontmatter，支持 Dataview 按词性分组 |
| `metaphor_type` | 不存在 | `结构隐喻/方位隐喻/本体隐喻/无隐喻` | 从正文原型义 callout 提取，支持统计分析 |
| `word_root` | 不存在 | `词根名` | 支持按词根聚合查询，无需遍历正文 |
| `network_activation` | 不存在 | `[词根, 同义辨析, ...]` | 替代底部整个"网络激活"章节 |
| 其余字段 | 保持 | 保持 | 无变更 |


### 正文结构变更对照

| Section | 现状 | 优化后 | 变更说明 |
| --- | --- | --- | --- |
| HERMES 注释 | 15+ 行 `%% HERMES-XX: ... %%` | 全部移除 | 迁移至指令实现.md |
| 基础信息 callout | 含音标 | 保持但音标已同步至 frontmatter | callout 仍展示音标，frontmatter 提供查询 |
| 词尾定性速查 | 每篇重复 2 行规则 | 改为 `词尾定性速查见 [[词汇学习哲学#完整词尾分析规则]]` | 消除 1500+ 篇的重复内容 |
| 词根词缀 → 记忆锚点 | 叙事经常重复 | 明确分工：词根词缀侧重"拆解+简叙"，记忆锚点侧重"多策略记忆+展开叙事" | 禁止两处叙事相同 |
| 复习记录 | 含 4 行 checkbox 模板 | 仅保留元数据行，移除 checkbox | checkbox 模板每篇相同，冗余 |
| 网络激活 | 整个 section（4+ 行） | 移除，用 frontmatter `network_activation` 替代 | 操作指令不应占正文空间 |
| 语义场双链 | frontmatter 与正文可能不一致 | 统一以 frontmatter `semantic_field` 为准，正文 callout 中 `[[semantic_field]]` 必须与之一致 | 单一数据源 |


### Callout 类型统一规范

| Callout 类型 | 语义 | 适用 Section |
| --- | --- | --- |
| `[!info]` | 客观元数据 | 基础信息 |
| `[!tip]` | 核心洞察/要点 | 原型义 |
| `[!abstract]` | 理论模型/框架 | 词义链路 |
| `[!check]` | 自检验证 | 链路验证 |
| `[!note]` | 中性信息/数据 | 词性转换、同义词、反义词、派生词、复习记录 |
| `[!quote]` | 个人创作/记忆 | 记忆锚点 |
| `[!example]` | 具体用例 | 搭配、语料 |
| `[!success]` | 成就/内化 | 主动产出 |


### Dataview 路径修正

- `FROM "VocabVault/Wiki/L0_单词集合"` → `FROM "Wiki/L0_单词集合"`
- `FROM "VocabVault/Wiki/词根词缀"` → `FROM "Wiki/词根词缀"`
- `FROM "VocabVault/Wiki/同义辨析"` → `FROM "Wiki/同义辨析"`
- `FROM "VocabVault/Wiki"` → `FROM "Wiki"`
- 涉及文件：`词汇仪表盘.md`、`Wiki/语义场/*.md`、`词汇知识库索引.md`

## 实现注意

- **向后兼容**：新增 frontmatter 字段对已有笔记是可选的，Dataview 查询中用 `WHERE phonetic` 过滤即可兼容新旧格式
- **修正顺序**：先修正模板文件 → 再修正操作规程 → 再输出批量修正规范 → 最后修正 Dataview 路径
- **词根词缀与记忆锚点去重**：修正规范中需明确——若已有笔记两处叙事相同，修正时保留记忆锚点的完整版本，将词根词缀的叙事精简为一句话引用（如"见记忆锚点"）
- **Dataview 路径**：当前路径无 `VocabVault/` 前缀，所有引用该前缀的查询均失效，必须统一修正
