## 产品概述

基于 English Word Coach 和英语学习助手两个 skill 的深度研究，重新设计完备的英语单词笔记模板，系统性解决三个已确认问题：句型框架（问题3）、语料可信度分层（问题4）、维度框架数组化（问题7），同时用 FSRS 记忆模型取代 L0-L4 等级体系。

## 核心特性

- 核心释义嵌入句型标注 + 语域标签 + 常见错误 callout
- 语料三级可信度标记（[真题]/[COCA]/[例]），完整句子格式，支持测试生成
- extension_dim 改为多值数组，metaphor_type 降级为可选
- FSRS 字段取代 mastery: L0，支持算法化间隔复习
- 搭配 section 定位为高频语块（lexical chunks），不再重复句型
- 每个字段和 section 附填写指南，消除占位符歧义

## 技术栈

- 文件格式：Obsidian Markdown + YAML frontmatter
- 复习算法：FSRS (Free Spaced Repetition Scheduler) 参数体系
- 参考框架：Lakoff & Johnson 隐喻理论（3类型）、5维延伸维度、Hunston & Francis Pattern Grammar

## 实现方案

### Frontmatter 字段重设计

**移除**：`mastery: L0`（被 FSRS 字段取代）

**改为数组**：`extension_dim: [社会路径]` → `extension_dim: [社会路径, 具身路径]`

**降级为可选**：`metaphor_type`（不填不报错，保留供研究用）

**新增 FSRS 字段**（取代 mastery）：

```
fsrs_state: New          # New/Learning/Review/Relearning
fsrs_difficulty: 0.0     # 0.0-10.0, 初始0
fsrs_stability: 0.0      # 记忆稳定性(天), 初始0
fsrs_retrievability: 1.0 # 当前可提取概率, 初始1.0
next_review: <date>      # 下次复习日期
```

**保留字段**：title, tags, aliases, date, word_freq, phonetic, pos, semantic_field, prototype, word_root, network_activation, last_review, review_count

### 正文 Section 变更

**核心释义**：义项后加句型标注 `V N` + 语域标签 `[formal]`

```markdown
**vt.** ①==**抛弃，放弃**== `V N` [formal/written] ；②==**沉溺于**== `V oneself to N` [literary] ；
```

**常见错误 callout**（可选，紧跟核心释义）：

```markdown
> [!warning]- 常见错误
> suggest 不接 `to V`：~~suggest to go~~ → suggest going / suggest that we go
```

**搭配 section**：语块格式，含语域标注

```markdown
> [!example]- 搭配 · L3
> - **abandon ship**：弃船（紧急命令/航海）
> - **with reckless abandon**：不顾一切地（文学/状语语块）
```

**语料 section**：三级可信度 + 完整句子

```markdown
> [!example]- 语料 · L3
> - The government abandoned the project due to budget constraints. `[真题]`
> - She danced with wild abandon, as if no one was watching. `[例]`
```

**复习记录 section**：FSRS 格式

```markdown
> [!note]- 复习追踪
> **状态**：New | **难度**：0.0 | **稳定性**：0天 | **可提取率**：100%
> **上次复习**：- | **下次复习**：<date> | **复习次数**：0
```

## 实现要点

- FSRS 字段用 `fsrs_` 前缀避免与 Obsidian 插件冲突
- `fsrs_state` 枚举值 New/Learning/Review/Relearning 对应 FSRS 算法4种状态
- 语域标签用方括号紧跟义项（`[formal]`/`[informal]`/`[law]`/`[academic]`/`[literary]`），可选不强制
- extension_dim 数组格式在 YAML 中写为 `extension_dim: [社会路径, 具身路径]`
- 现有 5249 卡片的迁移策略：`mastery: L0` → `fsrs_state: New`，`extension_dim` 单值 → 包裹为数组
- 逐行解析 frontmatter（不用正则 \s*），避免之前 B0 脚本跨行匹配的 bug
